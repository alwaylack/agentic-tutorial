## 9.1 Deep Agents 是什么

在 LangGraph（见未来第 4 章） 中，我们学习了如何手动编排 Agent 的节点、边和状态。那是**底层运行时**——给你完全的控制权，但也意味着你要自己实现循环、工具调用、记忆、子代理等逻辑。

**Deep Agents** 是运行在 LangGraph 之上的 **Agent Harness（智能体脚手架）**。它把 LangGraph 的编排能力封装成更高层的抽象，让你可以用更少代码获得更丰富的功能：

| 能力 | LangGraph（底层） | Deep Agents（Harness） |
|---|---|---|
| 工具调用 | 自己写 ToolNode + 循环 | 内置 |
| 子代理 | 自己编译子图 | `create_deep_agent` 自动派生 |
| 记忆 | 自己配 Checkpointer | 内置短/长期记忆 |
| 上下文压缩 | 自己写截断逻辑 | 内置 Context Compaction |
| 技能系统 | 无 | Skills（可复用指令模板） |
| 审批模式 | 自己接 Interrupt | 内置 Manual / Auto / YOLO |
| 终端编码 | 无 | `dcode` CLI |

> 💡 **关键理解**：Deep Agents 不是替代 LangGraph，而是在 LangGraph 之上提供了一层**生产级脚手架**。当你需要精细控制图结构时使用 LangGraph；当你需要快速构建有记忆、有审批、有技能的 Agent 时使用 Deep Agents。
>
> 详见 [LangChain 文档：产品对比](https://docs.langchain.com/oss/python/concepts/products)。

## 9.3 基本用法：create_deep_agent

`create_deep_agent()` 是最核心的入口函数。它接收三个必需参数：`model`、`tools`、`system_prompt`。

### 模型格式

Deep Agents 使用统一的 `provider:model-name` 格式，支持以下提供商：

| 格式 | 示例 | 说明 |
|---|---|---|
| `openai:*` | `openai:gpt-5` | OpenAI 全系列 |
| `anthropic:*` | `anthropic:claude-sonnet-4-6` | Claude 全系列 |
| `google_genai:*` | `google_genai:gemini-3.6-flash` | Gemini 全系列 |
| `openrouter:*` | `openrouter:z-ai/glm-5.2` | OpenRouter 路由 |

### 第一个例子：带天气工具的 Deep Agent

```python
from deepagents import create_deep_agent

# 工具定义：Python 函数 + docstring
def get_weather(city: str) -> str:
    """Get current weather for a given city.
    
    Args:
        city: The city name in English (e.g., 'San Francisco', 'Tokyo')
    
    Returns:
        A string describing the current weather conditions
    """
    # 实际项目中这里会调用 Weather API
    return f"It's 22°C and sunny in {city}!"

# 创建 agent
agent = create_deep_agent(
    model="anthropic:claude-sonnet-4-6",
    tools=[get_weather],
    system_prompt="You are a helpful weather assistant. Always cite the source of your information.",
)

# 运行 agent
result = agent.invoke(
    {"messages": [{"role": "user", "content": "What's the weather in San Francisco?"}]}
)

print(result["messages"][-1]["content"])
```

### 输出示例

```
Assistant: Based on real-time data, San Francisco is currently 22°C with sunny skies.
Note: Weather data sourced from local meteorological stations.
```

## 9.4 多模型示例：三种主流 Provider

Deep Agents 的模型抽象层让切换提供商只需改动一行配置：

### OpenAI

```python
from deepagents import create_deep_agent

def get_weather(city: str) -> str:
    """Get current weather for a given city."""
    return f"It's 22°C and sunny in {city}!"

agent = create_deep_agent(
    model="openai:gpt-5",          # 切换 OpenAI
    tools=[get_weather],
    system_prompt="You are a helpful weather assistant.",
)
```

### Anthropic

```python
agent = create_deep_agent(
    model="anthropic:claude-sonnet-4-6",  # 切换 Anthropic
    tools=[get_weather],
    system_prompt="You are a helpful weather assistant.",
)
```

### Google Gemini

```python
agent = create_deep_agent(
    model="google_genai:gemini-3.6-flash",  # 切换 Google
    tools=[get_weather],
    system_prompt="You are a helpful weather assistant.",
)
```

### OpenRouter（多模型路由）

```python
agent = create_deep_agent(
    model="openrouter:z-ai/glm-5.2",  # 通过 OpenRouter 路由到 GLM
    tools=[get_weather],
    system_prompt="You are a helpful weather assistant.",
)
```

> 💡 **推荐**：生产环境使用 `openrouter:*` 或结合 [Vercel AI Gateway](/ai-sdk/ch03) 实现多模型路由和成本优化。

## 9.5 工具定义规范

Deep Agents 使用 Python 函数作为工具，**docstring 即 schema**：

```python
def search_documents(query: str, max_results: int = 5) -> str:
    """Search internal document database for relevant information.
    
    Args:
        query: The search query in natural language
        max_results: Maximum number of results to return (1-10, default: 5)
    
    Returns:
        JSON string containing search results with relevance scores
    """
    # 实际实现...
    return '{"results": [{"title": "...", "score": 0.95}]}'
```

**关键规则：**
1. 函数名会被用作工具 ID
2. `docstring` 被解析为工具描述
3. 类型注解决定参数的 JSON Schema
4. 参数默认值写入 schema 的 `default` 字段

## 9.6 完整实战示例：多工具 Deep Agent

下面是一个完整的客服代理示例，包含多个工具和错误处理：

```python
from deepagents import create_deep_agent
import json

# 模拟数据库
ORDERS = {
    "ORD-12345": {"status": "shipped", "tracking": "1Z999AA10123456784"},
    "ORD-12346": {"status": "processing", "tracking": None},
}

def get_order_status(order_id: str) -> str:
    """Get the current status of an order.
    
    Args:
        order_id: Order ID in format 'ORD-XXXXX'
    
    Returns:
        Order status and tracking information
    """
    order = ORDERS.get(order_id)
    if not order:
        return f"Order {order_id} not found."
    
    result = f"Order {order_id}: {order['status']}"
    if order['tracking']:
        result += f" | Tracking: {order['tracking']}"
    return result

def cancel_order(order_id: str, reason: str) -> str:
    """Cancel an order if it hasn't been shipped yet.
    
    Args:
        order_id: Order ID to cancel
        reason: Reason for cancellation (required)
    
    Returns:
        Cancellation result
    """
    order = ORDERS.get(order_id)
    if not order:
        return f"Order {order_id} not found."
    
    if order['status'] == 'shipped':
        return f"Cannot cancel order {order_id} - already shipped. Please initiate a return instead."
    
    ORDERS[order_id]['status'] = 'cancelled'
    return f"Order {order_id} has been cancelled. Reason: {reason}"

def connect_to_human_agent() -> str:
    """Escalate the conversation to a human agent.
    
    Use this when the customer's request cannot be handled by automated tools.
    
    Returns:
        Confirmation message with transfer details
    """
    return "Transferring you to a human agent. Estimated wait time: 3 minutes."

# 创建客服代理
support_agent = create_deep_agent(
    model="anthropic:claude-sonnet-4-6",
    tools=[get_order_status, cancel_order, connect_to_human_agent],
    system_prompt="""You are a customer support agent for TechCorp. 
Help customers with their orders using the available tools. 
Always be polite and professional. If the customer's issue cannot be resolved with the tools, 
escalate to a human agent using connect_to_human_agent().""",
)

# 测试会话
result = support_agent.invoke({
    "messages": [
        {"role": "user", "content": "What's the status of my order ORD-12345?"}
    ]
})
print(result["messages"][-1]["content"])
```

## 9.7 与 LangGraph 的关系

理解 Harness 与 Runtime 的区别：

```
┌─────────────────────────────────────────────┐
│            Deep Agents (Harness)            │
│  ┌───────────────────────────────────────┐ │
│  │   create_deep_agent()                 │ │
│  │   - 内置工具循环                       │ │
│  │   - 内置记忆系统                       │ │
│  │   - 内置审批模式                       │ │
│  │   - 内置上下文压缩                     │ │
│  └───────────────────────────────────────┘ │
│              ↓ 编译为 ↓                     │
│  ┌───────────────────────────────────────┐ │
│  │      LangGraph StateGraph             │ │
│  │      - 节点：LLM node, tool node      │ │
│  │      - 边：条件路由                   │ │
│  │      - 状态：MessagesState            │ │
│  └───────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

**什么时候用 Deep Agents：**
- 快速原型验证
- 标准 Agent 模式（工具调用 + 记忆）
- 需要审批模式（如代码执行前人工确认）
- 需要 Skills 和 Memory 系统

**什么时候直接用 LangGraph：**
- 需要自定义图结构
- 需要复杂条件路由（如多分支规划器）
- 需要细粒度控制每一步的 state 转换
- 需要集成已有的 LangGraph 组件

> 如需深入学习 LangGraph 底层编排，参考 第 4-8 章（LangGraph 核心）。

## 本章小结

- Deep Agents 是运行在 LangGraph 之上的 Agent Harness，封装了工具循环、记忆、审批等常用能力
- `create_deep_agent(model, tools, system_prompt)` 是最简入口
- 支持四种模型格式：`openai:*`、`anthropic:*`、`google_genai:*`、`openrouter:*`
- 工具即 Python 函数，docstring 自动解析为 schema
- Deep Agents 编译为 LangGraph StateGraph，两者可无缝结合使用
