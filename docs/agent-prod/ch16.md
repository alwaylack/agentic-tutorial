> 本章目标
> - 理解 ECS 与 Fargate 的区别及选型场景
> - 掌握将 Docker 镜像推送到 ECR 的完整流程

本章是"生产部署"阶段的起点。前面的章节你已经学会了如何用 asyncio 和 FastAPI 构建异步 Agent 服务，如何用 LangGraph 编排多 Agent 工作流。现在，我们需要把这些服务真正部署到生产环境。

AWS ECS（Elastic Container Service）是 AWS 上最主流的容器编排服务。Fargate 是 ECS 的一种无服务器计算模式——你不需要管理底层 EC2 实例，AWS 自动处理扩缩容和补丁。

## 16.1 ECS vs Fargate：选型决策

| 特性 | EC2 启动类型 | Fargate |
|---|---|---|
| 基础设施管理 | 需要管理 EC2 集群 | 无需管理 |
| 成本模型 | 按 EC2 实例计费 | 按 vCPU/内存秒级计费 |
| 适用场景 | 长期稳定负载、成本敏感 | 波动负载、快速迭代、Agent 服务 |
| 启动延迟 | 低（实例常驻） | 中（冷启动约 2-5s） |
| 扩缩容速度 | 分钟级 | 秒级 |

**Agent 服务推荐 Fargate**：Agent 调用通常有突发流量（用户同时发起多个请求），Fargate 能快速扩容；且不需要管理 EC2，降低运维成本。

## 16.2 Docker 镜像构建与推送

首先编写生产级 Dockerfile。参考 [FastAPI 教程第 22 章](/fastapi/) 的部署部分，这里针对 Fargate 做优化。

```dockerfile
# Dockerfile
FROM python:3.12-slim

WORKDIR /app

# 安装系统依赖（如需要编译原生扩展）
```

```bash

# 获取登录凭证并登录 ECR

```

## 16.3 Fargate Task Definition

Task Definition 是容器的"配方"，定义 CPU、内存、环境变量、网络等。

创建一个 JSON 文件保存 Task Definition（便于版本控制）：

```json
{
  "family": "agent-service",
  "networkMode": "awsvpc",
  "requiresCompatibilities": ["FARGATE"],
  "cpu": "512",
  "memory": "1024",
  "executionRoleArn": "arn:aws:iam::<ACCOUNT_ID>:role/ecs-task-execution-role",
  "taskRoleArn": "arn:aws:iam::<ACCOUNT_ID>:role/ecs-agent-role",
  "containerDefinitions": [
    {
      "name": "agent-service",
      "image": "<ACCOUNT_ID>.dkr.ecr.us-east-1.amazonaws.com/agent-service:latest",
      "portMappings": [
        {
          "containerPort": 8000,
          "protocol": "tcp"
        }
      ],
      "environment": [
        {
          "name": "AWS_DEFAULT_REGION",
          "value": "us-east-1"
        },
        {
          "name": "LLM_API_KEY",
          "valueFrom": "arn:aws:ssm:us-east-1:<ACCOUNT_ID>:parameter/llm-api-key"
        }
      ],
      "logConfiguration": {
        "logDriver": "awslogs",
        "options": {
          "awslogs-group": "/ecs/agent-service",
          "awslogs-region": "us-east-1",
          "awslogs-stream-prefix": "ecs"
        }
      }
    }
  ]
}
```

注册 Task Definition：

```bash
aws ecs register-task-definition --cli-input-json file://task-definition.json
```

## 16.4 S3 存储：Agent 文件处理

生产 Agent 服务通常需要处理用户上传的文件（PDF、图片、音频）。S3 是理想选择：

```python
# app/storage.py
import boto3
import uuid
from botocore.config import Config

s3_client = boto3.client(
    "s3",
    config=Config(
        signature_version="s3v4",
        retries={"max_attempts": 3, "mode": "adaptive"}
    )
)

BUCKET_NAME = "agent-uploads"
PUBLIC_BUCKET_URL = f"https://{BUCKET_NAME}.s3.amazonaws.com"


def upload_file(file_bytes: bytes, filename: str, content_type: str) -> str:
    """上传文件到 S3，返回公开访问 URL"""
    key = f"uploads/{uuid.uuid4().hex}/{filename}"
    s3_client.put_object(
        Bucket=BUCKET_NAME,
        Key=key,
        Body=file_bytes,
        ContentType=content_type,
    )
    return f"{PUBLIC_BUCKET_URL}/{key}"


def download_file(key: str) -> bytes:
    """从 S3 下载文件"""
    response = s3_client.get_object(Bucket=BUCKET_NAME, Key=key)
    return response["Body"].read()


def get_presigned_url(key: str, expires_in: int = 3600) -> str:
    """生成预签名 URL（用于私有文件下载）"""
    return s3_client.generate_presigned_url(
        "get_object",
        Params={"Bucket": BUCKET_NAME, "Key": key},
        ExpiresIn=expires_in,
    )
```

注意：生产环境应使用 IAM Role 授权容器访问 S3，而非硬编码 Access Key：

```json
// ecs-agent-role 的信任策略
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Principal": {"Service": "ecs-tasks.amazonaws.com"},
      "Action": "sts:AssumeRole"
    }
  ]
}
```

```json
// ecs-agent-role 的权限策略
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["s3:GetObject", "s3:PutObject", "s3:ListBucket"],
      "Resource": [
        "arn:aws:s3:::agent-uploads",
        "arn:aws:s3:::agent-uploads/*"
      ]
    }
  ]
}
```

## 16.5 完整示例：Fargate 上部署 FastAPI Agent 服务

结合前面的知识，这是一个可运行的最小生产服务：

```python
# app/main.py
from fastapi import FastAPI, UploadFile, File, HTTPException
from fastapi.responses import JSONResponse
import boto3
import os

from .storage import upload_file, get_presigned_url

app = FastAPI(title="Agent 生产服务")

# 从环境变量读取配置（通过 SSM Parameter Store 注入）
BUCKET_NAME = os.getenv("BUCKET_NAME", "agent-uploads")
s3_client = boto3.client("s3")


@app.post("/upload")
async def upload_document(file: UploadFile = File(...)):
    """Agent 知识库文档上传"""
    content = await file.read()
    url = upload_file(content, file.filename, file.content_type)
    return JSONResponse({"url": url, "filename": file.filename})


@app.get("/presigned-url/{key}")
async def get_download_url(key: str):
    """生成私有文件下载链接"""
    url = get_presigned_url(key, expires_in=3600)
    return JSONResponse({"url": url})


@app.get("/health")
async def health():
    """健康检查（Fargate 使用此端点判断服务是否可用）"""
    return {"status": "ok"}
```

部署到 Fargate 集群：

```bash
# 创建 ECS 集群
aws ecs create-cluster --cluster-name agent-cluster --configuration '{"executeConfiguration":{"logDriver":"awslogs"}}'

# 创建服务（自动扩缩容到 2-4 个任务）
aws ecs create-service \
  --cluster agent-cluster \
  --service-name agent-service \
  --task-definition agent-service \
  --desired-count 2 \
  --launch-type FARGATE \
  --network-configuration "awsvpcConfiguration={subnets=[subnet-xxxxx],securityGroups=[sg-xxxxx],assignPublicIp=ENABLED}" \
  --load-balancer targetGroupArn=arn:aws:elasticloadbalancing:us-east-1:<ACCOUNT_ID>:targetgroup/agent-tg,containerName=agent-service,containerPort=8000
```

## 本章小结

- **ECS Fargate** 是无服务器容器部署的首选，适合 Agent 服务的波动负载
- **ECR** 存储镜像，**Task Definition** 定义资源规格和环境变量
- **S3** 作为 Agent 文件存储后端，支持上传、下载、预签名 URL
- **IAM Role** 授权容器访问 AWS 服务，避免硬编码密钥
- **健康检查** 端点是 Fargate 服务发现的基础
