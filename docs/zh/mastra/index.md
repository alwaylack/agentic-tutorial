# Mastra · 课程导学

本课程共 **21 章**，基于 **Mastra 官方文档与仓库**，掌握 TypeScript 全栈 AI 应用框架。

## 你将学到什么

| 阶段 | 章节 | 内容 |
|---|---|---|
| 入门 | 01–06 | 项目脚手架、Studio、模型路由、Agent、工具 |
| 进阶 | 07–13 | Workflow 图引擎、Suspend/Resume、Memory、RAG、Storage |
| 高级 | 14–17 | MCP Server、Evals 评估、可观测性、前端集成 |
| 生产 | 18–21 | 独立部署与服务端 · 三实战：生产级智能客服 / 全栈 AI 应用 / 数据问答 BI Agent |
