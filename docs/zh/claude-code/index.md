# Claude Code · 课程导学

本课程共 **21 章**，基于 **Claude Code 2.x** 官方文档与 npm 包说明，从零基础到团队级工程化应用。

## 你将学到什么

| 阶段 | 章节 | 内容 |
|---|---|---|
| 入门 | 01–05 | 安装配置、基本对话、CLAUDE.md、文件编辑、Bash 执行 |
| 进阶 | 06–10 | 权限安全、多轮会话、Git 集成、MCP 工具、Skills |
| 高级 | 11–15 | 子代理、Hooks、IDE 集成、SDK 编程调用、企业配置 |
| 生产 | 16–21 | 企业配置、成本管理、最佳实践与团队规范、综合实战、近期新特性 |
