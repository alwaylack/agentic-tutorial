# Playwright 教程 · 课程导学

本课程基于 **Playwright 1.6x 官方文档（Python 版）**编写，共 **22 章**，从零基础到生产级 E2E 测试体系。

## 你将学到什么

| 阶段 | 章节 | 内容 |
|---|---|---|
| 入门 | 01–05 | 架构原理、定位器、自动等待、Web-First 断言 |
| 进阶 | 06–12 | pytest 集成、iframe/popup、网络 Mock、认证复用、Trace、设备仿真 |
| 高级 | 13–18 | POM 设计模式、并行 Sharding、CI/Docker、API 测试、异步 API |
| 生产实践 | 19–22 | Flaky 治理、无障碍测试、WebSocket 实时应用、E2E 策略 |

## 与本站其他课程的配合

- 第 06 章起的 pytest fixture 用法可直接衔接 [pytest 教程](/zh/pytest/)；
- 第 18 章与 [FastAPI 教程](/zh/fastapi/) 的测试章节互相呼应，组成完整的 Web 测试技能栈。
