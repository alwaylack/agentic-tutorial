# 第 8 章 · 提示基本要素与指令设计

> 本章目标：掌握提示的基本构成要素，学会设计清晰、有效的指令，理解指令设计对模型输出的影响。

## 8.1 提示的五大要素

一个完整的提示通常包含以下要素：

| 要素 | 作用 | 示例 |
|---|---|---|
| **角色** | 设定模型的"人设" | "你是一个专业的 Python 工程师" |
| **任务** | 明确要完成什么 | "分析这段代码的性能瓶颈" |
| **上下文** | 提供背景信息 | 代码片段、文档链接、领域知识 |
| **约束** | 限制输出范围 | "用中文回答"、"不超过 200 字" |
| **格式** | 指定输出结构 | JSON、Markdown、列表等 |

## 8.2 指令设计原则

### 1. 清晰明确
避免模糊表述，使用具体、可执行的指令：

```python
# ❌ 不好的示例
"帮我写点东西"

# ✅ 好的示例
"写一篇 500 字的技术博客，介绍 Python 异步编程的最佳实践，面向有一定基础的开发者"
```

### 2. 结构化管理
使用分隔符和结构化格式：

```python
prompt = """
# 角色
你是一个技术文档撰写专家。

# 任务
将以下技术笔记整理成规范的 API 文档。

# 输入
{notes}

# 要求
1. 使用 Markdown 格式
2. 包含参数说明表格
3. 提供至少一个代码示例
4. 语言：中文

# 输出格式
## API 名称
## 描述
## 参数
## 示例
"""
```

### 3. 正面表述
优先使用正面指令而非否定：

```python
# ❌ 避免负面表述
"不要使用复杂的术语"

# ✅ 使用正面表述
"使用简单易懂的语言"
```

## 8.3 常见指令模式

### 1. 角色扮演模式
```python
role_prompt = """
你是一位拥有 10 年经验的系统架构师。
请从架构角度分析以下设计的优缺点：
{design_doc}
"""
```

### 2. 分步推理模式
```python
step_by_step = """
请逐步解决这个问题：
1. 首先理解问题的核心
2. 列出已知条件和约束
3. 推导解决方案
4. 验证结果的正确性

问题：{problem}
"""
```

### 3. 对比分析模式
```python
compare_prompt = """
请对比以下两种方案：
- 方案 A：{option_a}
- 方案 B：{option_b}

从成本、性能、可维护性三个维度进行分析，给出推荐。
"""
```

## 8.4 调试提示的技巧

当模型输出不理想时，尝试以下方法：

1. **添加更多上下文**：提供更详细的背景信息
2. **调整约束条件**：收紧或放宽限制
3. **改变表述方式**：换一种说法可能效果更好
4. **使用示例**：few-shot 示例能有效引导模型
5. **分解任务**：将复杂任务拆分为子步骤

## 本章小结

- 提示包含角色、任务、上下文、约束、格式五大要素
- 指令设计要清晰、结构化、使用正面表述
- 掌握角色扮演、分步推理、对比分析等常用模式
- 调试时从上下文、约束、表述、示例、分解五个角度尝试
