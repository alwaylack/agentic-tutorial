# Pi 编码智能体教程 · 课程导学

本课程基于 **pi 0.8x 官方文档**（README + docs/ 全部 30+ 篇）编写，共 **20 章**，从零基础到构建你自己的智能体工作流。

Pi 是一个极简的终端编码 harness：核心只做"模型 + 工具 + 会话"，其余一切（子代理、计划模式、主题、技能）都通过 **TypeScript 扩展 / 技能 / 提示词模板 / 包生态** 按需加装——"让 pi 适配你的工作流，而不是反过来"。

## 你将学到什么

| 阶段 | 章节 | 内容 |
|---|---|---|
| 入门 | 01–04 | 理念与架构、安装上手、模型配置、交互模式 |
| 进阶 | 05–09 | 会话分支、上下文压缩、设置与项目信任、提示词模板、技能 |
| 高级 | 10–15 | TypeScript 扩展开发、自定义工具、主题、包生态、SDK、RPC |
| 生产实践 | 16–20 | CI 自动化、CLI 全解、安全模型、容器化、团队工作流 |
