# 第 23 章 · 终端用户界面：pi-tui 与差量渲染

> 本章目标：掌握 `@earendil-works/pi-tui` 的差量渲染原理与核心组件，构建一个带 Markdown 渲染、输入框、结果滚动视图和 loader 动画的 Agent REPL 界面。

## 23.1 为什么需要差量渲染

传统 TUI 框架（如 curses）每次更新都会重绘整个终端，当输出量大时产生明显闪烁和延迟。`pi-tui` 的差量渲染（differential rendering）只重绘发生变化的部分，大幅提升交互流畅度：

```
传统方案：每次渲染 → 清屏 → 重画所有内容
差量渲染：对比前后帧 → 只输出变更字符 → 终端位置保持不动
```

这种模式特别适合 Agent REPL——用户输入时界面稳定，流式输出逐步追加，不会闪屏。

## 23.2 核心组件一览

`@earendil-works/pi-tui` 导出以下核心组件：

| 组件 | 用途 |
|---|---|
| `Box` | 带边框的容器，支持标题和圆角 |
| `ScrollView` | 可滚动内容区，自动处理换行 |
| `Markdown` | 渲染 Markdown 文本（基于 marked） |
| `Input` | 单行文本输入，支持 history |
| `SelectList` | 下拉选择列表，支持模糊匹配 |
| `Loader` | 旋转动画指示器 |
| `Image` | 终端内图像渲染（支持 ANSI 转义） |
| `HStack` / `VStack` | 水平/垂直布局容器 |
| `Spacer` | 弹性空白 |
| `Text` / `TruncatedText` | 文本显示 |

## 23.3 基础布局：Box + VStack

最简单的 Agent 界面由一个外层 Box 包裹 VStack 堆叠的内容：

```typescript
import { render } from '@earendil-works/pi-tui'
import { Box, VStack, HStack, Text, Spacer } from '@earendil-works/pi-tui/components'

await render(
  Box({
    title: '🤖 Agent REPL',
    borderStyle: 'round',
    content: VStack({
      children: [
        Text({ content: '正在分析请求...', color: 'cyan' }),
        Spacer(),
        HStack({
          children: [
            Text({ content: '输入命令: ' }),
            // Input 组件将在这里渲染
          ],
        }),
      ],
    }),
  })
)
```

`Box` 支持 `borderStyle: 'round' | 'single' | 'double' | 'hidden'` 四种边框风格。

## 23.4 Markdown 渲染与滚动视图

Agent 输出通常包含 Markdown 格式，用 `Markdown` 组件渲染，配合 `ScrollView` 实现长内容滚动：

```typescript
import { Markdown, ScrollView } from '@earendil-works/pi-tui/components'

// Agent 响应
const response = `
## 测试结果

| 用例 | 状态 | 耗时 |
|------|------|------|
| login | ✅ | 120ms |
| checkout | ❌ | 超时 |

**失败原因**：接口 /api/checkout 返回 500
`

await render(
  Box({
    title: 'Agent 输出',
    content: ScrollView({
      children: [Markdown({ content: response })],
      maxHeight: 20,
    }),
  })
)
```

`ScrollView` 自动处理滚动条和 `maxHeight` 约束。

## 23.5 交互特性：Keybindings 与 Undo

pi-tui 内置了完善的终端交互支持：

```typescript
import {
  KeybindingsManager,
  TUI_KEYBINDINGS,
  type Keybinding,
} from '@earendil-works/pi-tui/keybindings'

// 注册自定义快捷键
const bindings: Keybinding[] = [
  { keys: ['c-c'], action: 'exit' },
  { keys: ['up'], action: 'history_prev' },
  { keys: ['down'], action: 'history_next' },
  { keys: ['alt-left'], action: 'word_back' },
  { keys: ['alt-right'], action: 'word_forward' },
]

const mgr = new KeybindingsManager([...TUI_KEYBINDINGS, ...bindings])
```

`TUI_KEYBINDINGS` 提供了默认的导航键（上下左右、Home/End），可以叠加自定义绑定。

Kill Ring（剪贴板）和 Undo Stack 自动工作：复制的内容可用 `y` 粘贴，编辑历史可用 `Ctrl+_` 撤销。

## 23.6 Autocomplete 模糊匹配

`CombinedAutocompleteProvider` 聚合多个补全来源，配合模糊搜索过滤：

```typescript
import {
  CombinedAutocompleteProvider,
  type AutocompleteItem,
  type SlashCommand,
} from '@earendil-works/pi-tui/autocomplete'
import { fuzzyFilter } from '@earendil-works/pi-tui/fuzzy'

// 命令补全
const slashCommands: SlashCommand[] = [
  { label: '/help', description: '查看帮助' },
  { label: '/clear', description: '清屏' },
  { label: '/status', description: '查看 Agent 状态' },
  { label: '/cost', description: '查看 token 消耗' },
]

// 工具补全
const toolSuggestions: AutocompleteItem[] = [
  { label: 'run_api_test', description: '执行接口测试' },
  { label: 'run_web_test', description: '执行 Web 测试' },
  { label: 'view_report', description: '查看测试报告' },
]

const provider = new CombinedAutocompleteProvider([
  { source: 'commands', items: slashCommands },
  { source: 'tools', items: toolSuggestions },
])

// 模糊匹配过滤
const query = 'run api'
const matches = fuzzyFilter(query, toolSuggestions, { key: 'label' })
// → 返回 label 含 "run api" 的项目，按相关性排序
```

## 23.7 Loader 与状态管理

Agent 执行期间显示加载动画，完成后替换为结果：

```typescript
import { Loader, type LoaderIndicatorOptions } from '@earendil-works/pi-tui/components'

const loaderOptions: LoaderIndicatorOptions = {
  type: 'dots',       // 'dots' | 'line' | 'spinner'
  color: 'cyan',
  text: '分析中...',
}

// 状态机驱动渲染
type View = 
  | { type: 'loading'; loader: LoaderIndicatorOptions }
  | { type: 'result'; content: string }
  | { type: 'error'; message: string }

async function renderView(view: View) {
  if (view.type === 'loading') {
    return render(Box({ content: Loader(view.loader) }))
  }
  if (view.type === 'result') {
    return render(Box({ content: Markdown({ content: view.content }) }))
  }
  // error ...
}
```

`CancellableLoader` 还支持可取消的长时间任务，用户可按 `Ctrl+C` 中断。

## 23.8 实战：Agent REPL 界面

结合以上组件，构建完整的 Agent REPL：

```typescript
import { render } from '@earendil-works/pi-tui'
import {
  Box, VStack, HStack, ScrollView, Markdown,
  Input, Loader, Spacer, Text,
} from '@earendil-works/pi-tui/components'
import { KeybindingsManager, TUI_KEYBINDINGS } from '@earendil-works/pi-tui/keybindings'
import { Agent } from '@earendil-works/pi-agent-core'
import { createModels } from '@earendil-works/pi-ai'
import { anthropicProvider } from '@earendil-works/pi-ai/providers/anthropic'

// 初始化 Agent
const models = createModels()
models.setProvider(anthropicProvider())
const model = models.getModel('anthropic', 'claude-sonnet-4-6')!

const agent = new Agent({
  initialState: { systemPrompt: '你是一个测试助手', model },
  streamFn: models.streamSimple.bind(models),
})

// 渲染循环
type State = 'idle' | 'streaming' | 'done'
let state: State = 'idle'
let currentOutput = ''

async function loop() {
  while (true) {
    // 渲染当前状态
    const content = VStack({
      children: [
        // 输出区域
        ScrollView({
          children: [Markdown({ content: currentOutput || '(等待输入...)' })],
          maxHeight: 25,
        }),
        Spacer(),
        // 输入栏
        HStack({
          children: [
            Text({ content: '❯ ', color: 'green' }),
            // Input 组件（伪代码，实际需接入 stdin）
          ],
        }),
      ],
    })

    await render(Box({ title: '🤖 测试助手', content }))

    if (state !== 'streaming') {
      // 等待用户输入...
      const input = await getInput()
      if (!input) break
      
      state = 'streaming'
      currentOutput = ''
      
      // 流式执行
      for await (const chunk of agent.streamPrompt(input)) {
        if (chunk.type === 'text_delta') {
          currentOutput += chunk.delta
          // 重新渲染（差量：只更新变化的部分）
          await render(Box({ title: '🤖 测试助手', content }))
        }
      }
      state = 'done'
    }
  }
}

loop()
```

这个 REPL 具备：
- Markdown 渲染 Agent 输出；
- 流式逐字追加，不闪屏；
- 输入框支持 history 和快捷键；
- 差量渲染只更新变化区域。

## 本章小结

- pi-tui 的差量渲染只重绘变更部分，避免传统 TUI 的闪烁；
- Box/VStack/HStack 组合可构建任意布局；
- Markdown + ScrollView 适合展示长文本输出；
- Keybindings + Kill Ring + Undo 提供完整编辑体验；
- CombinedAutocompleteProvider 支持多源模糊补全。
