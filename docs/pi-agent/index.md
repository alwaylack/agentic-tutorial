# Pi Agent 开发 · 课程导学

本课程共 **23 章**，基于 **@earendil-works/pi-agent-core** 与 **@earendil-works/pi-ai** 官方源码文档，用 TypeScript 从零构建生产级智能体。

## 你将学到什么

| 阶段 | 章节 | 内容 |
|---|---|---|
| 入门 | 01–05 | pi-ai 统一 LLM API、模型路由、第一个 Agent、事件流 |
| 进阶 | 06–10 | 工具定义与调用、消息转换、上下文变换、认证解析 |
| 高级 | 11–15 | 思考推理、图像、错误中止、自定义 Provider、测试 |
| 生产 | 16–20 | 跨提供商切换、会话持久化、浏览器使用、综合实战 |
| 扩展 | 21–23 | Telemetry 可观测性、pi-tui 终端 UI、三章贯穿式实战 |
