# Playwright Tutorial · Course Guide

This course is based on the **Playwright 1.6x Official Documentation (Python edition)**, covering **22 chapters** from zero foundation to a production-grade E2E testing system.

## What You Will Learn

| Stage | Chapters | Content |
|---|---|---|
| Beginner | 01–05 | Architecture, locators, auto-wait, Web-First assertions |
| Intermediate | 06–12 | pytest integration, iframe/popup, network mock, auth reuse, Trace, device emulation |
| Advanced | 13–18 | POM design pattern, parallel sharding, CI/Docker, API testing, async API |
| Production | 19–22 | Flaky治理, accessibility testing, WebSocket real-time apps, E2E strategy |

## How It Connects to Other Courses

- The pytest fixture usage from Chapter 6 onward seamlessly connects to the [pytest course](/pytest/);
- Chapter 18 complements the testing chapters of the [FastAPI course](/fastapi/) to form a complete web testing skill stack.
