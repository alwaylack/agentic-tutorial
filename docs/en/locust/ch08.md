# Chapter 8 · Event Hooks and Custom Statistics

> Chapter goals: master Locust's event system (events.request/test_start/test_stop, etc.), learn to inject custom metrics and listen to key nodes.

## 8.1 Event System Overview

Locust's event system is based on the `locust.events` module. You can register callback functions at different stages of the test:

```python
from locust import events

@events.test_start.add_listener
def on_test_start(environment, **kwargs):
    print("Load test started!")

@events.test_stop.add_listener
def on_test_stop(environment, **kwargs):
    print("Load test ended!")
```

Common events:

| Event | Trigger Time |
|---|---|
| `test_start` | Once at the start of the entire load test |
| `test_stop` | Once at the end of the load test |
| `request` | After each HTTP request completes |
| `worker_report` | When Worker reports to Master |
| `spawning_complete` | When all virtual users have started |

## 8.2 Listening to the request Event

The `request` event fires after each HTTP request completes, usable for custom logging, alerts, or statistics:

```python
from locust import events
import time

@events.request.add_listener
def on_request(request_type, name, response_time, response_length, exception, context, **kwargs):
    if exception:
        print(f"❌ {request_type} {name} failed: {exception}")
    elif response_time > 2000:  # Slow requests exceeding 2 seconds
        print(f"⚠️ Slow request {name}: {response_time:.0f}ms")
```

## 8.3 Custom Metric Reporting

Through `events.request.fire()`, you can incorporate non-HTTP operations into Locust's statistics system:

```python
from locust import HttpUser, task, between, events

class CustomMetricsUser(HttpUser):
    wait_time = between(1, 2)

    @task
    def process_data(self):
        start = time.time()
        # Execute some non-HTTP operations (e.g., database query)
        result = self.run_query()
        elapsed_ms = (time.time() - start) * 1000

        # Report as a custom request,纳入 Locust's response time charts
        events.request.fire(
            request_type="DB",
            name="SELECT users",
            response_time=elapsed_ms,
            response_length=len(str(result)),
            exception=None,
        )
```

## 8.4 Displaying Custom Data in the Web UI

```python
from locust import events
from locust.web import app
from flask import jsonify

custom_stats = {"errors": 0}

@events.request.add_listener
def track_errors(exception, **kwargs):
    if exception:
        custom_stats["errors"] += 1

@app.route("/custom-stats")
def custom_stats_endpoint():
    return jsonify(custom_stats)
```

Visit `http://localhost:8089/custom-stats` to get real-time data.

## Chapter Summary

- The `events` module provides hooks like test_start/test_stop/request;
- Through `events.request.fire()`, you can report custom metrics for non-HTTP operations;
- Combined with Flask routes, you can expose custom monitoring endpoints in the Web UI.
