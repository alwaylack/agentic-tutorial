## 19.1 Understanding Response Time Percentiles

The average response time is **the most misleading metric**—it gets diluted by大量快请求 (many fast requests), masking the impact of少数慢请求 (a few slow ones). Production-grade performance analysis must关注尾部延迟 (focus on tail latency):

```text
Response time distribution for 100 requests:

  p50 (median) = 120ms   ← half of users are faster than this
  p90          = 350ms   ← 90% of users are faster than this
  p95          = 500ms   ← 95% of users are faster than this (common SLA standard)
  p99          = 1200ms  ← the tail 1% of users may wait 1.2 seconds!
  Average      = 180ms   ← pulled down by大量快请求 (many fast requests), masking problems
```

::: warning Why Averages Lie
Assume 95 requests take 50ms and 5 requests take 2000ms:
- Average = (95×50 + 5×2000) / 100 = **147ms** ← looks acceptable
- p95 = **2000ms** ← exposes the real problem!

If your SLA is "99% of requests complete within 500ms," the average completely fails to反映真实情况 (reflect the true situation).
:::

### Locust Built-in Statistics解读 (Interpretation)

Key columns in the Locust Web UI and CSV reports:

| Column | Meaning | What to Watch |
|------|------|--------|
| Average | Mean response time | Reference value |
| Median (50%) | Median | Normal user experience |
| 95% | p95 | Common SLA threshold |
| 98% | p98 | High-requirement scenarios |

## 19.2 Prometheus + Grafana Integration

Locust supports pushing statistics to Prometheus via event hooks, enabling real-time monitoring and historical trend analysis.

### Method 1: locust-exporter (Recommended)

[locust-exporter](https://github.com/ContainerSolutions/locust-exporter) is an独立 Prometheus exporter (independent Prometheus exporter) that拉取数据 (pulls data) directly from the Locust master's API:

```yaml
# docker-compose.yml — one-command启动完整监控栈 (start complete monitoring stack)
version: "3.8"
services:
  locust:
    image: locustio/locust
    ports:
      - "8089:8089"
    volumes:
      - ./locustfile.py:/mnt/locust/locustfile.py
    command: -f /mnt/locust/locustfile.py --master

  exporter:
    image: containersol LOCust-exporter:latest
    ports:
      - "9101:9101"
    environment:
      - LOCUST_HOST=http://locust:8089

  prometheus:
    image: prom/prometheus
    ports:
      - "9090:9090"
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml

  grafana:
    image: grafana/grafana
    ports:
      - "3000:3000"
    environment:
      - GF_SECURITY_ADMIN_PASSWORD=admin
```

```yaml
# prometheus.yml
scrape_configs:
  - job_name: locust
    static_configs:
      - targets: ['exporter:9101']
```

访问 `http://localhost:3000` (login: admin/admin) 即可查看 Locust metrics.

### Method 2: Custom Event Hook

For轻量级场景 (lightweight scenarios),直接 push to Prometheus via the request event:

```python
from locust import events
from prometheus_client import Counter, Histogram
import time

request_count = Counter('locust_requests_total', 'Total requests', ['name', 'method'])
response_time_hist = Histogram('locust_response_time_seconds', 'Response time', ['name'])

@events.request.add_listener
def on_request(request_type, name, response_time, response_length, exception, **kwargs):
    request_count.labels(name=name, method=request_type).inc()
    if response_time:
        response_time_hist.labels(name=name).observe(response_time / 1000)
```

## 19.3 Systematically定位性能瓶颈 (Locating Performance Bottlenecks)

When RPS plateaus and response times spike, follow this checklist:

1. **Check the target server**: CPU, memory, disk I/O, network bandwidth
2. **Check数据库查询 (database queries)**: slow queries, missing indexes, connection pool exhaustion
3. **Check第三方依赖 (third-party dependencies)**: external API latency, rate limits
4. **Check Locust itself**: CPU warning? fd limit reached? Use `FastHttpUser` or `--processes`

```bash
# Check Locust machine resources during a test
top -o cpu        # CPU usage
vmstat 1          # Memory and I/O
iostat -x 1       # Disk I/O
ss -tn            # Network connections
```

## Chapter Summary

- p95/p99反映尾部延迟 (reflect tail latency); averages are misleading;
- Prometheus + Grafana via locust-exporter providesreal-time监控 (real-time monitoring) and历史趋势 (historical trends);
- When RPS plateaus, check targetserver resources first—don't blame the app prematurely;
- Always ensure the load-test machine has充足余量 (sufficient headroom).
