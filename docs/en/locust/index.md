# Locust Performance Testing · Course Guide

This course consists of **20 chapters**, based on the **Locust 2.46.x official documentation**, from zero foundation to distributed production-grade load testing.

## What You Will Learn

| Stage | Chapters | Content |
|---|---|---|
| Beginner | 01–05 | Performance testing fundamentals, HttpUser, task writing, Web UI, assertions |
| Intermediate | 06–10 | TaskSet nesting, event hooks, parameterization, distributed testing, Docker |
| Advanced | 11–15 | Kubernetes, non-HTTP protocols, asyncio, using as a library, plugins |
| Production | 16–20 | Performance tuning, CI/CD, monitoring and analysis, capstone project |
