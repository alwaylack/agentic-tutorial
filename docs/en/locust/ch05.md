# Chapter 5 · Web UI and Headless Mode

> Chapter goals: read the Web UI statistics indicators and charts; master all headless mode parameters; learn to save load test results using CSV and HTML reports.

## 5.1 Web UI Interface解读

After starting `locust`, visit `http://localhost:8089`. Core metrics are concentrated on the **Statistics** tab:

| Column | Meaning |
|---|---|
| Type | Request method (GET/POST) |
| Name | Request path (or group name specified by name parameter) |
| # Requests | Total completed requests |
| # Fails | Failure count (HTTP non-2xx or manual failure) |
| Median (ms) | Response time median |
| 95%ile / 99%ile | 95th/99th percentile response time |
| Average (min/max) | Average / minimum / maximum response time |
| Current RPS | Current requests per second |

The **Charts** tab has three real-time graphs: Total Requests per Second, Response Times (ms), and Number of Users.

::: warning How to Know When the System Has Hit a Bottleneck
When user count keeps increasing but the RPS curve flattens while response times spike sharply—the target system is saturated. If response times stay flat and RPS hasn't reached target, you need to keep applying more pressure.
:::

## 5.2 Headless Mode: Running Without a UI

CI pipelines have no browser. Use `--headless` to specify all parameters directly on the command line:

```bash
locust --headless \
    --users 50 \
    --spawn-rate 5 \
    --run-time 2m \
    -H https://httpbin.org
```

| Parameter | Abbreviation | Description |
|---|---|---|
| `--users` | `-u` | Peak concurrent user count |
| `--spawn-rate` | `-r` | User spawn rate (new users per second) |
| `--run-time` | `-t` | Run duration (e.g., `30s`, `2m`, `1h30m`) |
| `-H` / `--host` | — | Target host address |
| `--headless` | — | Do not start Web UI |

At the end of the run, the terminal prints the final statistics table:

```text
Type     Name           # reqs   # fails |  Avg   Min   Max  Median |  # reqs/sec
GET      /get              1500      0(0%)|  210   180   890    200 |      12.50
--------- ------------------------------------------------------------------------------
Aggregated                1500      0(0%)|  210   180   890    200 |      12.50
```

::: tip Adjust During Runtime
Even in headless mode you can add/remove users in real-time via keyboard: press `w` to add 1, `W` to add 10, `s` to remove 1, `S` to remove 10.
:::

## 5.3 CSV Output

Add one parameter to write full statistics to disk:

```bash
locust --headless --users 20 --run-time 1m \
    -H https://httpbin.org \
    --csv results/run_001
```

This automatically generates three files:

| File | Content |
|---|---|
| `results/run_001_stats.csv` | Final statistics table (one row per endpoint) |
| `results/run_001_stats_history.csv` | Time-sliced historical data (ideal for trend charts) |
| `results/run_001_failures.csv` | Details of all failed requests |

`stats_history.csv` is the most valuable file—you can use pandas or Excel to画 the RPS and response time变化曲线 over the entire test:

```python
import pandas as pd

df = pd.read_csv("results/run_001_stats_history.csv")
df.plot(x="Timestamp", y="Current RPS")
```

## 5.4 HTML Report

When you need to report results to the team, the HTML report is the most intuitive format:

```bash
locust --headless --users 50 --run-time 2m \
    -H https://httpbin.org \
    --html report_{u}u_{r}ps.html
```

The filename supports placeholders:

- `{u}` → concurrent user count
- `{r}` → spawn rate
- `{t}` → run duration

The generated single-file HTML contains complete statistics tables and interactive charts—send it directly to colleagues who don't have Python installed. The Web UI mode also has a **Download Report** button with identical output.

## Chapter Summary

- The Statistics table: focus on three columns to locate problems—# Fails, 95%ile, Current RPS;
- In Charts, "RPS flattens + response times spike" = target system saturation signal;
- Headless trio: `--users` + `--spawn-rate` + `--run-time`;
- `--csv` produces three files, with stats_history ideal for trends; `--html` generates a self-contained report with {u}/{r}/{t} placeholders.
