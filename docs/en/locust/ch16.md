## 16.1 locust-plugins: Officially Recommended Plugin Library

[locust-plugins](https://github.com/SvenskaSpel/locust-plugins) is a third-party extension library参与 (with participation from) Locust core maintainers (current version 5.x), providing a wealth of out-of-the-box enhancements:

```bash
pip install locust-plugins
```

| Module | Feature |
|--------|---------|
| `locust_plugins.users` | PlaywrightUser, SeleniumUser, KafkaUser, FtpUser, etc. |
| `locust_plugins.datasets` | Data pools (CSV/JSON-driven) |
| `locust_plugins.monitors` | Monitoring integration |
| `locust_plugins.listeners` | Timescale/Grafana reporting |

### Using PlaywrightUser for Browser-Level Load Testing

```python
# locustfile.py
from locust_plugins.users import PlaywrightUser


class BrowserUser(PlaywrightUser):
    tasks = [
        {
            "weight": 1,
            "task": lambda page: page.goto("https://example.com"),
            "name": "Visit homepage"
        },
        {
            "weight": 2,
            "task": lambda page: (
                page.goto("https://example.com/login"),
                page.fill("#username", "test"),
                page.fill("#password", "pass"),
                page.click("button[type=submit]")
            ),
            "name": "Login operation"
        }
    ]
```

::: tip Why Use PlaywrightUser
Traditional HttpUser only load-tests the HTTP layer,无法覆盖 (cannot cover) JavaScript rendering time and前端性能瓶颈 (front-end performance bottlenecks). PlaywrightUser launches a real browser to execute page operations, suitable for evaluating end-to-end user experience.
:::

### Using Data Pools for Parameterization

```python
from locust_plugins.datasets import load_csv_data


class ApiUser(HttpUser):
    # Load test data from CSV,循环使用 (loop reuse)
    dataset = load_csv_data("test_users.csv")

    def on_start(self):
        self.credentials = next(self.dataset)

    @task
    def login(self):
        self.client.post("/login", json=self.credentials)
```

## 16.2 Custom LoadTestShape

`LoadTestShape` lets you定义动态负载曲线 (define dynamic load curves)—not just固定的台阶 (fixed steps):

```python
from locust import LoadTestShape

class StagedLoadShape(LoadTestShape):
    """Three-stage load: warmup → peak → cooldown"""

    def tick(self):
        run_time = self.get_run_time()

        if run_time < 120:  # 前 2 分钟：10 用户
            return (10, 1)
        elif run_time < 300:  # 接下来 3 分钟：100 用户
            return (100, 10)
        elif run_time < 360:  # 最后 1 分钟：5 用户冷却
            return (5, 1)
        else:
            return None  # 终止测试
```

`tick()` 每秒被调用一次，返回 `(users, spawn_rate)`；返回 `None` 时测试终止。

## 16.3 Stepped Pressure Increase: Finding the Breaking Point

阶梯加压 (stepped pressure increase) is the standard method for定位系统容量拐点 (locating system capacity inflection points):

```python
class IncrementalShape(LoadTestShape):
    def tick(self):
        run_time = self.get_run_time()
        # 每 60 秒增加 20 用户，直到 200
        users = min(200, int(run_time / 60) * 20 + 20)
        if users >= 200 and run_time > 600:
            return None
        return (users, 20)
```

观察 RPS 曲线何时开始 plateau 而响应时间开始 spike——that 点就是系统容量极限。

## 16.4 Extending the Web UI

通过 `events.init` 可以添加自定义路由到 Locust 的内置 Flask app：

```python
from locust import events
from locust.web import app

@events.init.add_listener
def on_locust_init(environment, **kwargs):
    @app.route("/p99")
    def p99_endpoint():
        from flask import jsonify
        p99 = environment.runner.stats.total.get_response_time_percentile(0.99)
        return jsonify({"p99_ms": p99})
```

访问 `http://localhost:8089/p99` 即可获取实时 P99 数据。

## Chapter Summary

- `locust-plugins` provides PlaywrightUser, data pools, and other advanced capabilities;
- `LoadTestShape.tick()` controls dynamic load curves; return `None` to terminate the test;
- Stepped pressure increase is the standard method for定位系统容量拐点 (locating system capacity inflection points);
- Extend the Web UI via `events.init` to add自定义端点 (custom endpoints);
- Set `process_exit_code = 1` in `events.quitting`让 CI 正确判定压测失败 (let CI correctly judge load test failure).
