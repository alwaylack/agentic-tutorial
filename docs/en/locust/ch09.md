# Chapter 9 · Parameterization and Data-Driven Testing

> Chapter goals: learn to drive tests using environment variables, CSV/JSON files, and per-virtual-user independent data to avoid hardcoding.

## 9.1 Environment Variable Injection

The simplest parameterization method controls target address and concurrency parameters via environment variables:

```python
import os
from locust import HttpUser, task, between

class ApiUser(HttpUser):
    host = os.getenv("TARGET_HOST", "https://httpbin.org")
    wait_time = between(
        float(os.getenv("MIN_WAIT", "1")),
        float(os.getenv("MAX_WAIT", "3"))
    )

    @task
    def get_data(self):
        self.client.get("/get")
```

Override at runtime via environment variables:

```bash
TARGET_HOST=https://staging.example.com locust -f locustfile.py
```

## 9.2 CSV Data Loading

```python
import csv
from locust import HttpUser, task, between

# Load all test data at startup
with open("users.csv") as f:
    USERS = list(csv.DictReader(f))

class LoginUser(HttpUser):
    wait_time = between(1, 3)

    def on_start(self):
        # Each virtual user picks one account from the queue (avoid duplicate logins)
        self.user_data = USERS.pop() if USERS else {"username": "default", "password": "test"}

    @task
    def login_and_browse(self):
        self.client.post("/login", json=self.user_data)
        self.client.get("/dashboard")
```

## 9.3 JSON Configuration Files

```python
import json
from locust import HttpUser, task, between

with open("config.json") as f:
    config = json.load(f)

class ConfigurableUser(HttpUser):
    host = config["target_url"]
    wait_time = between(*config["wait_range"])

    @task
    def hit_endpoint(self):
        for ep in config["endpoints"]:
            self.client.get(ep)
```

## 9.4 Per-Virtual-User Independent Data

Use `queue.Queue` to ensure each virtual user gets unique test data:

```python
import queue
from locust import HttpUser, task, between

# Create data queue
data_queue = queue.Queue()
for i in range(1000):
    data_queue.put({"email": f"user{i}@test.com", "password": "pass123"})

class SignupUser(HttpUser):
    wait_time = between(0.5, 2)

    def on_start(self):
        if data_queue.empty():
            self.environment.runner.quit()  # stop test when data exhausted
        self.credentials = data_queue.get_nowait()

    @task
    def signup(self):
        self.client.post("/register", json=self.credentials)
        data_queue.task_done()
```

## Chapter Summary

- Environment variables are the lightest parameterization method, ideal for switching target environments;
- CSV/JSON files suit batch test data;
- `queue.Queue` ensures each virtual user gets unique data, auto-stopping when exhausted.
