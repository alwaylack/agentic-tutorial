# Pi Coding Agent Tutorial · Course Guide

This course is built from the **pi 0.8x official docs** (README + all 30+ docs/ articles), comprising **21 chapters** — from zero to building your own agent workflows.

Pi is a极简 terminal coding harness: the core does only "model + tools + sessions"; everything else (sub-agents, plan mode, themes, skills) is added on-demand via **TypeScript extensions / skills / prompt templates / package ecosystem** — "let pi适配 your workflow, not the other way around."

## What You Will Learn

| Phase | Chapters | Content |
|---|---|---|
| Getting Started | 01–04 | Philosophy & architecture, installation & quickstart, model config, interaction modes |
| Advanced | 05–09 | Session branching, context compaction, settings & project trust, prompt templates, skills |
| Expert | 10–15 | TypeScript extension development, custom tools, themes, package ecosystem, SDK, RPC |
| Production | 16–21 | CI automation, full CLI reference, security model, containerization, team workflows, multi-session collaboration (intercom/messenger) |
