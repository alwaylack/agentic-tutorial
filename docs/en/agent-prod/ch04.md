## 4.1 Why We Need LangGraph

LangChain agents  provide开箱 that is用 of架构（ such as ReAct、Plan-and-Execute)，但缺乏对execute流程 of精细控制。LangGraph 填补了 this空白：

> LangGraph  is a低层级编排框架和运行时，用于build、管理和部署长期运行 ofstate化 Agent。它允许你 will确定性逻辑and LLM 驱动 of决策混合in同 a图中。

核心差异：

| 特性 | LangChain Agents | LangGraph |
|---|---|---|
| 抽象层级 | advanced | 低层级 |
| flow control | black-box loop | explicit graph structure |
| state持久化 | limited | built-in Checkpointer |
| Human-in-the-loop | not supported | native support |
| 调试 | difficult | LangSmith visualization |

## 4.2 最小 Hello World

```python
from langgraph.graph import StateGraph, MessagesState, START, END

# 定义node：simple LLM call
def mock_llm(state: MessagesState) -> dict:
    return {
        "messages": [
            {"role": "assistant", "content": "Hello from LangGraph!"}
        ]
    }

# build图
graph = StateGraph(MessagesState)
graph.add_node("llm", mock_llm)
graph.add_edge(START, "llm")
graph.add_edge("llm", END)
compiled = graph.compile()

# execute
result = compiled.invoke({
    "messages": [{"role": "user", "content": "hi!"}]
})
print(result["messages"][-1]["content"])
```

## 4.3 StateGraph core concepts

```python
from langgraph.graph import StateGraph, MessagesState, START, END
from typing import TypedDict

# custom state：in MessagesState add on top of metadata
class AgentState(MessagesState):
    context: list[str]  # retrieved context
    step_count: int     # executed step count
    final_answer: str   # final answer

# each node function
def search_node(state: AgentState) -> dict:
    """retrieve related documents"""
    return {
        "context": ["文档A内容", "文档B内容"],
        "step_count": state.get("step_count", 0) + 1
    }

def llm_node(state: AgentState) -> dict:
    """call LLM to generate answer"""
    context = " ".join(state.get("context", []))
    return {
        "messages": [{"role": "assistant", "content": f"based on context: {context}"}],
        "step_count": state["step_count"] + 1
    }

# build图
workflow = StateGraph(AgentState)
workflow.add_node("search", search_node)
workflow.add_node("llm", llm_node)
workflow.add_edge(START, "search")
workflow.add_edge("search", "llm")
workflow.add_edge("llm", END)

graph = workflow.compile()
```

## 4.4 Relationship with LangChain Agents

```python
# LangGraph can be used with LangChain 组件combined use
from langchain.chat_models import ChatOpenAI
from langchain.tools import tool

@tool
def get_weather(city: str) -> str:
    """获取城市天气"""
    return f"{city} 今天晴朗，25°C"

# use LangChain 的 LLM + LangGraph 的图编排
llm = ChatOpenAI(model="gpt-4o-mini")
# ... 将 LLM call封装为图node
```

## 4.5 Compile and Execute Modes

```python
# synchronous execution
result = graph.invoke({"messages": [...]})

# streaming execution（see Chapter 8)
for event in graph.stream({"messages": [...]}):
    print(event)

# asynchronous execution
async_result = await graph.ainvoke({"messages": [...]})
```

## 本章Summary

- LangGraph is a low-level orchestration runtime providing fine-grained graph structure control
- `StateGraph` + `MessagesState`  is最小起步单元
- custom state继承 `MessagesState` 并扩展field
- Can be mixed with LangChain components
