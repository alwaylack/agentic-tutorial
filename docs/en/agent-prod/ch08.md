## 8.1 stream() Basics

```python
from langgraph.graph import StateGraph, MessagesState, START, END

# Use stream instead of invoke
for event in graph.stream(
    {"messages": [HumanMessage("Hello")]},
    stream_mode="values"
):
    print(event["messages"][-1].content)
```

### 8.1.1 Stream Modes

| Mode | Description |
|---|---|
| `"values"` | Full state after each node |
| `"messages"` | Only message updates |
| `"updates"` | Node outputs only |
| `"debug"` | Detailed execution info |

## 8.2 Streaming Token by Token

```python
async for event in graph.astream(
    {"messages": [HumanMessage("Tell me a story")]},
    stream_mode="messages"
):
    msg, metadata = event
    if metadata.get("langgraph_node") == "agent":
        print(msg.content, end="", flush=True)
```

## 8.3 Interrupt Recovery

Resume from interrupted state:

```python
# First invocation - will interrupt
try:
    result = graph.invoke(input, config)
except InterruptedError as e:
    # Save checkpoint_id for later resume
    saved_config = e.config
```

### 8.3.1 Resume with Input

```python
# Later, provide human input
result = graph.invoke(
    {"approval": True, "feedback": "Good, but add more details"},
    config=saved_config
)
```

## 8.4 Approval Workflow

```python
def review_node(state: AgentState) -> dict:
    # Check if review needed
    if needs_review(state):
        # Interrupt for human approval
        review = interrupt({
            "question": "Review this response?",
            "content": state["messages"][-1].content
        })
        
        if not review.get("approved"):
            return {"revision_needed": True}
    
    return {"approved": True}
```

## Chapter Summary

1. **stream() vs invoke()**: stream() returns updates incrementally;
2. **Stream Modes**: values, messages, updates, debug;
3. **Token Streaming**: Use astream with messages mode for real-time output;
4. **Interrupt Recovery**: Save checkpoint and resume with human input;
5. **Approval Workflow**: interrupt() pauses for human review.
