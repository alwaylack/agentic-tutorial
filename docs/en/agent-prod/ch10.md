## 10.1 Skills System

Skills are reusable Agent capabilities and instructions:

```markdown
<!-- .deepagents/skills/researcher/AGENTS.md -->
---
name: researcher
description: Research topics and generate comprehensive reports
model: anthropic:claude-haiku-4-5-20251001
tools: [search, read_file, write_file]
---

# Researcher Skill

You are an expert researcher. Your workflow:

1. **Search**: Use search tool to find relevant information
2. **Read**: Read documents and extract key points
3. **Synthesize**: Combine findings into coherent analysis
4. **Write**: Generate structured report

## Output Format
- Executive summary (1 paragraph)
- Key findings (bullet points)
- Sources cited
- Recommendations
```

### 10.1.1 Skill Composition

```python
from deepagents import Skill, create_deep_agent

# Define skill programmatically
researcher = Skill(
    name="researcher",
    description="Research and analyze topics",
    model="claude-haiku",
    tools=["search", "read", "write"]
)

# Load from file
skill = Skill.from_file(".deepagents/skills/researcher/AGENTS.md")
```

## 10.2 Memory System

### 10.2.1 Short-term Memory

Conversation context within a session:

```python
agent = create_deep_agent(
    memory="short_term",
    memory_config={
        "type": "window",
        "window_size": 10,  # Last 10 messages
        "summary_threshold": 5  # Summarize after 5 exchanges
    }
)
```

**Behavior**:
- Keeps last N messages in context
- Automatically summarizes older conversations
- Session-bound (lost on restart unless persisted)

### 10.2.2 Long-term Memory

Persistent memory across sessions:

```python
agent = create_deep_agent(
    memory="long_term",
    memory_config={
        "type": "vector_store",
        "store": "chroma",
        "collection": "agent_memory",
        "embedding_model": "text-embedding-3-small"
    }
)
```

**Behavior**:
- Stores facts, preferences, and insights
- Semantic search for relevant memories
- Survives across sessions and restarts

### 10.2.3 Memory Comparison

| Feature | Short-term | Long-term |
|---|---|---|
| Duration | Session-only | Persistent |
| Capacity | Limited (window) | Unlimited |
| Search | Exact match | Semantic |
| Use Case | Context continuity | User profiling |

## 10.3 Approval Modes

### 10.3.1 Manual Mode

Every tool call requires human approval:

```python
agent = create_deep_agent(
    approval_mode="manual",
    approval_callback=lambda tool_call: input(f"Approve {tool_call.name}? (y/n): ") == 'y'
)
```

**Use Case**: Sensitive operations, production deployment, compliance requirements.

### 10.3.2 Auto Mode

Auto-approve safe operations, prompt for risky ones:

```python
agent = create_deep_agent(
    approval_mode="auto",
    safe_tools=["read_file", "search", "calculate"],
    risky_tools=["write_file", "execute_code", "send_email"]
)
```

**Use Case**: Balance between autonomy and safety.

### 10.3.3 YOLO Mode

No approval required, maximum autonomy:

```python
agent = create_deep_agent(
    approval_mode="yolo"
)
```

**Use Case**: Development, testing, trusted environments.

## 10.4 Remote Code Sandbox

Execute Agent code in isolated sandbox:

```python
from deepagents.sandbox import E2BSandbox, ModalSandbox

# E2B Sandbox
agent = create_deep_agent(
    sandbox=E2BSandbox(api_key="e2b_...")
)

# Modal Sandbox
agent = create_deep_agent(
    sandbox=ModalSandbox(api_key="modal_...")
)
```

### 10.4.1 Sandbox Benefits

- Isolated execution environment
- Resource limits (CPU, memory, time)
- No access to host system
- Audit trail of executions
