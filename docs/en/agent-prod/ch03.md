## 3.1 distributedlockpreventduplicate

多个 Celery Worker 同时同时可能出现被多个 Worker 抢走情况 Redis `SET NX EX` Implementatomicitymutual exclusionlock

```python
# services/agent/redis_lock.py
import redis
import uuid
from contextlib import contextmanager

r = redis.from_url("redis://redis:6379/0")


@contextmanager
def distributed_lock(lock_name: str, ttl: int = 30):
    """
    用 Redis SET NX EX Implement可重入distributedlock。

    - NX：键不存在才设置（mutual exclusion）
    - EX：过期时间（prevent Worker 崩溃后lock永不过期）
    - unique token：保证只有持lock者能释放lock
    """
    token = str(uuid.uuid4())
    acquired = r.set(lock_name, token, nx=True, ex=ttl)
    if not acquired:
        raise RuntimeError(f"无法获取lock: {lock_name}")
    try:
        yield
    finally:
        # Lua 脚本保证「检查 token + 删除」的atomicity
        lua = """
        if redis.call("get", KEYS[1]) == ARGV[1] then
            return redis.call("del", KEYS[1])
        else
            return 0
        end
        """
        r.eval(lua, 1, lock_name, token)
```

## 3.2 idempotency设计unique ID deduplication

distributed环境下可能重复投递网络抖动、Worker 解决方案

1. **生成unique _id**UUID v7含timestamp可sort
2. **开始前查deduplication表**已则直接cache结果
3. **写入结果表**

```python
# services/agent/idempotency.py
import uuid
from datetime import datetime
import redis

r = redis.from_url("redis://redis:6379/0")


def generate_task_id() -> str:
    """生成 UUID v7，便于时间sort和index。"""
    return str(uuid.uuid7())


def check_duplicate(task_id: str) -> bool:
    """
    检查 task_id 是否已被processed。
    Redis SET NX 原子操作：首次返回 True（未处理），重复返回 False。
    """
    key = f"idempotent:{task_id}"
    return bool(r.set(key, "1", nx=True, ex=3600))  # 1 小时过期


def cache_result(task_id: str, result: dict) -> None:
    """cache任务结果，供重复请求直接返回。"""
    r.setex(f"result:{task_id}", 300, str(result))  # 5 分钟 TTL
```

```python
# services/agent/tasks.py
from .idempotency import generate_task_id, check_duplicate, cache_result


@shared_task
def handle_agent_request(user_input: str):
    task_id = generate_task_id()

    if not check_duplicate(task_id):
        return {"task_id": task_id, "status": "duplicate", "note": "任务已处理"}

    # 执行 Agent 逻辑...
    result = {"response": "Agent 输出...", "task_id": task_id}
    cache_result(task_id, result)
    return result
```

## 3.3 Docker 多stage构建optimize Python image

Python image默认带完整 GCC development headersvolume可达 1GB多stage构建大幅缩小

```dockerfile
# services/agent/Dockerfile
FROM python:3.12-slim AS base

# stage 1：安装系统dependency
FROM base AS builder
RUN apt-get update && apt-get install -y --no-install-recommends \
    gcc libpq-dev && \
    rm -rf /var/lib/apt/lists/*

# 复制dependency文件并安装 Python 包
COPY requirements.txt .
RUN pip install --no-cache-dir --prefix=/install -r requirements.txt

# stage 2：minimalfinalimage
FROM base
WORKDIR /app
COPY --from=builder /install /usr/local
COPY . .

# non-root 用户运行
RUN useradd -m agentuser && chown -R agentuser /app
USER agentuser

EXPOSE 8000
CMD ["uvicorn", "services.agent.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

**关键optimize点**

| optimize项 | 效果 |
|---|---|
| `python:3.12-slim` | image 1GB 降到 ~150MB |
| `--no-install-recommends` | avoid必推荐包 |
| `--no-cache-dir` | pip cachewheel减少imagevolume |
| non-root 户 | securitybest practicepreventcontainer escape |

```yaml

    build:
      context: .
      dockerfile: services/agent/Dockerfile

      - "8000:8000"

      timeout: 10s

      context: .
      dockerfile: services/agent/Dockerfile
```

## 3.5 health checkgraceful shutdown

### Fast 健康endpoint

```python
# services/agent/main.py
from fastapi import FastAPI
from redis import Redis
import psycopg2

app = FastAPI()


@app.get("/health")
async def health_check():
    checks = {}

    # Redis connectivity
    try:
        r = Redis.from_url("redis://redis:6379/0")
        checks["redis"] = r.ping()
    except Exception as e:
        checks["redis"] = False

    # Postgres connectivity
    try:
        conn = psycopg2.connect("postgresql://agent:agent@postgres:5432/agentdb")
        conn.close()
        checks["postgres"] = True
    except Exception:
        checks["postgres"] = False

    healthy = all(checks.values())
    status_code = 200 if healthy else 503
    return {"status": "healthy" if healthy else "unhealthy", "checks": checks}, status_code
```

### Celery Worker graceful shutdown

```python
# services/agent/celery_app.py
from celery import Celery
import signal
import sys

app = Celery("agent", broker="redis://redis:6379/1")
app.conf.update(
    task_serializer="json",
    result_serializer="json",
    accept_content=["json"],
    timezone="UTC",
    enable_utc=True,
)


def graceful_shutdown(signum, frame):
    print("收到退出signal，completecurrent任务后stop...")
    sys.exit(0)


signal.signal(signal.SIGTERM, graceful_shutdown)
signal.signal(signal.SIGINT, graceful_shutdown)
```
