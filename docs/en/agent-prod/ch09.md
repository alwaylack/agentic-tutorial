## 9.1 What is Deep Agents?

Deep Agents is an Agent Harness provided by LangChain, offering on top of LangGraph:
- Simplified API (create Agent in one line of code)
- Built-in context management
- Filesystem tools
- Sub-agent support
- Memory system

> Comparison: LangGraph is Runtime, Deep Agents is Harness (Harness layer)

## 9.2 Quick Start

```python
from deepagents import create_deep_agent

# Create agent with one line
agent = create_deep_agent(
    model="gpt-4o",
    tools=["search", "code", "filesystem"],
    memory=True
)

# Run agent
result = agent.run("Research and summarize this topic")
```

### 9.2.1 Provider Configuration

```python
from deepagents import create_deep_agent
from deepagents.providers import OpenAIProvider, AnthropicProvider, GoogleProvider

# Multiple providers
agent = create_deep_agent(
    providers=[
        OpenAIProvider(api_key="sk-..."),
        AnthropicProvider(api_key="sk-ant-..."),
        GoogleProvider(api_key="AIza..."),
    ],
    default_provider="openai"
)
```

## 9.3 Skills System

Skills are reusable Agent capabilities and instructions:

```markdown
<!-- .deepagents/skills/researcher/AGENTS.md -->
---
name: researcher
description: Research topics and generate reports
model: anthropic:claude-haiku-4-5-20251001
---

You are a research assistant. Your tasks:
1. Search for relevant information
2. Synthesize findings
3. Generate structured report
```

### 9.3.1 Loading Skills

```python
from deepagents import load_skills

skills = load_skills(".deepagents/skills/")
agent = create_deep_agent(skills=skills)
```

## 9.4 Memory System

### 9.4.1 Short-term Memory

Conversation history within a session:

```python
agent = create_deep_agent(
    memory="short_term",  # Last N messages
    memory_window=10
)
```

### 9.4.2 Long-term Memory

Persistent memory across sessions:

```python
agent = create_deep_agent(
    memory="long_term",
    memory_store="sqlite:///memory.db"
)
```

---

## 9.5 Approval Modes

Three approval modes for human-in-the-loop:

| Mode | Behavior |
|---|---|
| `Manual` | Every tool call requires approval |
| `Auto` | Auto-approve safe operations |
| `YOLO` | No approval, maximum autonomy |

```python
agent = create_deep_agent(
    approval_mode="manual",  # or "auto" or "yolo"
    allowed_tools=["read_file", "search"]
)
```
