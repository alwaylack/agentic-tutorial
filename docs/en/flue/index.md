# Flue · Course Guide

This course spans **19 chapters**, based on the **Flue official documentation and repository**, mastering the open-source Agent Harness framework by the Astro team.

## What You Will Learn

| Stage | Chapters | Content |
|---|---|---|
| Getting Started | 01–05 | Harness philosophy, project scaffold, 'use agent' functions, model config, sessions |
| Intermediate | 06–11 | Tools, Skills, MCP integration, Subagents, Channels, Sandboxes |
| Advanced | 12–16 | Durability, Observability, CLI & local run, Node.js deployment, CI & hosting |
| Production Practice | 17–19 | Three capstones: GitHub triage Agent, Slack on-call Assistant (with framework comparison), Code review Agent |

## Prerequisites

- TypeScript / Node.js basics;
- Node.js ≥ 22.19.0;
- At least one LLM provider API key (Anthropic / OpenAI / DeepSeek compatible).
