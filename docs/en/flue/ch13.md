# Chapter 13 · Observability

> Chapter goals: Distinguish Flue's two event surfaces, learn to subscribe to runtime events with `observe()`, read token usage, and export telemetry to OpenTelemetry, Sentry, and Braintrust.

## 13.1 Two Event Surfaces

Flue exposes "what the agent did" as **typed runtime events**: model turns, tool calls, structured logs, compaction, settlement. Note that this is **a different surface** from the chat UI's message stream:

```text
① Runtime event surface (this chapter): subscribe via observe(); for ops and debugging
② Session message surface: Routing + Flue Agent SDK; for chat interface逐条 messages
```

```typescript
// Ops-oriented event subscription: observe()
import { observe } from '@flue/runtime';

const stop = observe((event) => {
  // Each event is a discriminated union type; handle with switch
  switch (event.type) {
    case 'model_turn':
      console.log('[model]', event.model, 'tokens:', event.usage);
      break;
    case 'tool_call':
      console.log('[tool]', event.name, 'latency:', event.durationMs, 'ms');
      break;
    case 'log':
      console.log('[log ]', event.level, event.message);
      break;
  }
});

// Stop subscribing when no longer needed
// stop();
```

## 13.2 What's in the Event Stream

Model turn events自带 **token usage and provider diagnostic info** — this is the raw data source for cost monitoring:

```typescript
// Cost stats: aggregate model_turn event usage
import { observe } from '@flue/runtime';

const usageByDay = new Map<string, { input: number; output: number }>();

observe((event) => {
  if (event.type !== 'model_turn') return;
  const day = new Date().toISOString().slice(0, 10); // Aggregate by day
  const cur = usageByDay.get(day) ?? { input: 0, output: 0 };
  usageByDay.set(day, {
    input: cur.input + (event.usage?.inputTokens ?? 0),
    output: cur.output + (event.usage?.outputTokens ?? 0),
  });
});

// Print usage report hourly
setInterval(() => {
  for (const [day, u] of usageByDay) {
    console.log(day, 'input:', u.input, 'output:', u.output);
  }
}, 60 * 60 * 1000);
```

## 13.3 Exporting to OpenTelemetry

`@flue/opentelemetry` converts runtime events to OTel trace/spans, connecting to any compatible backend (Jaeger, Grafana Tempo etc.):

```bash
npm install @flue/opentelemetry @opentelemetry/sdk-node @opentelemetry/exporter-trace-otlp-http
```

```typescript
// src/otel.ts
// OpenTelemetry export adapter
import { flueOtel } from '@flue/opentelemetry';
import { NodeSDK } from '@opentelemetry/sdk-node';
import { OTLPTraceExporter } from '@opentelemetry/exporter-trace-otlp-http';

const sdk = new NodeSDK({
  // Flue-provided adapter maps agent activity to spans
  traceExporter: new OTLPTraceExporter({
    url: process.env.OTEL_EXPORTER_OTLP_ENDPOINT, // e.g. http://localhost:4318/v1/traces
  }),
});

// Register the Flue events → OTel bridge
flueOtel({ sdk });
sdk.start();
```

## 13.4 Sentry and Braintrust

Two ready-made integrations cover "error tracking" and "LLM evaluation" needs:

```typescript
// Sentry: send agent exceptions and context into error tracking
import * as Sentry from '@sentry/node';
import { observe } from '@flue/runtime';

Sentry.init({ dsn: process.env.SENTRY_DSN });

observe((event) => {
  if (event.type === 'error') {
    Sentry.captureException(event.error, {
      tags: { agent: event.agentId },
      contexts: { flue: { event: event.type } },
    });
  }
});
```

```typescript
// Braintrust: export eval data for LLM evaluation tracking
import { braintrustExporter } from '@flue/braintrust';

braintrustExporter({
  apiKey: process.env.BRAINTRUST_API_KEY,
  projectName: 'my-flue-agent',
});
```

## 13.5 Chapter Summary

- Flue exposes two event surfaces: runtime events (observe()) and session messages (SDK routing);
- `observe()` subscribes to typed events: model_turn, tool_call, log, error, compaction, settlement;
- Model turn events自带 token usage — the raw source for cost monitoring;
- `@flue/opentelemetry` bridges to Jaeger/Grafana Tempo; `@sentry/node` for error tracking; `@flue/braintrust` for LLM eval tracking.
