# Mastra · Course Guide

This course spans **21 chapters**, based on the **Mastra official documentation and repository**, covering TypeScript full-stack AI application frameworks.

## What You Will Learn

| Stage | Chapters | Content |
|---|---|---|
| Getting Started | 01–06 | Project scaffold, Studio, model routing, Agent, tools |
| Intermediate | 07–13 | Workflow graph engine, Suspend/Resume, Memory, RAG, Storage |
| Advanced | 14–17 | MCP Server, Evals, observability, frontend integration |
| Production | 18–21 | Standalone deployment & server-side · Three capstones: production-grade smart customer service / full-stack AI app / data Q&A BI Agent |
