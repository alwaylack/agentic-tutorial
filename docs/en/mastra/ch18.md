# Chapter 18 · Standalone Deployment and Server-Side

> Chapter goals: Master Mastra's three deployment shapes — dev server, Node standalone, and Serverless — and understand the storage and state considerations for each.

## 18.1 Three Runtime Shapes

| Shape | Command / Method | Use Case |
|---|---|---|
| Dev | `mastra dev` | Local development,自带 Studio (default :4111) |
| Node standalone | `node dist/index.mjs` | Self-managed server / Docker, full features |
| Serverless | Vercel / Vercel-like platforms | Elastic scaling; watch for statefulcapabilities |

## 18.3 Node Standalone Deployment (Docker)

```dockerfile
# Dockerfile
FROM node:22-slim AS build
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build        # Produces dist/

FROM node:22-slim
WORKDIR /app
COPY --from=build /app ./
EXPOSE 4111
CMD ["node", "dist/index.mjs"]
```

## 18.4 Serverless Considerations

Serverless functions have no local disk and may freeze-restart at any time, so:

1. **Storage must be external** — LibSQL cloud (Turso) or Postgres;
2. **Suspend/resume depends on snapshots** — the persistence config from Chapter 13 is mandatory here;
3. **Background proxies are受限** — Observational Memory's background tasks are unreliable in short-lived functions;
4. **Cold starts** — lazy-load agents on demand; avoid pulling the full model目录 at init.

## 18.5 Production Entry and Env Validation

Fail-fast on startup to avoid deploying with missing config:

```typescript
// src/env.ts —— refuse to start if key vars are missing
const required = ['LIBSQL_URL', 'LIBSQL_AUTH_TOKEN', 'OPENAI_API_KEY'] as const
for (const key of required) {
  if (!process.env[key]) {
    console.error(`Missing env var: ${key}`)
    process.exit(1)
  }
}
export const env = { LIBSQL_URL: process.env.LIBSQL_URL! }
```

```typescript
// src/server.ts —— explicitly specify listen port and host
import { createServer } from 'node:http'
import { mastra } from './mastra'
import './env'

const port = Number(process.env.PORT ?? 4111)
createServer(mastra.getServerHandler?.() ?? undefined)
console.log(`Mastra service started: http://0.0.0.0:${port}`)
```

## 18.7 Chapter Summary

- Three shapes: dev (mastra dev), Node standalone (node dist/index.mjs), Serverless (Vercel etc.);
- Never use local file: databases in containers — use Postgres/Turso;
- Serverless requires external storage, explicit suspend/resume persistence, and lazy agent loading;
- Fail-fast env validation + smoke测试 before going live.
