## 2.1 Downloading and Running an LLM

The first step is to load the model onto the GPU for faster inference. Note that we load the model and tokenizer separately and keep them independent so they can be explored separately later.

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

# Load model and tokenizer
model = AutoModelForCausalLM.from_pretrained(
    "microsoft/Phi-3-mini-4k-instruct",
    device_map="cuda",
    torch_dtype="auto",
    trust_remote_code=False,
)
tokenizer = AutoTokenizer.from_pretrained("microsoft/Phi-3-mini-4k-instruct")
```

Below, run a full generation with an apology-email prompt:

```python
prompt = "Write an email apologizing to Sarah for the tragic gardening mishap. Explain how it happened.<|assistant|>"

# Tokenize the input prompt
input_ids = tokenizer(prompt, return_tensors="pt").input_ids.to("cuda")

# Generate the text
generation_output = model.generate(
  input_ids=input_ids,
  max_new_tokens=20
)

# Print the output
print(tokenizer.decode(generation_output[0]))
```

Examine the tokenized `input_ids`:

Decode each token ID one by one and observe how the text is split:



## 2.3 Comparing Tokenizers Trained on Different LLMs

Different models use different tokenizers, and the splitting granularity varies enormously. Define a visualization function that prints each token with a colored background:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

colors_list = [
    '102;194;165', '252;141;98', '141;160;203',
    '231;138;195', '166;216;84', '255;217;47'
]

def show_tokens(sentence, tokenizer_name):
    tokenizer = AutoTokenizer.from_pretrained(tokenizer_name)
    token_ids = tokenizer(sentence).input_ids
    for idx, t in enumerate(token_ids):
        print(
            f'\x1b[0;30;48;2;{colors_list[idx % len(colors_list)]}m' +
            tokenizer.decode(t) +
            '\x1b[0m',
            end=' '
        )
```

## 2.4 Contextual Word Embeddings from Language Models (BERT-Style Models as an Example)

Embeddings produced by language models are **contextual**—the same word has different vectors in different sentences. Here we demonstrate with DeBERTa:

```python
from transformers import AutoModel, AutoTokenizer

# Load a tokenizer
tokenizer = AutoTokenizer.from_pretrained("microsoft/deberta-base")

# Load a language model
model = AutoModel.from_pretrained("microsoft/deberta-v3-xsmall")

# Tokenize the sentence
tokens = tokenizer('Hello world', return_tensors='pt')

# Process the tokens
output = model(**tokens)[0]
```

Inspect the shape of the output tensor:

```python
output.shape
```

Break down the input to see each token:

```python
for token in tokens['input_ids'][0]:
    print(tokenizer.decode(token))
```

The complete output tensor (one contextual vector per token):

```python
output
```

## 2.5 Text Embeddings (for Sentences and Full Documents)

To generate a fixed-length vector for an entire sentence or document, `sentence-transformers` is the most commonly used tool:

```python

# Load model
model = SentenceTransformer('sentence-transformers/all-mpnet-base-v2')

# Convert text to text embeddings
vector = model.encode("Best movie ever!")
```

## 2.7 Song Recommendation Using Embeddings

Finally, a complete application: train Word2Vec on playlist data to recommend similar songs. First download and parse the dataset:

```python
import pandas as pd
from urllib import request

# Get the playlist dataset file
data = request.urlopen('https://storage.googleapis.com/maps-premium/dataset/yes_complete/train.txt')

# Parse the playlist dataset file. Skip the first two lines as
# they only contain metadata
lines = data.read().decode("utf-8").split('\n')[2:]

# Remove playlists with only one song
playlists = [s.rstrip().split() for s in lines if len(s.split()) > 1]

# Load song metadata
songs_file = request.urlopen('https://storage.googleapis.com/maps-premium/dataset/yes_complete/song_hash.txt')
songs_file = songs_file.read().decode("utf-8").split('\n')
songs = [s.rstrip().split('\t') for s in songs_file]
songs_df = pd.DataFrame(data=songs, columns = ['id', 'title', 'artist'])
songs_df = songs_df.set_index('id')
```

Look at the contents of the first two playlists:

```python
print( 'Playlist #1:\n ', playlists[0], '\n')
print( 'Playlist #2:\n ', playlists[1])
```

Each playlist is treated as a "sentence", and the song IDs within it are like "words"; train Word2Vec on this basis:

```python
from gensim.models import Word2Vec

# Train our Word2Vec model
model = Word2Vec(
    playlists, vector_size=32, window=20, negative=50, min_count=1, workers=4
)
```

Ask the model for songs similar to song #2172:

```python
song_id = 2172

# Ask the model for songs similar to song #2172
model.wv.most_similar(positive=str(song_id))
```

Look up the metadata for this song:

```python
print(songs_df.iloc[2172])
```

Wrap a recommendation function to output a list with song titles:

```python
import numpy as np

def print_recommendations(song_id):
    similar_songs = np.array(
        model.wv.most_similar(positive=str(song_id),topn=5)
    )[:,0]
    return  songs_df.iloc[similar_songs]

# Extract recommendations
print_recommendations(2172)
```

Try a few different seed songs:

```python

```

## 2.8 Chapter Summary

- Text is first tokenized into tokens and then mapped to token IDs; `tokenizer(prompt).input_ids` yields the ID sequence, and `tokenizer.decode` reverses the process;
- Decoding a single token and decoding a combination are not always equivalent: `decode([3323, 622])` may differ from decoding each individually and concatenating;
- Different models' tokenizers have vastly different splitting granularities (`bert-base-uncased`, `gpt2`, `Xenova/gpt-4`, Phi-3, etc.), which directly affects sequence length and computational cost;
- BERT-style models output **contextual** word embeddings; `sentence-transformers` outputs sentence-level fixed-length vectors;
- Static word embeddings (GloVe/Word2Vec), though not LLM products, can still support practical applications such as the "king ≈ queen" analogy and song recommendation.
