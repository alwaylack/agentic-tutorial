## 11.3 Supervised Classification

### 11.3.1 HuggingFace Trainer

First load the `bert-base-cased` model and its tokenizer; `num_labels=2` indicates this is a binary classification task:

```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification

# Load Model and Tokenizer
model_id = "bert-base-cased"
model = AutoModelForSequenceClassification.from_pretrained(model_id, num_labels=2)
tokenizer = AutoTokenizer.from_pretrained(model_id)
```

Tokenize the data. To keep sequence lengths consistent within each batch, we use `DataCollatorWithPadding` to dynamically pad to the longest sequence in the batch:

```python
from transformers import DataCollatorWithPadding

# Pad to the longest sequence in the batch
data_collator = DataCollatorWithPadding(tokenizer=tokenizer)

def preprocess_function(examples):
   """Tokenize input data"""
   return tokenizer(examples["text"], truncation=True)

# Tokenize train/test data
tokenized_train = train_data.map(preprocess_function, batched=True)
tokenized_test = test_data.map(preprocess_function, batched=True)
```

Define the evaluation metric — here we use the F1 score:

```python
import numpy as np
import evaluate


def compute_metrics(eval_pred):
    """Calculate F1 score"""
    logits, labels = eval_pred
    predictions = np.argmax(logits, axis=-1)

    load_f1 = evaluate.load("f1")
    f1 = load_f1.compute(predictions=predictions, references=labels)["f1"]
    return {"f1": f1}
```

Configure training arguments and build the Trainer to execute the training process:

```python
from transformers import TrainingArguments, Trainer

# Training arguments for parameter tuning
training_args = TrainingArguments(
   "model",
   learning_rate=2e-5,
   per_device_train_batch_size=16,
   per_device_eval_batch_size=16,
   num_train_epochs=1,
   weight_decay=0.01,
   save_strategy="epoch",
   report_to="none"
)

# Trainer which executes the training process
trainer = Trainer(
   model=model,
   args=training_args,
   train_dataset=tokenized_train,
   eval_dataset=tokenized_test,
   tokenizer=tokenizer,
   data_collator=data_collator,
   compute_metrics=compute_metrics,
)

```

Start training:

```python
trainer.train()
```

Evaluate results:

```python
trainer.evaluate()
```

### 11.3.2 Freezing All Layers Except the Classification Head

Full fine-tuning is expensive; a more economical approach is to train only the classification head while freezing the encoder backbone. First reload the model, then print all parameter names to inspect the structure:

```python
# Load Model and Tokenizer
model = AutoModelForSequenceClassification.from_pretrained(model_id, num_labels=2)
tokenizer = AutoTokenizer.from_pretrained(model_id)
```

```python
# Print layer names
for name, param in model.named_parameters():
    print(name)
```

Parameters starting with `classifier` belong to the classification head — keep them trainable; freeze everything else:

```python
for name, param in model.named_parameters():

     # Trainable classification head
     if name.startswith("classifier"):
        param.requires_grad = True

      # Freeze everything else
     else:
        param.requires_grad = False
```

Check whether the model was updated correctly:

```python
# We can check whether the model was correctly updated
for name, param in model.named_parameters():
     print(f"Parameter: {name} ----- {param.requires_grad}")
```

Rerun training and evaluation with the same configuration as before:

### 11.3.3 Freezing Encoder Blocks 1–5

A step beyond "train only the classification head": unfreeze selected encoder blocks. First print the parameter list with indices to determine the index range of the encoder blocks:

```python
# We can check whether the model was correctly updated
for index, (name, param) in enumerate(model.named_parameters()):
     print(f"Parameter: {index}{name} ----- {param.requires_grad}")
```

Experiments show that index 165 is the starting position of encoder block 10; freeze everything before it and train only the last few blocks:

```python
# Load model
model_id = "bert-base-cased"
model = AutoModelForSequenceClassification.from_pretrained(model_id, num_labels=2)
tokenizer = AutoTokenizer.from_pretrained(model_id)

# Encoder block 10 starts at index 165 and
# we freeze everything before that block
for index, (name, param) in enumerate(model.named_parameters()):
    if index < 165:
        param.requires_grad = False

# Trainer which executes the training process
trainer = Trainer(
   model=model,

   eval_dataset=tokenized_test,
   tokenizer=tokenizer,
```

## 11.4 Few-Shot Classification

When labeled data is scarce (only a dozen samples per class), traditional fine-tuning struggles to converge. SetFit solves this problem through contrastive learning. First simulate a few-shot setting with `sample_dataset` — sample 16 examples per class:

```python
from setfit import sample_dataset

# We simulate a few-shot setting by sampling 16 examples per class
sampled_train_data = sample_dataset(tomatoes["train"], num_samples=16)
```

Load a pre-trained SentenceTransformer model as the backbone:

```python
from setfit import SetFitModel

# Load a pre-trained SentenceTransformer model
model = SetFitModel.from_pretrained("sentence-transformers/all-mpnet-base-v2")
```

SetFit training has two stages: first contrastive learning on text pairs, then training the classification head. When defining training arguments, control how many text pairs are generated via `num_iterations`:

```python
from setfit import TrainingArguments as SetFitTrainingArguments
from setfit import Trainer as SetFitTrainer

# Define training arguments
args = SetFitTrainingArguments(
    num_epochs=3, # The number of epochs to use for contrastive learning
    num_iterations=20  # The number of text pairs to generate
)
args.eval_strategy = args.evaluation_strategy

# Create trainer
trainer = SetFitTrainer(
    model=model,
    args=args,
    train_dataset=sampled_train_data,
    eval_dataset=test_data,
    metric="f1"
)
```

Define the label mapping (O/B-PER/I-PER/B-ORG, etc., 9 classes total):

```python
label2id = {
    'O': 0, 'B-PER': 1, 'I-PER': 2, 'B-ORG': 3, 'I-ORG': 4,
    'B-LOC': 5, 'I-LOC': 6, 'B-MISC': 7, 'I-MISC': 8
}
id2label = {index: label for label, index in label2id.items()}
label2id
```

Load the token classification model and pass in id2label/label2id so that inference results have readable labels:

```python
from transformers import AutoModelForTokenClassification

# Load model

    "bert-base-cased",
    num_labels=len(id2label),
    id2label=id2label,
    label2id=label2id
)
```

The core challenge in NER: words are split into sub-tokens, but labels are word-level. First split the words to inspect the sub-token situation:

```python
# Split individual tokens into sub-tokens
token_ids = tokenizer(example["tokens"], is_split_into_words=True)["input_ids"]
sub_tokens = tokenizer.convert_ids_to_tokens(token_ids)
sub_tokens
```

The `align_labels` function aligns labels: special tokens are marked -100 (not participating in loss computation); the first sub-token of a word inherits the original label; subsequent sub-tokens that are B-XXX are changed to I-XXX:

```python
def align_labels(examples):
    token_ids = tokenizer(examples["tokens"], truncation=True, is_split_into_words=True)
    labels = examples["ner_tags"]

    updated_labels = []
    for index, label in enumerate(labels):

        # Map tokens to their respective word
        word_ids = token_ids.word_ids(batch_index=index)
        previous_word_idx = None
        label_ids = []
        for word_idx in word_ids:

            # The start of a new word
            if word_idx != previous_word_idx:

                previous_word_idx = word_idx
                updated_label = -100 if word_idx is None else label[word_idx]
                label_ids.append(updated_label)

            # Special token is -100
            elif word_idx is None:
                label_ids.append(-100)

            # If the label is B-XXX we change it to I-XXX
            else:
                updated_label = label[word_idx]
                if updated_label % 2 == 1:
                    updated_label += 1
                label_ids.append(updated_label)

        updated_labels.append(label_ids)

    token_ids["labels"] = updated_labels
    return token_ids

tokenized = dataset.map(align_labels, batched=True)
```

Compare original and aligned labels:


NER uses the seqeval library for sequence-level evaluation, collecting non -100 predictions and true labels per document per token:

```python
import evaluate

# Load sequential evaluation
seqeval = evaluate.load("seqeval")

def compute_metrics(eval_pred):
    # Create predictions
    logits, labels = eval_pred
    predictions = np.argmax(logits, axis=2)

    true_predictions = []
    true_labels = []

    # Document-level iteration
    for prediction, label in zip(predictions, labels):

      # token-level iteration
      for token_prediction, token_label in zip(prediction, label):

        # We ignore special tokens
        if token_label != -100:
          true_predictions.append([id2label[token_prediction]])
          true_labels.append([id2label[token_label]])

    results = seqeval.compute(predictions=true_predictions, references=true_labels)
    return {"f1": results["overall_f1"]}
```

## Chapter Summary

- The standard supervised fine-tuning pipeline: load model → tokenize (dynamic padding) → define metrics → `Trainer` train and evaluate;
- Freezing strategies can significantly reduce training cost: training only the classification head is cheapest; unfreezing selected encoder blocks trades off performance — ablation experiments show F1 stabilizes after unfreezing about 4 blocks;
- For few-shot scenarios, **SetFit** is the preferred choice: even with only 16 samples per class, contrastive learning achieves notable results;
- When domain data differs significantly, perform **MLM continued pre-training** first, then downstream fine-tuning; `DataCollatorForLanguageModeling` auto-masks at 15% probability;
- The key to NER is **sub-word to word label alignment**: special tokens marked -100; first sub-token inherits the label; subsequent sub-tokens B→I.
