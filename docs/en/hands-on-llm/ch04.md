## 4.3 Text Classification Using Representative Models

### 4.3.1 Using a Task-Specific Model

The most straightforward approach is to use a model already fine-tuned on a similar task. Here we choose **cardiffnlp/twitter-roberta-base-sentiment-latest**, a sentiment analysis model trained on Twitter data:

```python
from transformers import pipeline

# Path to our HF model
model_path = "cardiffnlp/twitter-roberta-base-sentiment-latest"

# Load model into pipeline
pipe = pipeline(
    model=model_path,
    tokenizer=model_path,
    return_all_scores=True,
    device="cuda:0"
)
```

```python
import numpy as np
from tqdm import tqdm
from transformers.pipelines.pt_utils import KeyDataset

# Run inference
y_pred = []
for output in tqdm(pipe(KeyDataset(data["test"], "text")), total=len(data["test"])):
    negative_score = output[0]["score"]
    positive_score = output[2]["score"]
    assignment = np.argmax([negative_score, positive_score])
    y_pred.append(assignment)
```

This model outputs three classes (negative / neutral / positive). Since our task is binary classification, we only compare the negative and positive scores and take the larger one as the prediction.

Next, define the evaluation function and view overall performance:

```python
from sklearn.metrics import classification_report

def evaluate_performance(y_true, y_pred):
    """Create and print the classification report"""
    performance = classification_report(
        y_true, y_pred,
        target_names=["Negative Review", "Positive Review"]
    )
    print(performance)
```

```python
evaluate_performance(data["test"]["label"], y_pred)
```

### 4.3.2 Using Embeddings for Classification Tasks

#### Supervised Classification

Instead of using a ready-made sentiment model, first use an embedding model to convert text to vectors, then train a standard classifier on the vectors:

```python
from sentence_transformers import SentenceTransformer

# Load model
model = SentenceTransformer('sentence-transformers/all-mpnet-base-v2')

# Convert text to embeddings
train_embeddings = model.encode(data["train"]["text"], show_progress_bar=True)
test_embeddings = model.encode(data["test"]["text"], show_progress_bar=True)
```

```python
train_embeddings.shape
```

all-mpnet-base-v2 outputs 768-dimensional embedding vectors.

```python
from sklearn.linear_model import LogisticRegression

# Train a Logistic Regression on our train embeddings
clf = LogisticRegression(random_state=42)
clf.fit(train_embeddings, data["train"]["label"])
```

```python
# Predict previously unseen instances
y_pred = clf.predict(test_embeddings)
evaluate_performance(data["test"]["label"], y_pred)
```

**Tip!**

What happens if we don't use a classifier at all? We can average the embeddings for each class, then use cosine similarity to predict which class best matches the document:

```python
import numpy as np
import pandas as pd
from sklearn.metrics import classification_report
from sklearn.metrics.pairwise import cosine_similarity

# Average the embeddings of all documents in each target label
df = pd.DataFrame(np.hstack([train_embeddings, np.array(data["train"]["label"]).reshape(-1, 1)]))
averaged_target_embeddings = df.groupby(768).mean().values

# Find the best matching embeddings between evaluation documents and target embeddings
sim_matrix = cosine_similarity(test_embeddings, averaged_target_embeddings)
y_pred = np.argmax(sim_matrix, axis=1)

# Evaluate the model
evaluate_performance(data["test"]["label"], y_pred)
```

#### Zero-Shot Classification

The most fascinating aspect of the embedding approach: no training required at all! Just write a description for each label, encode the descriptions as embeddings, and see which label description the document matches most closely:

```python
# Create embeddings for our labels
label_embeddings = model.encode(["A negative review",  "A positive review"])
```

```python
from sklearn.metrics.pairwise import cosine_similarity

# Find the best matching label for each document
sim_matrix = cosine_similarity(test_embeddings, label_embeddings)
y_pred = np.argmax(sim_matrix, axis=1)
```

```python
evaluate_performance(data["test"]["label"], y_pred)
```

**Tip!**

What happens if you use different descriptions? Try **"A very negative movie review"** and **"A very positive movie review"** and see how performance changes!

## 4.4 Text Classification Using Generative Models

### 4.4.1 Encoder-Decoder Models

Generative models take a different path: have the model **generate** the answer rather than output scores. Here we use the encoder-decoder architecture **google/flan-t5-small**:

```python
# Load our model
pipe = pipeline(
    "text2text-generation",
    model="google/flan-t5-small",
    device="cuda:0"
)
```

```python
# Prepare our data
prompt = "Is the following sentence positive or negative? "
data = data.map(lambda example: {"t5": prompt + example['text']})
data
```

```python
# Run inference
y_pred = []
for output in tqdm(pipe(KeyDataset(data["test"], "t5")), total=len(data["test"])):
    text = output[0]["generated_text"]
    y_pred.append(0 if text == "negative" else 1)
```

```python
evaluate_performance(data["test"]["label"], y_pred)
```

Note the parsing logic: if the generated text is exactly `"negative"`, record 0; otherwise record 1—a generative model outputs free text, so such mapping rules are needed.

### 4.4.2 Using ChatGPT for Classification

Finally, try the closed-source OpenAI API. First create the client:

```python
import openai

# Create client
client = openai.OpenAI(api_key="YOUR_KEY_HERE")
```

Define a generation function that assembles system and user prompts before calling the API:

```python
def chatgpt_generation(prompt, document, model="gpt-3.5-turbo-0125"):
    """Generate an output based on a prompt and an input document."""
    messages=[
        {
            "role": "system",
            "content": "You are a helpful assistant."
            },
        {
            "role": "user",
            "content":   prompt.replace("[DOCUMENT]", document)
            }
    ]
    chat_completion = client.chat.completions.create(
      messages=messages,
      model=model,
      temperature=0
    )
    return chat_completion.choices[0].message.content
```

```python
# Define a prompt template as a base
prompt = """Predict whether the following document is a positive or negative movie review:

[DOCUMENT]

If it is positive return 1 and if it is negative return 0. Do not give any other answers.
"""

# Predict the target using GPT
document = "unpretentious , charming , quirky , original"
chatgpt_generation(prompt, document)
```

Next, run the OpenAI model on the entire evaluation set. However, make sure you have sufficient credits before running—it will call the API once for each record in the test set (1066 records):

```python
# You can skip this if you want to save your (free) credits
predictions = [chatgpt_generation(prompt, doc) for doc in tqdm(data["test"]["text"])]
```

```python
# Extract predictions
y_pred = [int(pred) for pred in predictions]

# Evaluate performance
evaluate_performance(data["test"]["label"], y_pred)
```

## 4.5 Chapter Summary

- Text classification has two approaches: representative models (embeddings/scores) and generative models (generate answer text);
- Task-specific models (twitter-roberta-base-sentiment-latest) are ready-to-use out of the box, but they output three-class predictions, requiring manual merging into a binary decision;
- Embeddings + LogisticRegression is a strong supervised baseline; averaging embeddings per class and using cosine similarity eliminates the need for any classifier;
- Zero-shot classification only requires writing descriptions for labels and encoding them as embeddings, with no training needed—the wording of descriptions affects results;
- Encoder-decoder models like flan-t5 generate free text, requiring string mapping rules to convert to labels; ChatGPT is flexible but billed per call.
