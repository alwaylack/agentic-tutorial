## 3.2 Loading the LLM

```python
from transformers import AutoModelForCausalLM, AutoTokenizer, pipeline

# Load model and tokenizer
tokenizer = AutoTokenizer.from_pretrained("microsoft/Phi-3-mini-4k-instruct")

model = AutoModelForCausalLM.from_pretrained(
    "microsoft/Phi-3-mini-4k-instruct",
    device_map="cuda",
    torch_dtype="auto",
    trust_remote_code=False,
)

# Create a pipeline
generator = pipeline(
    "text-generation",
    model=model,
    tokenizer=tokenizer,
    return_full_text=False,
    max_new_tokens=50,
    do_sample=False,
)
```

Here we load **microsoft/Phi-3-mini-4k-instruct**—a small but capable instruct model—and wrap it with `pipeline` as a text generator. `return_full_text=False` means only the newly generated portion is returned; `do_sample=False` means deterministic decoding is used.

## 3.3 A Post-Training Transformer LLM: Inputs and Outputs

```python
prompt = "Write an email apologizing to Sarah for the tragic gardening mishap. Explain how it happened."

output = generator(prompt)

print(output[0]['generated_text'])
```

```python
print(model)
```

`print(model)` outputs the complete model structure. You will see that a typical generative LLM consists of two main parts:

- **model (backbone)**: A backbone network formed by stacking dozens of transformer blocks, responsible for progressively processing the input token sequence into hidden states;
- **lm_head (output head)**: A linear layer that projects the final hidden state back to vocabulary size, producing logits (unnormalized probability scores) for each token.

## 3.4 Selecting a Single Token from a Probability Distribution (Sampling / Decoding)

We can manually split these two parts to observe the complete process of the model "selecting the next word":

```python
prompt = "The capital of France is"

# Tokenize the input prompt
input_ids = tokenizer(prompt, return_tensors="pt").input_ids

# Move to GPU
input_ids = input_ids.to("cuda")

# Get the output of the model before the lm_head
model_output = model.model(input_ids)

# Get the output of the lm_head
lm_head_output = model.lm_head(model_output[0])
```

```python
token_id = lm_head_output[0,-1].argmax(-1)
tokenizer.decode(token_id)
```

Taking the `argmax` of the logits at the last position decodes to `" Paris"`—this is the most intuitive form of **greedy decoding**.

```python
model_output[0].shape
```

```python
lm_head_output.shape
```

Comparing the shapes of the two tensors clarifies the data flow: `model_output[0]` has shape `[batch_size, sequence_length, hidden_dimension]` (hidden states), while `lm_head_output` has shape `[batch_size, sequence_length, vocabulary_size]`—the last dimension changes from hidden dimension to vocabulary size, with each position corresponding to scores for all tokens in the vocabulary.

## 3.5 Accelerating Generation with KV Caching (Keys and Values)

When generating very long text, without caching, each newly generated token requires recomputing attention keys and values for all layers across the entire sequence. The caching mechanism stores these intermediate results for reuse:

```python
prompt = "Write a very long email apologizing to Sarah for the tragic gardening mishap. Explain how it happened."

# Tokenize the input prompt
input_ids = tokenizer(prompt, return_tensors="pt").input_ids
input_ids = input_ids.to("cuda")
```

```python
%%timeit -n 1
# Generate the text
generation_output = model.generate(
  input_ids=input_ids,
  max_new_tokens=100,
  use_cache=True
)
```

```python
%%timeit -n 1
# Generate the text
generation_output = model.generate(
  input_ids=input_ids,
  max_new_tokens=100,
  use_cache=False
)
```

Generate 100 tokens with `use_cache=True` and `use_cache=False` respectively and compare timing. You will find that enabling caching makes generation much faster—this is precisely why all mainstream inference frameworks enable KV caching by default.

## 3.6 Chapter Summary

- A generative LLM = transformer backbone network (model) + language model output head (lm_head), where the latter projects hidden states into logits over the vocabulary;
- `model.model(input_ids)` returns hidden states before lm_head, with shape `[batch, seq_len, hidden_dim]`; after passing through lm_head it becomes `[batch, seq_len, vocab_size]`;
- Taking `argmax` on the logits at the last position performs greedy decoding—"The capital of France is" yields " Paris";
- KV caching (`use_cache=True`) reuses attention keys and values from previous tokens, avoiding full recomputation at each step, significantly accelerating long text generation.
