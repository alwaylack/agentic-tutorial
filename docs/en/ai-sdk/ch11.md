## 11.1 What Is an Embedding

An embedding is a method of representing words, phrases, or images as vectors in high-dimensional space. In this space, semantically similar content sits close together, and the distance between vectors can be used to measure similarity.

AI SDK routes model calls through the AI Gateway by default — you can use gateway model strings like `'openai/text-embedding-3-small'` directly, or swap in a custom OpenAI-compatible Provider instance (see Chapter 3); both approaches are fully transparent to the embed series functions.

## 11.2 Embedding a Single Value

The [`embed`](https://ai-sdk.dev/docs/reference/ai-sdk-core/embed) function embeds a single value, suitable for tasks like finding similar phrases or text clustering:

```ts filename="embed-single.ts"
import { embed, createGateway } from 'ai';

const gateway = createGateway({ apiKey: process.env.AI_GATEWAY_API_KEY ?? '' });

// 'embedding' is an embedding object (number[])
const { embedding } = await embed({
  model: 'openai/text-embedding-3-small', // Routed via AI Gateway; or use a custom provider instance
  value: 'sunny day at the beach',
});
```

## 11.3 Batch-Embedding Multiple Values

When loading data (e.g., preparing a data store for Retrieval-Augmented Generation / RAG), batch-embedding multiple values at once is通常 more efficient. [`embedMany`](https://ai-sdk.dev/docs/reference/ai-sdk-core/embed-many) is designed for this:

```ts filename="embed-many.ts"
import { embedMany } from 'ai';

// 'embeddings' is an array of embeddings (number[][]),
// ordered to correspond one-to-one with the input values
const { embeddings } = await embedMany({
  model: 'openai/text-embedding-3-small',
  values: [
    'sunny day at the beach',
    'rainy afternoon in the city',
    'snowy night in the mountains',
  ],
});
```

### Embedding Similarity

After embedding, you can use the [`cosineSimilarity`](https://ai-sdk.dev/docs/reference/ai-sdk-core/cosine-similarity) function to compute the cosine similarity between them, then sort and filter related entries:

```ts filename="similarity.ts"
import { cosineSimilarity, embedMany } from 'ai';

const { embeddings } = await embedMany({
  model: 'openai/text-embedding-3-small',
  values: ['sunny day at the beach', 'rainy afternoon in the city'],
});

console.log(
  `cosine similarity: ${cosineSimilarity(embeddings[0], embeddings[1])}`,
);
```

## 11.4 Token Usage and Response Info

Many providers bill by token count. Both `embed` and `embedMany` return usage information in the `usage` property of the result object:

```ts filename="usage.ts"
import { embed } from 'ai';

const { embedding, usage } = await embed({
  model: 'openai/text-embedding-3-small',
  value: 'sunny day at the beach',
});

console.log(usage); // { tokens: 10 }
```

They also return `response` info containing the raw provider response,便于 debugging:

```ts filename="response.ts"
import { embed } from 'ai';

const { embedding, response } = await embed({
  model: 'openai/text-embedding-3-small',
  value: 'sunny day at the beach',
});

console.log(response); // Raw provider response
```

## 11.5 Generation Settings

**Provider Options**: Configure provider-specific parameters via `providerOptions`:

```ts filename="provider-options.ts"
import { embed } from 'ai';

const { embedding } = await embed({
  model: 'openai/text-embedding-3-small',
  value: 'sunny day at the beach',
  providerOptions: {
    openai: {
      dimensions: 512, // Reduce embedding dimensionality
    },
  },
});
```

Google's `gemini-embedding-2` also supports multimodal embeddings via `providerOptions.google.content`, where each entry can contain `{ text }`, `{ inlineData }`, or `{ fileData }` parts.

**Parallel Requests**: `embedMany` supports controlling concurrency with `maxParallelCalls` to optimize performance:

```ts filename="parallel.ts"
import { embedMany } from 'ai';

const { embeddings, usage } = await embedMany({
  maxParallelCalls: 2, // Limit parallel request count
  model: 'openai/text-embedding-3-small',
  values: [
    'sunny day at the beach',
    'rainy afternoon in the city',
    'snowy night in the mountains',
  ],
});
```

**Retries**: `maxRetries` defaults to 2 (3 total attempts); set to 0 to disable. Both also accept an optional `abortSignal` parameter (e.g., `AbortSignal.timeout(1000)` to abort after 1 second) and a `headers` parameter to add custom request headers.

## 11.6 Embedding Model Middleware

You can enhance embedding models using `wrapEmbeddingModel` and `EmbeddingModelMiddleware`, e.g., to set defaults. The following example uses the built-in `defaultEmbeddingSettingsMiddleware`:

```ts filename="middleware.ts"
import {
  defaultEmbeddingSettingsMiddleware,
  embed,
  wrapEmbeddingModel,
  createGateway,
} from 'ai';

const gateway = createGateway({ apiKey: process.env.AI_GATEWAY_API_KEY ?? '' });

const embeddingModelWithDefaults = wrapEmbeddingModel({
  model: gateway.embeddingModel('google/gemini-embedding-001'),
  middleware: defaultEmbeddingSettingsMiddleware({
    settings: {
      providerOptions: {
        google: {
          outputDimensionality: 256,
          taskType: 'CLASSIFICATION',
        },
      },
    },
  }),
});
```

Common embedding models: OpenAI `text-embedding-3-large` (3072 dims) / `text-embedding-3-small` (1536 dims), Google `gemini-embedding-001` (3072 dims), Mistral `mistral-embed` (1024 dims), Cohere `embed-multilingual-v3.0` (1024 dims), etc.

## 11.7 Reranking

Reranking improves search quality by reordering a set of documents by query relevance. Unlike embedding-based similarity search, reranking models are专门 trained to understand the relationship between a query and documents,通常 yielding more accurate relevance scores.

The [`rerank`](https://ai-sdk.dev/docs/reference/ai-sdk-core/rerank) function reranks documents by relevance:

```ts filename="rerank-basic.ts"
import { rerank } from 'ai';

const documents = [
  'sunny day at the beach',
  'rainy afternoon in the city',
  'snowy night in the mountains',
];

const { ranking } = await rerank({
  model: 'openai/rerank-2',
  query: 'beach weather',
  documents,
});
```

The result contains a `ranking` array with each document's relevance score, ordered from highest to lowest.

## Chapter Summary

- Embeddings convert text/images into high-dimensional vectors; semantic similarity is measured by vector distance;
- Core APIs: `embed` (single value), `embedMany` (batch), `cosineSimilarity` (similarity computation);
- Generation settings: `providerOptions` for provider-specific params, `maxParallelCalls` for concurrency, `maxRetries` and `abortSignal` for resilience;
- `wrapEmbeddingModel` + middleware lets you set defaults and enhance embedding behavior;
- Reranking reorders documents by query relevance using a dedicated model — more accurate than pure embedding similarity for retrieval.
