## 14.1 Generating Images with generateImage

AI SDK provides the [`generateImage`](https://ai-sdk.dev/docs/reference/ai-sdk-core/generate-image) function to generate images based on a given prompt using an image model.

```tsx filename="index.ts"
import { generateImage, createGateway } from 'ai';
import 'dotenv/config';

const gateway = createGateway({ apiKey: process.env.AI_GATEWAY_API_KEY ?? '' });

// A string model ID is resolved via the global default provider (AI Gateway);
// custom OpenAI-compatible providers use myProvider.image('your-image-model')
const { image } = await generateImage({
  model: gateway.image('openai/dall-e-3'),
  prompt: 'Santa Claus driving a Cadillac',
});
```

You can access the image data via `base64` or `uint8Array`:

```tsx
const base64 = image.base64; // base64-encoded image data
const uint8Array = image.uint8Array; // Uint8Array binary data
```

## 14.2 Basic Settings

### Size and Aspect Ratio

Depending on the model, you can specify `size` or `aspectRatio`. Size is a string in `{width}x{height}` format — models support only a few sizes, varying by model and provider:

```tsx highlight={"7"}
import { generateImage } from 'ai';
import 'dotenv/config';

const { image } = await generateImage({
  model: 'openai/dall-e-3',
  prompt: 'Santa Claus driving a Cadillac',
  size: '1024x1024',
});
```

Aspect ratio is in `{width}:{height}` format, with only a few values available:

```tsx highlight={"7"}
import { generateImage } from 'ai';
import 'dotenv/config';

const { image } = await generateImage({
  model: 'openai/dall-e-3',
  prompt: 'Santa Claus driving a Cadillac',
  aspectRatio: '16:9',
});
```

### Batch Generating Multiple Images

`generateImage` supports generating multiple images in one call:

```tsx highlight={"7"}
import { generateImage } from 'ai';
import 'dotenv/config';

const { images } = await generateImage({
  model: 'openai/dall-e-3',
  prompt: 'Santa Claus driving a Cadillac',
  n: 4, // number of images to generate
});
```

`generateImage` auto-calls the model in parallel as needed to generate the requested number of images. Each image model has an internal limit on how many images can be generated per API call; the SDK自动 batches reasonably (e.g., DALL-E 3 generates 1 image per call, DALL-E 2 up to 10 per call).

You can override the default batch size with `maxImagesPerCall` — particularly useful for new or custom models:

```tsx
const { images } = await generateImage({
  model: 'openai/dall-e-2',
  prompt: 'Santa Claus driving a Cadillac',
  maxImagesPerCall: 5, // Override the default batch size
  n: 10, // Will make 2 calls of 5 images each
});
```

### Specifying a Seed

Providing a seed controls the image generation output. If the model supports it, the same seed always produces the same image:

```tsx highlight={"7"}
import { generateImage } from 'ai';
import 'dotenv/config';

const { image } = await generateImage({
  model: 'openai/dall-e-3',
  prompt: 'Santa Claus driving a Cadillac',
  seed: 1234567890,
});
```

### Provider-Specific Settings

Image models通常 have provider- or even model-specific settings, passed via the `providerOptions` parameter (options become request body properties). The following example follows the official docs' OpenAI pattern to show the `providerOptions` structure:

```tsx
import { generateImage, createGateway } from 'ai';
import 'dotenv/config';

const gateway = createGateway({ apiKey: process.env.AI_GATEWAY_API_KEY ?? '' });

const { image } = await generateImage({
  model: gateway.image('openai/dall-e-3'),
  prompt: 'Santa Claus driving a Cadillac',
  size: '1024x1024',
  providerOptions: {
    openai: {
      style: 'vivid',
      quality: 'hd',
    },
  },
});
```

### Abort Signal and Timeout

`generateImage` accepts an optional [`AbortSignal`](https://developer.mozilla.org/en-US/docs/Web/API/AbortSignal) type `abortSignal` parameter, which can be used to abort image generation or set a timeout:

```ts highlight={"7"}
import { generateImage } from 'ai';
import 'dotenv/config';

const { image } = await generateImage({
  model: 'openai/dall-e-3',
  prompt: 'Santa Claus driving a Cadillac',
  abortSignal: AbortSignal.timeout(1000), // Abort after 1 second
});
```

### Custom Headers and Warnings

The optional `headers` parameter (type `Record<string, string>`) adds custom headers to image generation requests; if the model returns warnings (e.g., for unsupported parameters), they are available in the result's `warnings` property:

```tsx
const { image, warnings } = await generateImage({
  model: 'openai/dall-e-3',
  prompt: 'Santa Claus driving a Cadillac',
});
```

### Provider Attachment Metadata

Some providers expose additional metadata on the overall result or per-image. The returned `providerMetadata` outer key is the provider name, inner is the metadata; it always includes an `images` key, an array同长度 as the top-level `images` array:

```tsx
const prompt = 'Santa Claus driving a Cadillac';

const { image, providerMetadata } = await generateImage({
  model: 'openai/dall-e-3',
  prompt,
});

const revisedPrompt = providerMetadata.openai.images[0]?.revisedPrompt;

console.log({
  prompt,
  revisedPrompt,
});
```

## 14.3 Error Handling

When `generateImage` cannot generate a valid image, it throws [`AI_NoImageGeneratedError`](https://ai-sdk.dev/docs/reference/ai-sdk-errors/ai-no-image-generated-error). Possible causes: the model failed to generate a response, or generated an unparseable response.

## 14.4 wrapImageModel Middleware

Use `wrapImageModel` to enhance image models with middleware, analogous to `wrapLanguageModel`:

```ts
import { wrapImageModel, generateImage } from 'ai';

const enhancedImageModel = wrapImageModel({
  model: gateway.image('openai/dall-e-3'),
  middleware: yourImageModelMiddleware,
});

const { image } = await generateImage({
  model: enhancedImageModel,
  prompt: 'Santa Claus driving a Cadillac',
});
```

## 14.5 uploadFile and ProviderReference

`uploadFile` uploads a file to the provider and returns a `ProviderReference` that can be passed to subsequent calls. This is useful for multi-modal inputs (e.g., passing an image to a vision model) without embedding large base64 strings directly:

```ts
import { uploadFile, createGateway } from 'ai';

const file = await uploadFile({
  model: gateway('openai/gpt-4o'),
  file: buffer, // Buffer or Blob
  mime: 'image/png',
});

// file.providerData contains the provider-specific reference
```

In multi-provider scenarios, file references are merged according to the provider's capabilities — the SDK handles cross-provider reference resolution automatically.

## Chapter Summary

- `generateImage` creates images from text prompts; access via `image.base64` or `image.uint8Array`;
- Size (`1024x1024`) and aspect ratio (`16:9`) are model-dependent; batch with `n` and control batch size with `maxImagesPerCall`;
- Seeds provide deterministic output when supported; `providerOptions` passes model-specific settings;
- `abortSignal` supports timeout and cancellation; `warnings` captures model-returned warnings;
- `wrapImageModel` applies middleware to image models; `uploadFile` handles multi-modal file uploads with ProviderReference.
