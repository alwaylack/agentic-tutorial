# Chapter 10 · Reasoning Models

## 10.1 What Is the Reasoning Phase

Many language models perform an internal "reasoning" phase (also called "thinking") before producing their final response. AI SDK provides a top-level `reasoning` parameter on both [`generateText`](https://ai-sdk.dev/docs/reference/ai-sdk-core/generate-text) and [`streamText`](https://ai-sdk.dev/docs/reference/ai-sdk-core/stream-text) to control this behavior across all providers in a portable way.

## 10.2 Basic Usage

```ts filename="basic.ts"
import { generateText, createGateway } from 'ai';

// Method 1: Vercel AI Gateway
const gateway = createGateway({ apiKey: process.env.AI_GATEWAY_API_KEY ?? '' });

const { text, reasoning, reasoningText } = await generateText({
  model: gateway('anthropic/claude-sonnet-4.6'),
  reasoning: 'medium',
  prompt: 'How many people will live in the world in 2040?',
});

// Method 2: Custom OpenAI-compatible Provider (choose one)

// });
// const model = myProvider('claude-sonnet-4.6'); // Use your server's actual model name
```

The `reasoning` parameter accepts the following values:

| Value | Behavior |
| --- | --- |
| `'provider-default'` | Use the provider's default reasoning behavior (the default when omitted) |
| `'none'` | Disable reasoning |
| `'minimal'` | Minimal reasoning |
| `'low'` | Fast, concise reasoning |
| `'medium'` | Balanced reasoning |
| `'high'` | Thorough reasoning |
| `'xhigh'` | Maximum reasoning |

## 10.3 Streaming Output

The `reasoning` parameter works identically in `streamText`. Stream parts are divided into `reasoning` and `text-delta` categories, which can be handled separately:

```ts filename="stream.ts"
import { streamText, createGateway } from 'ai';

const gateway = createGateway({ apiKey: process.env.AI_GATEWAY_API_KEY ?? '' });

const result = streamText({
  model: gateway('google/gemini-3-flash-preview'),
  reasoning: 'high',
  prompt: 'Explain the Riemann hypothesis in simple terms.',
});

for await (const part of result.stream) {
  if (part.type === 'reasoning') {
    process.stdout.write(part.textDelta);
  } else if (part.type === 'text-delta') {
    process.stdout.write(part.textDelta);
  }
}
```

## 10.4 Precedence Rules

The top-level `reasoning` parameter and provider-specific `providerOptions` **never merge**. If you set reasoning-related options in `providerOptions`, they take full effect and the top-level `reasoning` parameter is ignored:

```ts filename="precedence.ts"
import { generateText, createGateway } from 'ai';

const { text } = await generateText({
  model: gateway('anthropic/claude-sonnet-4.6'),
  reasoning: 'low', // Ignored because providerOptions takes precedence
  providerOptions: {
    anthropic: {
      thinking: { type: 'enabled', budgetTokens: 2000 },
    },
  },
  prompt: 'Solve this math problem.',
});
```

## 10.5 Migration from Provider-Specific Configs

### Anthropic

Previously configured via `thinking`:

```ts filename="before-anthropic.ts"
const { text } = await generateText({
  model: gateway('anthropic/claude-sonnet-4.6'),
  providerOptions: {
    anthropic: {
      thinking: { type: 'enabled', budgetTokens: 12000 },
    },
  },
  prompt: 'How many people will live in the world in 2040?',
});
```

Migrate to the portable parameter:

```ts filename="after-anthropic.ts"
const { text } = await generateText({
  model: gateway('anthropic/claude-sonnet-4.6'),
  reasoning: 'medium', // Replaces budgetTokens: 12000
  prompt: 'How many people will live in the world in 2040?',
});
```

### Google

Previously configured via `includeThoughts`:

```ts filename="before-google.ts"
const { text } = await generateText({
  model: gateway('google/gemini-3-flash-preview'),
  providerOptions: {
    google: { thinkingConfig: { includeThoughts: true } },
  },
  prompt: 'Explain the Riemann hypothesis in simple terms.',
});
```

```ts filename="after-google.ts"
const { text } = await generateText({
  model: gateway('google/gemini-3-flash-preview'),
  reasoning: 'medium',
  providerOptions: {
    google: { thinkingConfig: { includeThoughts: true } }, // Non-reasoning options stay in providerOptions
  },
  prompt: 'Explain the Riemann hypothesis in simple terms.',
});
```

### OpenAI

Previously configuring both `reasoningEffort` and `reasoningSummary`:

```ts filename="before-openai.ts"
const { text } = await generateText({
  model: gateway('openai/o3'),
  providerOptions: {
    openai: { reasoningEffort: 'high' },
  },
  prompt: 'Explain quantum entanglement.',
});
```

```ts filename="after-openai.ts"
const { text } = await generateText({
  model: gateway('openai/o3'),
  reasoning: 'high', // Replaces providerOptions.openai.reasoningEffort
  providerOptions: {
    openai: { reasoningSummary: 'auto' }, // Provider-specific features unrelated to reasoning strength stay in providerOptions
  },
  prompt: 'Explain quantum entanglement.',
});
```

Note: `providerOptions` can still be used alongside `reasoning` for provider-specific features unrelated to reasoning strength. But if `providerOptions` contains reasoning-strength/budget settings (e.g., `reasoningEffort`, `thinking`, `thinkingConfig.thinkingBudget`), they完全优先 and the top-level `reasoning` parameter is ignored.

## Chapter Summary

- Many models have an internal "reasoning" phase before producing the final response; AI SDK unifies control via the top-level `reasoning` parameter
- Six tiers: `none` / `minimal` / `low` / `medium` / `high` / `xhigh`, plus `provider-default`
- In streaming, `reasoning` parts and `text-delta` parts can be handled separately
- `providerOptions` reasoning settings完全优先 over the top-level `reasoning`; they do not merge
- Each provider maps `reasoning` to its native API; unsupported providers emit an `unsupported` warning
- When migrating, keep provider-specific non-reasoning options in `providerOptions`; switch reasoning strength to the portable parameter
