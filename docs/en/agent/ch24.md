## 24.1 Official and Community Skills Repositories

### Anthropic Skills Repository

Anthropic maintains an official skill collection: [anthropics/skills](https://github.com/anthropics/skills). It includes:

- **Document processing skills**: PDF extraction, Word conversion, PPT parsing;
- **Web development skills**: frontend builds, API design, deployment pipelines;
- **Code quality skills**: security scanning, performance analysis, refactoring suggestions.

These skills遵循 the Agent Skills standard and can be directly loaded by any compatible tool.

## 24.2 Cross-Tool Compatibility

One of the design goals of the Agent Skills standard is **cross-tool compatibility**. Mainstream tools已 support it:

```json
// ~/.pi/agent/settings.json
{
  "skills": [
    "~/.claude/skills",       // Claude Code skills directory
    "~/.codex/skills",        // OpenAI Codex skills directory
    "~/.pi/agent/skills",     // Pi global skills
    "./.pi/skills"            // Project-level skills (requires trusted project)
  ]
}
```

Compatibilitytool清单 (as of mid-2025):

- **Claude Code** (Anthropic)
- **Codex** (OpenAI)
- **Cursor** / **Windsurf** / **VS Code Copilot**
- **Gemini CLI** (Google)
- **Pi** (this tutorial platform)
- **Devin**, **Aider**, **Opencode**, etc.

::: tip Note
不同 tools may have略有差异 in their implementation程度 of the standard; consulting thespecific tool\'s docs is recommended to confirm.
:::

## 24.3 Team Sharing Methods

### Method 1: Git Repo + settings Reference

```json
{
  "skills": ["https://github.com/myteam/project-skills"]
}
```

### Method 2: Internal npm Package

Package the skills as an npm包; team members `npm install` then reference:

```json
{
  "skills": ["@myorg/team-skills"]
}
```

### Method 3: shared/skills Directory in a Monorepo

```text
monorepo/
├── packages/
│   ├── frontend/
│   └── backend/
└── skills/                    # Shared skills
    ├── code-review/
    │   └── SKILL.md
    └── deploy-check/
        └── SKILL.md
```

Reference in the root `settings.json`:

```json
{
  "skills": ["./skills"]
}
```

## 24.4 Security Review Checklist

Before introducing a third-party skill,务必完成以下检查:

| Item | Description |
|---|---|
| **Source可读** | Can理解 the full content of SKILL.md |
| **No malicious commands** | Check whether steps contain dangerous shell commands |
| **Resource isolation** | Confirm the referenced scripts/references are within可控范围 |
| **Least privilege** | Does the skill请求工具 permissions beyond what\'s needed? |
| **Update mechanism** | Is the subscription source可信? Are updates auto androllable-back? |

::: danger Security Warning
Skills can instruct the model to execute任意 operations and may携带 executable code.务必阅读 the content before installing community skills.
:::

## 24.5 Team Governance Suggestions

1. **建立技能审核流程**: new skills需经 tech lead review;
2. **Version管理**: use git tags to标记 skill versions; avoid静默 updates;
3. **Disable auto-trigger for sensitive skills**: set `disable-model-invocation: true` for skills involving生产 environment operations;
4. **定期清理**: remove unused skills to减少 context noise.
