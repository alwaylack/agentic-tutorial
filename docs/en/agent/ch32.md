## 32.4 Frequently Asked Questions

**Q: I've finished the course; which framework should I use next?**
A: Depends on the goal:
- Rapid prototype → Pi
- Multi-agent collaboration → CrewAI
- Deep customization + production deployment → Agno

**Q: What's the difference between Prompt Engineering and Harness Engineering?**
A: Prompt solves "how to说 it"; Harness solves "where to say it, how to说 it, how to验 it." The former is a subset of the latter.

**Q: What is the relationship between MCP and Skills?**
A: MCP provides通用 tool capabilities (search, database); Skills封装特定 task workflows. The two can叠加使用.

**Q: Is Loop Engineering suitable for所有 projects?**
A: Not for greenfield projects (starting从零). It's最适合 for持续 maintenance scenarios with an existing codebase.

**Q: Can I go to production directly after finishing this course?**
A: It's建议 to配合 [Playwright](/playwright/) and [FastAPI](/fastapi/) courses,补足 testing and backend capabilities before deploying.
