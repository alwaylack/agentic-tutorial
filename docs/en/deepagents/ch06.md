# Chapter 06 · Memory and AGENTS.md

memory= points to AGENTS.md files that are all loaded at startup and persisted in the backend. It fits “long-term preferences / project conventions” and complements on-demand skills.

## Mechanics and design choices

memory vs skill differs in load timing: memory always enters context; skills enter as frontmatter summaries and then on-demand full text. Keep memory short and stable; too much inflates per-turn tokens.

## Example

```python
import os
from langchain_openai import ChatOpenAI

model = ChatOpenAI(
    model=os.environ["MODEL_ID"],
    api_key=os.environ["DEEPAGENT_API_KEY"],
    base_url=os.environ.get("DEEPAGENT_BASE_URL", "https://api.openai.com/v1"),
)

import pathlib, shutil, tempfile
from deepagents import create_deep_agent
from deepagents.backends import FilesystemBackend

root = tempfile.mkdtemp(prefix="deepagents-memory-")
try:
    agents_md = pathlib.Path(root) / "AGENTS.md"
    agents_md.write_text("# Rules\n- Use Python 3.11+\n- Never hard-code secrets\n")
    agent = create_deep_agent(
        model=model,
        memory=[str(agents_md)],
        backend=FilesystemBackend(root_dir=root, virtual_mode=True),
        system_prompt="Follow the AGENTS.md rules.",
    )
    result = agent.invoke(
        {"messages": [{"role": "user", "content": "Summarize the coding rules in one line."}]},
        {"configurable": {"thread_id": "ch06"}},
    )
    print(result["messages"][-1].content)
finally:
    shutil.rmtree(root, ignore_errors=True)
```

### Run and verify

API key required. The answer mentions both the Python 3.11+ and no-hard-coded-secrets rules.

## Pitfalls

AGENTS.md holds conventions, not secrets. Put credentials in a secret manager; do not push the .env file itself into memory.
