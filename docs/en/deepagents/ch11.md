# Chapter 11 · Streaming and subagent events

stream supports modes such as updates/messages/custom; delegated subtasks can also produce an independent stream.subagents event stream, rendering each subtask as its own channel.

## Mechanics and design choices

The UI layer consumes typed events, with different modes mapping to different components. Deep Agents adds subagents events on top of standard streams, giving each delegated task its own handle; these are hidden by default and need explicit subscription.

## Example

```python
import os
from langchain_openai import ChatOpenAI

model = ChatOpenAI(
    model=os.environ["MODEL_ID"],
    api_key=os.environ["DEEPAGENT_API_KEY"],
    base_url=os.environ.get("DEEPAGENT_BASE_URL", "https://api.openai.com/v1"),
)

import asyncio
from deepagents import create_deep_agent

agent = create_deep_agent(
    model=model,
    system_prompt="Answer in one line.",
)

async def run():
    async for chunk in agent.astream(
        {"messages": [{"role": "user", "content": "Say: ready."}]},
        config={"configurable": {"thread_id": "ch11"}},
        stream_mode=["messages", "custom"],
        version="v2",
    ):
        if chunk["type"] == "messages":
            token, meta = chunk["data"]
            if token.content:
                print(token.content, end="|", flush=True)

asyncio.run(run())
```

### Run and verify

API key required. Acceptance: the terminal streams “ready” (or an equivalent one-line confirmation) without errors.

## Pitfalls

Typed events are not the entire state sent to the frontend — filter sensitive fields first. Subagent events are hidden by default and subscribed to when needed.
