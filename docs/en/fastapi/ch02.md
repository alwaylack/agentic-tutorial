# Chapter 2 · First Application and Automatic Documentation

> Chapter goals: master the correspondence between path operation decorators and HTTP verbs, understand route matching order, learn to use the three automatic artifacts: /docs, /redoc, and openapi.json.

## 2.1 Path Operation Decorators

"Path operation" refers to "which HTTP verb accesses which path." FastAPI declares them with decorators:

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/items")       # GET    read resources
def list_items():
    return [{"id": 1, "name": "apple"}]


@app.post("/items")      # POST   create resources
def create_item():
    return {"created": True}


@app.put("/items/{item_id}")     # PUT    full replacement
def replace_item(item_id: int):
    return {"replaced": item_id}


@app.patch("/items/{item_id}")   # PATCH  partial update
def update_item(item_id: int):
    return {"patched": item_id}


@app.delete("/items/{item_id}")  # DELETE  remove
def remove_item(item_id: int):
    return {"deleted": item_id}
```

`@app.get("/items")` does: tell FastAPI "when receiving a `GET /items` request, call the function below, and convert the return value to JSON to send back." Available verbs also include `head/options/trace`, but the five above are most common in REST APIs.

::: tip Decorator Parameters
Each decorator supports `response_model`, `status_code`, `tags`, `summary` and other parameters (starting from Chapter 6 these陆续登场), they only affect documentation and response behavior, not route matching itself.
:::

## 2.2 Route Matching Order Is "Top to Bottom"

FastAPI tries to match routes in declaration order. This creates a classic trap:

```python
app = FastAPI()


@app.get("/items/{item_id}")
def read_item(item_id: int):
    return {"item_id": item_id}


@app.get("/items/special")
def read_special():
    return {"special": True}
```

Requesting `/items/special` — FastAPI first tries to match the first route (`/items/{item_id}`), fails to parse `"special"` as an integer, returns 422. The correct approach: **put specific routes before generic routes**:

```python
@app.get("/items/special")     # match specific paths first
def read_special():
    return {"special": True}


@app.get("/items/{item_id}")   # then match generic paths
def read_item(item_id: int):
    return {"item_id": item_id}
```

## 2.3 Three Automatic Document Artifacts

After starting the application, FastAPI automatically provides three document endpoints:

| Endpoint | Purpose | Characteristics |
|---|---|---|
| `/docs` | Swagger UI | Interactive API docs, can test interfaces directly in browser |
| `/redoc` | ReDoc | Static rendered API docs, suitable for reading |
| `/openapi.json` | OpenAPI spec | JSON-structured description, for tools to generate client code |

```bash
# After starting the application, visit
curl http://127.0.0.1:8000/docs        # Swagger UI
curl http://127.0.0.1:8000/redoc       # ReDoc
curl http://127.0.0.1:8000/openapi.json # OpenAPI spec
```

::: tip Disable Documents
Can disable in production:
```python
app = FastAPI(docs_url=None, redoc_url=None, openapi_url=None)
```
:::

## 2.4 Chapter Summary

- Path operation decorators (`@app.get` etc.) declare HTTP verb to path mapping;
- Route matching is top-to-bottom, specific routes before generic routes;
- `/docs`, `/redoc`, `/openapi.json` three automatic document endpoints ready out-of-box;
- Production environments can disable document endpoints.
