# FastAPI Tutorial · Course Guide

This course covers **22 chapters** based on the **FastAPI 0.14x Official Documentation**, from zero foundation to production deployment.

## What You Will Learn

| Stage | Chapters | Content |
|---|---|---|
| Beginner | 01–06 | Environment setup, routing, path/query/body params, Pydantic validation, response models |
| Intermediate | 07–13 | Forms & files, error handling, dependency injection, middleware, database integration |
| Advanced | 14–20 | OAuth2/JWT security, async concurrency, WebSocket, templates, large project structure, testing |
| Production | 21–22 | Configuration management (Pydantic Settings), lifespan, Docker & deployment |

## How It Connects to Other Courses

- Chapter 20's testing chapter pairs with the [pytest course](/en/pytest/);
- Chapter 18's template rendering complements frontend framework courses.
