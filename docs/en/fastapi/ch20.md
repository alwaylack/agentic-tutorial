# Chapter 20 · Testing FastAPI Applications

> Chapter goals: write automated tests for FastAPI applications using `TestClient` + pytest; master dependency overrides, lifespan testing, and WebSocket/file upload测试.

## 20.1 TestClient Basics

FastAPI, built on Starlette's `TestClient` (powered by HTTPX), **doesn't need to actually start a server or occupy a port** — it calls the ASGI application directly within the process:

```bash
uv add httpx pytest   # TestClient requires httpx
```

```python
# main.py
from fastapi import FastAPI

app = FastAPI()


@app.get("/")
async def read_main():
    return {"msg": "Hello World"}
```

```python
# test_main.py
from fastapi.testclient import TestClient
from .main import app  # relative import when in the same package as main.py

client = TestClient(app)  # pass the app to TestClient


def test_read_main():
    response = client.get("/")
    assert response.status_code == 200
    assert response.json() == {"msg": "Hello World"}
```

Run `pytest`. Three key conventions:

- Test functions use plain `def`, **not** `async def`; calling the client doesn't require `await` — this lets you run tests directly with pytest, no extra plugin needed;
- `TestClient` usage is identical to httpx: paths/query params拼into the URL, JSON body via the `json` parameter, forms via `data`, request headers via `headers`, cookies via `cookies`;
- The data you send should be "objects convertible to JSON," not Pydantic models; if you have a model, convert with `jsonable_encoder` first.

::: tip
You can also `from starlette.testclient import TestClient` — `fastapi.testclient` is just a convenient re-export of the same object.
:::

## 20.2 Organizing Tests with pytest Fixtures

Real-world apps may need lifespan to initialize resources. Put the client in a fixture, and use the `with` statement to **trigger the lifespan during tests**:

```python
import pytest
from fastapi.testclient import TestClient
from .main import app


@pytest.fixture
def client():
    # Enter the with block to execute startup (first half of lifespan)
    # Exit to execute shutdown (second half of lifespan), e.g., close connection pools
    with TestClient(app) as c:
        yield c


def test_health(client):
    assert client.get("/health").status_code == 200
```

Without `with`, TestClient won't run the lifespan — this is the most common reason for "why isn't the database initialized in tests."

## 20.3 dependency_overrides: Replacing Dependencies

When testing external services (paid auth providers, databases), you shouldn't actually call them. FastAPI provides the `app.dependency_overrides` dict: **key is the original dependency function, value is the replacement** — the original dependency's sub-dependencies also won't execute:

```python
# main.py
from fastapi import Depends, FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()


class User(BaseModel):
    username: str


async def verify_token_from_provider(token: str):  # simulate expensive third-party auth
    raise HTTPException(status_code=401)


async def get_current_user(user=Depends(verify_token_from_provider)):
    return user


@app.get("/me")
async def me(user: User = Depends(get_current_user)):
    return user
```

```python
# test_main.py
from fastapi.testclient import TestClient
from fastapi import Depends
from .main import app, get_current_user

client = TestClient(app)


def fake_user():
    return {"username": "test_user"}  # always-succeeding mock user


def test_me_with_override():
    app.dependency_overrides[get_current_user] = fake_user
    resp = client.get("/me")
    assert resp.status_code == 200
    assert resp.json() == {"username": "test_user"}
    app.dependency_overrides.clear()  # clear to restore original dependencies
```

Key points:

- No matter where the original dependency is used — path function parameters, decorator `dependencies=[...]`, or `include_router` — it can be overridden;
- To replace only in individual tests, set the override at the start of that test and `clear()` or set to `{}` at the end;
- This is also the standard technique for swapping in test databases: override `get_db` to return an in-memory SQLite session.

## 20.4 Testing WebSockets and File Uploads

### WebSocket Testing

Also use `TestClient`, establishing a **session context** via `websocket_connect`:

```python
# Already defined in main.py
@app.websocket("/ws")
async def ws(websocket):
    await websocket.accept()
    await websocket.send_text("hello")
    msg = await websocket.receive_text()
    await websocket.send_text(f"echo: {msg}")
    await websocket.close()
```

```python
# test_ws.py
from fastapi.testclient import TestClient
from .main import app


def test_websocket_echo():
    client = TestClient(app)
    with client.websocket_connect("/ws") as ws:
        assert ws.receive_text() == "hello"
        ws.send_text("world")
        assert ws.receive_text() == "echo: world"
```

Within the `with` block, sends and receives must alternate to match server behavior: first `receive_text()` to get "hello", then send, then receive the echo.

### File Uploads and Form Testing

httpx style: files via the `files` parameter, form fields via `data`:

```python
from fastapi import FastAPI, UploadFile, File, Form

app = FastAPI()


@app.post("/upload")
async def upload(file: UploadFile, note: str = Form(...)):
    content = await file.read()
    return {"filename": file.filename, "size": len(content), "note": note}
```

```python
def test_upload():
    client = TestClient(app)
    resp = client.post(
        "/upload",
        files={"file": ("report.txt", b"hello data", "text/plain")},
        data={"note": "Quarterly report"},
    )
    assert resp.status_code == 200
    assert resp.json()["size"] == 10
    assert resp.json()["filename"] == "report.txt"
```

## 20.5 Chapter Summary

- `TestClient(app)` connects directly to the ASGI application in-process; test functions use synchronous `def`; no server startup required;
- Parameter passing follows httpx rules: `json`/`data`/`headers`/`cookies`/`files`; Pydantic models需经 `jsonable_encoder` first;
- `with TestClient(app)` triggers lifespan startup/shutdown; WebSocket testing uses `with client.websocket_connect(...)`;
- `app.dependency_overrides[original_dep] = replacement_func` can replace dependencies anywhere (including sub-dependencies短路); remember to `clear()` when done;
- Swapping databases and skipping third-party auth both rely on dependency overrides.
