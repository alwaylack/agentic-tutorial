# Chapter 3 · Path Parameters and Query Parameters

> Chapter goals: master path parameter type conversion and validation, optional/required/list query parameter declarations, and FastAPI's recognition rules and common pitfalls when mixing both.

## 3.1 Path Parameters and Automatic Type Conversion

The `{}` placeholders in the path are path parameters; FastAPI parses and validates them according to the function signature's type annotations:

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
def read_item(item_id: int):
    # annotated as int: auto-converts when requesting /items/5;
    # returns 422 validation error when requesting /items/abc, never enters the function body
    return {"item_id": item_id}
```

Requesting `/items/abc` yields a structured error (HTTP status 422):

```json
{
  "detail": [
    {
      "type": "int_parsing",
      "loc": ["path", "item_id"],
      "msg": "Input should be a valid integer, unable to parse string as an integer"
    }
  ]
}
```

This is "types as validation": every type annotation you write serves as both a runtime defense and documentation.

## 3.2 Constrain Values with Enum

To restrict a path parameter to a fixed set of values, use an enum:

```python
from enum import Enum
from fastapi import FastAPI

app = FastAPI()


class ModelName(str, Enum):
    # inherit str so members participate directly in string comparison and serialization
    alexnet = "alexnet"
    resnet = "resnet"
    lenet = "lenet"


@app.get("/models/{model_name}")
def get_model(model_name: ModelName):
    if model_name is ModelName.alexnet:
        return {"model": model_name, "message": "Deep Learning FTW!"}
    return {"model": model_name, "message": "Have some residuals"}
```

## 3.3 Query Parameters

Parameters not in the path become query parameters by default:

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/")
def read_items(skip: int = 0, limit: int = 10):
    return {"skip": skip, "limit": limit}
```

Visiting `/items/?skip=5&limit=20` passes parameters. Optional parameters get default values, required parameters don't:

```python
@app.get("/items/{item_id}")
def read_item(item_id: int, q: str | None = None):
    # q is optional; item_id is required (path parameters are naturally required)
    if q:
        return {"item_id": item_id, "q": q}
    return {"item_id": item_id}
```

::: tip Parameter Recognition Rules
FastAPI distinguishes path parameters from query parameters by "path placeholder vs function parameter name":
- Function parameter name matches path `{}` → path parameter
- Function parameter name not in path → query parameter (optional with default, required without)
:::

## 3.4 Chapter Summary

- Path parameters declared with `{param}`, type annotations drive automatic conversion and validation;
- Enum classes constrain fixed values, prevent invalid strings from entering business logic;
- Non-path parameters default to query parameters, default values determine optional/required;
- Route matching order: specific routes first, generic routes last.
