# Chapter 4 · Request Body and Pydantic Models

> Chapter goals: learn to declare request bodies with Pydantic BaseModel, master nested models, Body(embed), multiple body parameters, and FastAPI's parameter recognition system.

## 4.1 Defining Request Bodies with BaseModel

When clients submit data to the API, they use request bodies (usually JSON). FastAPI requires declaring them with Pydantic models:

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()


class Item(BaseModel):
    name: str                 # required
    description: str | None = None   # optional, default None
    price: float              # required
    tax: float | None = None  # optional


@app.post("/items/")
def create_item(item: Item):
    # item is already a validated Pydantic object, attributes fully typed
    return {"name": item.name, "price_with_tax": item.price + (item.tax or 0)}
```

After declaration FastAPI automatically does six things:

1. Parse JSON from the request body
2. Validate against the model schema
3. Convert types (e.g., string "10.5" → float 10.5)
4. Inject the model instance into the path operation function
5. Generate OpenAPI documentation
6. Return 422 on validation errors

## 4.2 Nested Models

Models can nest arbitrarily:

```python
from pydantic import BaseModel

class Address(BaseModel):
    street: str
    city: str
    zip_code: str


class User(BaseModel):
    name: str
    address: Address          # nested model


@app.post("/users/")
def create_user(user: User):
    return {"name": user.name, "city": user.address.city}
```

请求体：
```json
{
  "name": "John",
  "address": {
    "street": "123 Main St",
    "city": "Springfield",
    "zip_code": "62701"
  }
}
```

## 4.3 Body(embed) and Multiple Body Parameters

By default FastAPI wraps a single body parameter in a JSON object. To send flat JSON, use `Body(embed=False)`:

```python
from fastapi import FastAPI, Body
from pydantic import BaseModel

app = FastAPI()


class Item(BaseModel):
    name: str
    price: float


@app.post("/items/")
def create_item(item: Item = Body(embed=False)):
    # 请求体直接是 {"name": "...", "price": ...} 而非 {"item": {...}}
    return item
```

多 body 参数时，每个都需显式声明为 Body：

```python
@app.post("/items/")
def create_item(
    item: Item = Body(...),
    user_id: int = Body(...)
):
    return {"item": item, "user_id": user_id}
```

## 4.4 本章小结

- Pydantic BaseModel 声明请求体，自动完成解析/校验/转换/文档；
- 嵌套模型支持任意深度；
- `Body(embed=False)` 发送扁平 JSON；
- 多 body 参数需每个都用 `Body(...)` 显式标记。
