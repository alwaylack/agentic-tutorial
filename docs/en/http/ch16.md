# Chapter 16 · Performance Optimization and Resource Management

> Chapter goals: master connection pooling, caching, compression, and other optimization techniques to boost HTTP client performance.

## 16.1 Connection Pool Configuration

```python
import requests
from requests.adapters import HTTPAdapter

session = requests.Session()

# 精细控制连接池
adapter = HTTPAdapter(
    pool_connections=20,      # 连接池数量
    pool_maxsize=100,         # 最大连接数
    max_retries=3             # 失败重试
)
session.mount('https://', adapter)
session.mount('http://', adapter)
```

## 16.2 Response Caching

```python
import requests
from requests_cache import CachedSession

# 启用磁盘缓存
session = CachedSession('cache.sqlite', expire_after=3600)

# 相同请求自动返回缓存
resp1 = session.get('https://api.example.com/data')  # 真实请求
resp2 = session.get('https://api.example.com/data')  # 缓存命中
```

## 16.3 Transfer Compression

```python
import requests

# 自动处理 gzip/deflate 压缩
resp = requests.get('https://api.example.com/large-data')
print(resp.headers['content-encoding'])  # gzip

# 请求时指定接受编码
resp = requests.get(
    'https://api.example.com/data',
    headers={'Accept-Encoding': 'gzip, deflate'}
)
```

## 16.4 httpx Performance Configuration

```python
import httpx

# 精细配置 Limits
limits = httpx.Limits(
    max_connections=100,           # 最大连接数
    max_keepalive_connections=20,  # 保持活跃连接数
    keepalive_expiry=30.0          # 保持活跃超时（秒）
)

with httpx.Client(limits=limits, timeout=10.0) as client:
    resp = client.get('https://httpbin.org/get')
```

## 16.5 Summary

- Connection reuse via pooling markedly improves multi-request performance;
- Response caching avoids repeated network calls;
- Transfer compression cuts bandwidth consumption;
- `httpx.Limits` gives fine-grained control over connection resources.
