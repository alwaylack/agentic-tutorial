# Chapter 13 · HTTP/2 and WebSocket

> Chapter goals: understand the multiplexing advantages of HTTP/2, and master httpx's HTTP/2 and WebSocket support.

## 13.1 HTTP/2 Multiplexing

HTTP/1.1 suffers from head-of-line blocking — one slow request blocks all subsequent ones. HTTP/2 solves this with multiplexing:

```bash
pip install "httpx[http2]"
```

```python
import httpx

# 启用 HTTP/2
client = httpx.Client(h2=True)
resp = client.get('https://httpbin.org/get')

# 多路复用：多个请求共享一个 TCP 连接
with httpx.Client(h2=True) as client:
    resp1 = client.get('https://api.github.com/users/octocat')
    resp2 = client.get('https://api.github.com/users/torvalds')
    # 两个请求在同一个连接上并发传输，互不阻塞
```

## 13.2 WebSocket Support

httpx ships a built-in WebSocket client:

```python
import httpx
import asyncio

async def websocket_demo():
    uri = "wss://echo.websocket.org"
    
    async with httpx.AsyncClient() as client:
        async with client.websocket_connect(uri) as ws:
            await ws.send_text("Hello, WebSocket!")
            response = await ws.receive_text()
            print(f"收到: {response}")  # 回显 "Hello, WebSocket!"

asyncio.run(websocket_demo())
```

## 13.3 Real-World Use Cases

```python
import httpx
import asyncio

class RealtimeMonitor:
    """实时监控 WebSocket 数据"""
    
    def __init__(self, url: str):
        self.url = url
        self.client = httpx.AsyncClient()
    
    async def connect(self):
        self.ws = await self.client.websocket_connect(self.url)
        await self.ws.send_text('subscribe: market_data')
    
    async def listen(self):
        async for message in self.ws.iter_text():
            print(f"收到: {message}")
            # 处理实时数据...
    
    async def close(self):
        await self.ws.close()
        await self.client.aclose()
```

## 13.4 Summary

- HTTP/2 multiplexing boosts concurrent performance while reducing connection count;
- httpx supports WebSocket natively — no extra libraries required;
- HTTP/2 needs an extra install: `pip install "httpx[http2]"`.
