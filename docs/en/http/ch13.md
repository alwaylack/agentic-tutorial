## 13.1 HTTP/2 Multiplexing

HTTP/1.1 has head-of-line blocking issues - one slow request blocks all subsequent requests. HTTP/2 solves this through multiplexing:

```bash
pip install "httpx[http2]"
```

```python
import httpx

# Enable HTTP/2
client = httpx.Client(h2=True)
resp = client.get('https://httpbin.org/get')

# Multiplexing: multiple requests share one TCP connection
with httpx.Client(h2=True) as client:
    resp1 = client.get('https://api.github.com/users/octocat')
    resp2 = client.get('https://api.github.com/users/torvalds')
    # Two requests transmitted concurrently on the same connection, not blocking each other
```

## 13.2 WebSocket Support

httpx has built-in WebSocket client:

```python
import httpx
import asyncio

async def websocket_demo():
    uri = "wss://echo.websocket.org"
    
    async with httpx.AsyncClient() as client:
        async with client.websocket_connect(uri) as ws:
            await ws.send_text("Hello, WebSocket!")
            response = await ws.receive_text()
            print(f"Received: {response}")  # Echo "Hello, WebSocket!"

asyncio.run(websocket_demo())
```

## 13.3 Real-World Application Scenarios

```python
import httpx
import asyncio

class RealtimeMonitor:
    """Real-time WebSocket data monitoring"""
    
    def __init__(self, url: str):
        self.url = url
        self.client = httpx.AsyncClient()
    
    async def connect(self):
        self.ws = await self.client.websocket_connect(self.url)
        await self.ws.send_text('subscribe: market_data')
    
    async def listen(self):
        async for message in self.ws.iter_text():
            print(f"Received: {message}")
            # Process real-time data...
    
    async def close(self):
        await self.ws.close()
        await self.client.aclose()
```

## 13.4 Chapter Summary

- HTTP/2 multiplexing improves concurrency performance, reducing connection count;
- httpx natively supports WebSocket without additional libraries;
- HTTP/2 requires extra installation: `pip install "httpx[http2]"`.
