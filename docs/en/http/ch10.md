# Chapter 10 · Introducing httpx and the Sync API

> Chapter goals: understand httpx's design philosophy, master the sync client, and compare it with requests.

## 10.1 Why httpx

requests is the de facto sync HTTP standard, but it has a fundamental limitation: **no async support**. As asyncio spread through the Python ecosystem, httpx emerged:

```python
# requests — sync only
import requests
resp = requests.get('https://api.github.com')  # blocks the thread

# httpx — one API for both sync and async
import httpx
# Sync usage (almost identical to requests)
resp = httpx.get('https://api.github.com')
```

## 10.2 Installation and Basic Usage


```python
import httpx

# The simplest GET request
resp = httpx.get('https://httpbin.org/get')
print(resp.status_code)    # 200
print(resp.json())         # automatic JSON parsing

# POST request
resp = httpx.post(
    'https://httpbin.org/post',
    json={'key': 'value'}
)
```

## 10.3 API Comparison with requests

| Operation | requests | httpx |
|---|---|---|
| GET | `requests.get(url)` | `httpx.get(url)` |
| POST JSON | `requests.post(url, json=data)` | `httpx.post(url, json=data)` |
| Query params | `requests.get(url, params={})` | `httpx.get(url, params={})` |
| Headers | `headers={'Key': 'Val'}` | `headers={'Key': 'Val'}` |
| Timeout | `timeout=10` | `timeout=10.0` |
| Session | `requests.Session()` | `httpx.Client()` |

::: tip Key difference
The httpx `timeout` accepts floats (seconds) or Timeout objects; requests accepts ints or `(connect, read)` tuples.
:::

## 10.4 The Client Object and Connection Pools

```python
import httpx

# Create a persistent client (reuses the connection pool)
with httpx.Client() as client:
    # All requests share the pool
    resp1 = client.get('https://api.github.com/users/octocat')
    resp2 = client.get('https://api.github.com/users/torvalds')

    # Inspect connection reuse
    print(client.transport)  # an HTTPConnectionPool instance
```

## 10.5 Chapter Summary

- httpx offers both sync and async APIs in a style highly compatible with requests;
- Use `httpx.Client()` for connection pooling — the counterpart of requests' Session;
- For developers who know requests, picking up httpx is nearly free.
