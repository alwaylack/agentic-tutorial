# Chapter 12 · Concurrent Requests and Concurrency Control

> Chapter goals: master rate limiting, throttling, and concurrency-level control for concurrent requests, and write robust high-concurrency HTTP clients.

## 12.1 More Concurrency Is Not Always Faster

Unbounded concurrency causes:
- Overloading the target server (you may get IP-banned)
- Exhausting local resources (file descriptors, memory)
- Triggering rate limits

## 12.2 Semaphore-Based Concurrency Control

```python
import asyncio
import httpx

async def fetch_with_semaphore(urls: list[str], max_concurrent: int = 5):
    """Limit the maximum number of concurrent tasks"""
    semaphore = asyncio.Semaphore(max_concurrent)
    
    async def limited_fetch(client: httpx.AsyncClient, url: str):
        async with semaphore:  # 控制并发度
            resp = await client.get(url)
            return resp.status_code
    
    async with httpx.AsyncClient() as client:
        tasks = [limited_fetch(client, url) for url in urls]
        return await asyncio.gather(*tasks)
```

## 12.3 Exponential Backoff Retry

```python
import asyncio
import random

async def retry_with_backoff(client: httpx.AsyncClient, url: str, max_retries: int = 3):
    """Retry with exponential backoff"""
    for attempt in range(max_retries):
        try:
            resp = await client.get(url)
            resp.raise_for_status()
            return resp.json()
        except httpx.HTTPStatusError as e:
            if e.response.status_code == 429:  # 速率限制
                wait = min(2 ** attempt + random.random(), 60)
                print(f'429 限制，等待 {wait:.1f}s...')
                await asyncio.sleep(wait)
            elif e.response.status_code >= 500 and attempt < max_retries - 1:
                await asyncio.sleep(2 ** attempt)
            else:
                raise
    return None
```

## 12.4 Batch Request Pattern

```python
import asyncio
import httpx
from typing import List, Callable, Any

async def batch_request(
    urls: List[str],
    handler: Callable[[httpx.AsyncClient, str], Any],
    concurrency: int = 10
) -> List[Any]:
    """Reusable batch request framework"""
    results = []
    semaphore = asyncio.Semaphore(concurrency)
    
    async def wrapped(url: str):
        async with semaphore:
            async with httpx.AsyncClient() as client:
                return await handler(client, url)
    
    tasks = [wrapped(url) for url in urls]
    return await asyncio.gather(*tasks, return_exceptions=True)

# 使用示例
async def main():
    urls = ['https://api.github.com/users/' + u for u in ['octocat', 'torvalds']]
    
    async def get_user(client, url):
        resp = await client.get(url)
        return resp.json()['login']
    
    results = await batch_request(urls, get_user, concurrency=5)
    for user in results:
        print(user)
```

## 12.5 Summary

- Use a Semaphore to cap concurrency and avoid crushing the server;
- Implement exponential backoff for 429 rate limits to prevent retry storms;
- A reusable batch-request framework improves code quality.
