# pytest Course · Guide

This course is built on the **pytest 9.x official documentation**, spanning **20 chapters** from zero basics all the way to production practice.

## What You Will Learn

| Stage | Chapters | Content |
|---|---|---|
| Getting started | 01–05 | Testing basics, assertions, organization & markers, parametrization |
| Intermediate | 06–11 | The full fixture toolbox, built-in fixtures, mocking, configuration files |
| Advanced | 12–18 | Plugin development, coverage, parallel execution, async testing, Hypothesis |
| Production | 19–20 | Web-service integration testing, CI and test governance |

## Prerequisites

- Basic Python syntax (functions, classes, module imports);
- Python 3.10+ installed locally.

## How to Study

1. Read each chapter's explanations and type out the example code yourself;
2. Take the quiz (wrong answers reveal the correct choice and why);
3. Finish the 3 hands-on exercises before moving to the next chapter.

👉 Start from [Chapter 1](/en/pytest/ch01.html).
