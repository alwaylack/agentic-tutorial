# Chapter 10 · Team Advanced: Shared State and Member Communication

> Chapter goals: master switching among the four collaboration modes; learn the correct姿势 for shared session state between members; observe团队内部分工 via streaming events.

## 10.1 Overview of Four Collaboration Modes

In the previous chapter we used `mode=TeamMode.coordinate` to让 leader dispatch tasks. Agno explicitly manifests four协作风格 as modes (`from agno.team.mode import TeamMode`):

| Mode | Config | Behavior |
|---|---|---|
| Coordinate (default) | Do not set `mode` or set `coordinate` | Leader picks members,改写任务, and汇总结果 |
| Route | `mode=TeamMode.route` | Leader路由 to one member; **直接返回该成员的回复** |
| Broadcast | `mode=TeamMode.broadcast` | Send the same task to all members |
| Tasks | `mode=TeamMode.tasks` | Leader维护共享任务清单循环执行 until完成 |

::: warning On Legacy Parameters
Old `respond_directly=True` and `delegate_to_all_members=True` are still兼容 (mapping to `route` and `broadcast` respectively); but **新代码一律使用 `mode=`** — when both appear, `mode` overrides the legacy flags.
:::

## 10.2 Route Mode: Direct-to-Reply

Scenarios like客服分流, language routing do not need the leader to再加工结果; route mode has the lowest延迟:

```python
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.team import Team, TeamMode

model = OpenAIChat(
    id="deepseek-chat",
    api_key=os.getenv("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com/v1",
)

billing_agent = Agent(name="Billing Agent", role="Handle billing and refund issues", model=model)
tech_agent = Agent(name="Tech Agent", role="Handle technical故障 issues", model=model)

router_team = Team(
    name="Customer Router",
    model=model,
    mode=TeamMode.route,
    members=[billing_agent, tech_agent],
    # Key switch: pass the user\'s原话直传 to members without leader改写
    determine_input_for_members=False,
    instructions=["Route the request to the most合适的 member; answer yourself if无法判断."],
)

router_team.print_response("My order was charged twice", stream=True)
```

`determine_input_for_members=False` is an important detail of route mode: without it the leader默认仍会为成员"润色"任务描述; in scenarios needing原话透传 this反而引入失真.

## 10.3 Broadcast and Tasks Modes

Broadcast suits "多视角并行评审"; task loops suit目标驱动的长流程:

```python
from agno.team import Team, TeamMode

# Broadcast: three reviewers同时收到同一篇稿子
review_team = Team(
    name="Review Panel",
    model=model,
    mode=TeamMode.broadcast,   # Send the same task to each member
    members=[
        Agent(name="Legal Reviewer", role="Review from a compliance perspective", model=model),
        Agent(name="UX Reviewer", role="Review from a UX perspective", model=model),
        Agent(name="SEO Reviewer", role="Review from a search optimization perspective", model=model),
    ],
    instructions="汇总所有成员意见; output a merged修改清单.",
)

# Task loop: leader拆解任务清单 and推进逐项
ops_team = Team(
    name="Ops Team",
    model=model,
    mode=TeamMode.tasks,
    max_iterations=6,          # Cap the task loop轮数 to prevent失控烧 token
    members=[tech_agent, billing_agent],
)
```

For Tasks mode务必设置 `max_iterations`: the task list is generated and checked off by the模型 itself; a loop without上限 equals handing the预算 to the model.

## 10.4 Shared Session State Between Members

To have multiple members协作 around同一份可变状态 (e.g.,共同维护一张购物清单), the core is three things: **declare `session_state` on the team, enable `add_session_state_to_context`, and share同一个数据库 between the team and members**:

```python
import os
from agno.agent import Agent
from agno.db.sqlite import SqliteDb
from agno.models.openai import OpenAIChat
from agno.team import Team

db = SqliteDb(db_file="tmp/team.db")
model = OpenAIChat(
    id="deepseek-chat",
    api_key=os.getenv("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com/v1",
)

shopping_agent = Agent(
    id="shopping-agent",
    name="Shopping List Agent",
    role="Manage the shopping list",
    model=model,
    db=db,                                    # Must share the same db with the team to共享会话
    add_session_state_to_context=True,        # Let members see the session state
    enable_agentic_state=True,                # Allow members to自主修改 state during对话
)

team = Team(
    name="Household Team",
    members=[shopping_agent],
    session_state={"shopping_list": []},      # Initial shared state
    db=db,
    add_session_state_to_context=True,
    enable_agentic_state=True,
    description="You are a team managing the shopping list and household chores",
    show_members_responses=True,
)

team.print_response("Add milk, eggs, and bread to the shopping list")
team.print_response("I already bought eggs; what is on the list now?")

print(f"Final state: {team.get_session_state()}")
```

Another轻量技巧 is **template injection** — state variables can be written directly into instructions and auto-replaced at runtime:

```python
team = Team(
    members=[],
    session_state={"user_name": "Xiao Ming"},
    instructions="The user\'s name is {user_name}; address them by name.",
    markdown=True,
)
```

## 10.5 Observing分工: Streaming Events and Member Responses

The key to debugging a team is看清 "who is doing the work". Three手段配合使用:

```python
team = Team(
    name="Research Team",
    model=model,
    members=[news_agent, finance_agent],
    markdown=True,
    show_members_responses=True,   # Attach each member\'s原始回复 in the final output
)

# With stream=True you can observe the full process: leader委派 -> member执行 -> leader汇总
for event in team.run("What are the recent developments in AI companies and how is NVDA performing?", stream=True):
    print(event)   # Member startup, tool calls, content增量 all have对应事件
```

Three配套最佳实践:

1. **Set显式 `id` for members**: delegation选择 and运行追踪 both use member id for定位; more稳定 than靠 name;
2. **Model inheritance**: when a member未设置 `model`, it自动继承 team\'s model — this让"成员用小模型、leader用大模型"的档位只需一行省略;
3. **Callable factories**: `members=` can接受函数; dynamically决定阵容按 `session_state` on each run (remember to配 `cache_callables=False`).

## 10.6 Chapter Summary

- New code统一用 `mode=TeamMode.coordinate/route/broadcast/tasks`; legacy flag `respond_directly` is replaced by the override mechanism;
- Route mode配 `determine_input_for_members=False` can透传 user输入原样;
- Full conditions for shared state: team and members share `db` + both set `add_session_state_to_context=True` +开 `enable_agentic_state=True` when自主修改 is needed;
- instructions support `{var}` template injection for session state;
- `show_members_responses` + streaming events + explicit member `id` are the三板斧 for观察团队分工.
