# Chapter 10 · Team 进阶：共享状态and成员通信

> Chapter goals：Master Team 四种协作模式切换、成员间共享 session state 正确姿势，以及如何through流式事件观察团队内部分工。

## 10.1 四种协作模式总览

上一章我们using `mode=TeamMode.coordinate` 让 leader 分派任务。Agno 协作风格显式化to四种模式（`from agno.team.mode import TeamMode`）：

| 模式 | Configuration | 行to |
|---|---|---|
| Coordinate（默认） | 不设 `mode` 或设 `coordinate` | Leader 选人、改写任务、汇总结果 |
| Route | `mode=TeamMode.route` | Leader 路由给一个成员，**直接返回该成员回复** |
| Broadcast | `mode=TeamMode.broadcast` | 同一任务发给所has成员 |
| Tasks | `mode=TeamMode.tasks` | Leader 维护共享任务清单循环执行，直to完成 |

::: warning about遗留参数
旧版本 `respond_directly=True` and `delegate_to_all_members=True` 仍然兼容（分别映射to `route` and `broadcast`），但**新代码一律使using `mode=`**——当两者at the same time出现时 `mode` 会覆盖遗留标志。
:::

## 10.2 Route 模式：直达回复

客服分流、语言路由这类场景不需要 leader 再加工结果，using route 模式延迟最低：

```python
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.team import Team, TeamMode

model = OpenAIChat(
    id="deepseek-chat",
    api_key=os.getenv("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com/v1",
)

billing_agent = Agent(name="Billing Agent", role="处理账单、退款类问题", model=model)
tech_agent = Agent(name="Tech Agent", role="处理技术故障类问题", model=model)

router_team = Team(
    name="Customer Router",
    model=model,
    mode=TeamMode.route,
    members=[billing_agent, tech_agent],
    # 关键开关：using户原始输入原样传给成员，不再由 leader 改写
    determine_input_for_members=False,
    instructions=["请求路由to最合适成员；无法判断时自行回答。"],
)

router_team.print_("我订单被扣款两次", stream=True)
```

`determine_input_for_members=False` is route 模式重要细节：不设置它时 leader 默认仍会to成员"润色"任务描述，这需要原话透传场景反而引入失真。

## 10.3 Broadcast and Tasks 模式

广播适合"多视角并行评审"，任务循环适合目标驱动长流程：

```python
from agno.team import Team, TeamMode

# 广播：三个评审员at the same time收to同一篇稿子
review_team = Team(
    name="Review Panel",
    model=model,
    mode=TeamMode.broadcast,   # 同一任务发给每个成员
    members=[
        Agent(name="Legal Reviewer", role="from合规角度评审", model=model),
        Agent(name="UX Reviewer", role="fromusing户体验角度评审", model=model),
        Agent(name="SEO Reviewer", role="from搜索优化角度评审", model=model),
    ],
    instructions="汇总所has成员意见，输出一份合并后修改清单。",
)

# 任务循环：leader 拆解任务清单并逐项推进
ops_team = Team(
    name="Ops Team",
    model=model,
    mode=TeamMode.tasks,
    max_iterations=6,          # 限制任务循环轮数上限，防止失控烧 token
    members=[tech_agent, billing_agent],
)
```

Tasks 模式务必设置 `max_iterations`：任务清单is模型自己生成and勾选，没has上限循环等于预算交给模型。

## 10.4 成员间共享 Session State

让多个成员围绕同一份可变状态协作（such as共同维护一张购物清单），核心is三件事：**team 上声明 `session_state`、打开 `add_session_state_to_context`、team and成员共using同一个数据库**：

```python
import os
from agno.agent import Agent
from agno.db.sqlite import SqliteDb
from agno.models.openai import OpenAIChat
from agno.team import Team

db = SqliteDb(db_file="tmp/team.db")
model = OpenAIChat(
    id="deepseek-chat",
    api_key=os.getenv("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com/v1",
)

shopping_agent = Agent(
    id="shopping-agent",
    name="Shopping List Agent",
    role="管理购物清单",
    model=model,
    db=db,                                    # and team 共using同一 db 才能共享会话
    add_session_state_to_context=True,        # 让成员能看to session state
    enable_agentic_state=True,                # 允许成员对话中自主修改 state
)

team = Team(
    name="Household Team",
    members=[shopping_agent],
    session_state={"shopping_list": []},      # 初始共享状态
    db=db,
    add_session_state_to_context=True,
    enable_agentic_state=True,
    description="你们is一个管理购物清单and家务团队",
    show_members_s=True,
)

team.print_("牛奶、鸡蛋and面包加进购物清单")
team.print_("鸡蛋我已经买，现清单上还has什么？")

print(f"最终状态: {team.get_session_state()}")
```

另一个轻量技巧is**模板注入**——state 变量可以直接写进 instructions，Running时自动替换：

```python
team = Team(
    members=[],
    session_state={"user_name": "小明"},
    instructions="using户名字is {user_name}，请using名字称呼他。",
    markdown=True,
)
```

## 10.5 观察分工：流式事件and成员响应

调试团队关键is看清"谁干活"。三个手段配合使using：

```python
team = Team(
    name="Research Team",
    model=model,
    members=[news_agent, finance_agent],
    markdown=True,
    show_members_s=True,   # 最终回复中附带各成员原始回复
)

# stream=True 时可以观察to leader 委派 -> 成员执行 -> leader 汇总全过程
for event in team.run("AI 公司最近动态and NVDA 股价表现如何？", stream=True):
    print(event)   # 成员启动、工具调using、内容增量都has对应事件
```

配套最佳实践还has三条：

1. **给成员设置显式 `id`**：委派选择andRunning追踪都using member id 定位，比靠 name 稳定；
2. **模型继承**：成员未设置 `model` 时自动继承 team 模型——这让"成员using小模型、leader using大模型"分档只需一行省略；
3. **callable factories**：`members=` 可以传函数，按 `session_state` 每次Running时动态决定阵容（记得配 `cache_callables=False`）。

## 10.6 Chapter Summary

- 新代码统一using `mode=TeamMode.coordinate/route/broadcast/tasks`，遗留标志 `respond_directly` 已被覆盖机制取代；
- Route 模式配 `determine_input_for_members=False` 可using户输入原样透传；
- 共享状态完整条件：team and成员共using `db` + 双方 `add_session_state_to_context=True` + 需要自主修改时开 `enable_agentic_state=True`；
- instructions 支持 `{var}` 模板注入 session state；
- `show_members_s` + 流式事件 + 显式 member `id` is观察团队分工三板斧。
