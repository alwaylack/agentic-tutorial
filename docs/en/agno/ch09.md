# Chapter 9 · Agent Team Introduction: Collaboration Modes

> Chapter goals: understand Agno Team\'s "leader-member" architecture; master the mechanisms and适用场景 of four collaboration modes — coordinate / route / broadcast / tasks; build a researcher + writer two-member team.

## 9.1 Why Teams Are Needed

A single Agent\'s context and角色定位 are limited: asking it to查资料, 写报告, and 审校 simultaneously makes the prompt increasingly臃肿, and the tools interfere with each other. **Team** splits tasks across multiple专职 Agents (members); a **leader model** is responsible for分派 and汇总 — like a小团队分工: each person专注 their own task; the leader is accountable for the最终交付.

::: warning When Not to Use a Team
Each dispatch in a Team is an独立的模型调用, bringing higher latency, token消耗, and协调复杂度. The official建议: if a single领域 can handle the task, use a single Agent; do not use multi-agent for its own sake.
:::

```python
from agno.agent import Agent
from agno.team import Team

team = Team(
    members=[
        Agent(name="English Support", role="Answer customer questions in English"),
        Agent(name="中文客服", role="Answer customer questions in Chinese"),
    ],
)
```

## 9.2 Four Collaboration Modes

Agno explicitly specifies the mode via the `mode` parameter (import `TeamMode` from `agno.team.mode`); the four modes决定领导者的分派路径:

| Mode | Config | Behavior |
|---|---|---|
| **Coordinate** (default) | `mode=TeamMode.coordinate` | Leader picks members,生成子任务 for each, then综合结果 |
| **Route** | `mode=TeamMode.route` | Leader路由 the request to the one最合适的 member; returns其结果 directly |
| **Broadcast** | `mode=TeamMode.broadcast` | Send the same task to **all** members; then汇总各方回答 |
| **Tasks** | `mode=TeamMode.tasks` | Leader维护共享任务清单;执行逐项 until the goal is met |

::: info Version Note
Early versions used two布尔开关 — `respond_directly=True` (equivalent to route) and `delegate_to_all_members=True` (equivalent to broadcast) — to express modes; now统一使用 `mode=` is recommended;旧标志仍然兼容 when mode is未设置.
:::

```python
from agno.team import Team, TeamMode

router_team = Team(
    name="Language Router",
    members=[english_agent, chinese_agent],
    mode=TeamMode.route,
    determine_input_for_members=False,   # Pass the user\'s原话直传 to members without leader改写
)
```

Selection口诀: **拆解综合选 coordinate, 分类转发选 route, 多角度交叉验证选 broadcast, 清单式推进选 tasks**.

```python
from agno.team import Team, TeamMode

# broadcast: send the same task to all members then汇总 (old写法 delegate_to_all_members=True)
review_team = Team(
    name="Multi-Perspective Review Panel",
    model=model,
    members=[lawyer, engineer, marketer],
    mode=TeamMode.broadcast,
)

# tasks: leader maintains a shared任务清单 and推进逐项; suits long链路交付
delivery_team = Team(
    name="Delivery Team",
    model=model,
    members=[planner, developer, tester],
    mode=TeamMode.tasks,
)
```

## 9.3 How the Leader Dispatches

The complete流程 under coordinate mode:

1. Team receives the user input;
2. The leader分析输入, deciding which members to委托;
3. The leader为每个选中成员**撰写具体子任务** (not a simple转发);
4. Members各自执行并返回结果 (members with no依赖可并发执行);
5. The leader综合所有产出成最终回复.

The leader can also调工具 directly or answer itself (简单问题不必惊动成员). Giving members stable显式 `id`s helps分派追踪 with调试.

## 9.4 Hands-On: Researcher + Writer Two-Member Team

```python
# research_writer_team.py
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.team import Team, TeamMode
from agno.tools.duckduckgo import DuckDuckGoTools

model = OpenAIChat(
    id="deepseek-chat",
    api_key=os.getenv("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com/v1",
)

researcher = Agent(
    name="Researcher",
    id="researcher",
    role="Responsible for searching online; output only facts and来源",
    tools=[DuckDuckGoTools()],           # Researcher专属工具: search
)

writer = Agent(
    name="Writer",
    id="writer",
    role="Responsible for改写 the material into a fluent Chinese short article;不做事实核查",
)

team = Team(
    name="Content Editorial Board",
    model=model,                          # The leader also needs a model for分派 and综合
    members=[researcher, writer],
    mode=TeamMode.coordinate,
    instructions=[
        "First委托 the researcher to收集素材; then hand the素材 to the writer to成文.",
        "最终输出 an article within 300 characters, with sources附.",
    ],
    markdown=True,
)

team.print_response("Introduce the core value of the MCP protocol")
```

After running,观察日志可以看到两阶段: first出现研究员的工具调用与返回, then the writer生成文章 based on the素材, and finally the leader润色输出.

## 9.5 Debugging and Cost Control

- **See the分派链路**: enable `debug_mode=True` or read each member\'s独立响应 and metrics; confirm whether the leader派给了对的成员;
- **收敛指令**: `instructions` must明确 "who goes first, what is the产出"; ambiguous instructions导致领导者来回摇摆;
- **Control规模**: member数量 typically 2–4 is ideal; for more角色, consider嵌套 Team or the固定编排 Workflow in the next chapter;
- **模型分级**: the leader can use a cheap and fast model; heavy work配强模型 to members as needed.

## 9.6 Chapter Summary

- Team = leader (dispatch/综合) + multiple专职 members (execution);本质 is trading额外模型调用 for职责分离;
- Four `TeamMode` modes: coordinate (拆解综合), route (单路转发), broadcast (全员并行), tasks (任务清单推进);优先用 `mode=`显式声明;
- Coordinate流程: analyze → pick members →写子任务 → members execute concurrently →综合回复;
- `determine_input_for_members=False` lets user输入原样直达成员;
- Do not up Team for tasks a single Agent can解决; watch latency and token成本.
