# Chapter 22 · MCP Protocol Integration

> Chapter goals: understand what problem MCP (Model Context Protocol) solves, learn to connect to MCP servers via stdio/SSE/Streamable HTTP using `MCPTools`, plug external tool capabilities into Agents plug-and-play, and守住安全边界.

## 22.1 What Is MCP

Each framework has its own tool format; every新系统接入 (GitHub, databases, file systems...) requires重写一遍封装. **MCP (Model Context Protocol)** is an open protocol initiated by Anthropic: the工具提供方 implements once as an **MCP Server**, and any MCP-supporting client (Agent frameworks, IDEs, chat apps) can directly发现 and call all its tools.

Analogy:

- Without MCP: every "Agent × external system" pair requires a定制集成, N×M integration cost;
- With MCP: the Server is written once (N+M), clients discover and call by标准.

Agno内置了完整的 MCP client 能力 (`from agno.tools.mcp import MCPTools`), supporting三种传输方式.

## 22.2 Stdio Connection to Local Servers

**stdio** is the default传输: Agno starts the MCP Server as a子进程, communicating via stdin/stdout; best suited for本机工具 (files, Git, local commands). Taking the official filesystem server as an example:

```python
# mcp_fs.py
import asyncio
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.tools.mcp import MCPTools

async def run():
    # Start npx @modelcontextprotocol/server-filesystem as a子进程,
    # limiting it to access only the ./docs directory
    mcp_tools = MCPTools(command="npx -y @modelcontextprotocol/server-filesystem ./docs")
    await mcp_tools.connect()          # Connect and pull the tool list from the server
    try:
        agent = Agent(
            model=OpenAIChat(
                id="deepseek-chat",
                api_key=os.getenv("DEEPSEEK_API_KEY"),
                base_url="https://api.deepseek.com/v1",
            ),
            tools=[mcp_tools],         # Pass like ordinary tools
            markdown=True,
        )
        await agent.aprint_response("List Markdown files under docs/ and summarize the first file's directory structure")
    finally:
        await mcp_tools.close()        # Must close the connection and回收子进程

asyncio.run(run())
```

```bash

```

## 22.3 Choosing Among Three Transports

| Transport | Connection target | Suitable scenarios |
|---|---|---|
| **stdio** | Local子进程 |本机 files/commands/Git等私有工具 |
| **SSE** | HTTP(S) server push |远程托管的旧版 MCP services |
| **Streamable HTTP** | Ordinary HTTP requests |远程连接 recommended方式, easy to scale and deploy |

For远程连接, pass URL类参数 instead of command, e.g., SSE uses `MCPTools(url="https://example.com/sse")`;具体参数以所用 server 的文档为准.

```python
import asyncio
from agno.tools.mcp import MCPTools

async def remote_tools():
    # Remote server: SSE transport, credentials via环境变量 not hardcoded
    sse_tools = MCPTools(url="https://mcp.example.com/sse")
    await sse_tools.connect()
    try:
        yield sse_tools        # Reuse the connection within the FastAPI request lifecycle
    finally:
        await sse_tools.close()
```

## 22.4 Mixing MCP Tools with Custom Tools

MCP tools can be freely混合 with自定义 tools and内置 Toolkits:

```python
agent = Agent(
    model=model,
    tools=[
        mcp_tools,                       # External tools from MCP servers
        get_current_user,                # Custom internal函数工具
        DuckDuckGoTools(),               # Agno built-in toolkit
    ],
)
```

This组合正是 MCP 的价值: **通用能力交给生态的 server, 业务逻辑自己写**,互不干扰.

## 22.5 Security Boundaries

While MCP大幅降低接入成本, it also amplifies供应链风险;务必守住四条边界:

1. **最小授权**: filesystem servers should only开放必要目录; database servers使用只读账号;
2. **来源可信**: only启用经过审计的 server packages; `npx -y` auto-downloads and执行任意代码;生产环境应固定版本号;
3. **敏感操作加确认**:叠加强制 confirmation for dangerous MCP tools using Chapter 21's机制 or guardrails;
4. **出口管控**: remote server URLs and凭证走环境变量/密钥管理, do not硬编码.

```python
from agno.guardrails import PIIDetectionGuardrail

# Stack Chapter 21's防线 onto MCP tools
safe_agent = Agent(
    model=model,
    tools=[mcp_tools],                      # Tool pool from external servers
    pre_hooks=[PIIDetectionGuardrail()],    # Sensitive info doesn't enter the model or external tools
    instructions=["Confirm the target path with the user before calling file tools."],
)
```

## 22.6 Chapter Summary

- MCP is an开放协议 for "implement the server once, all clients通用"; reduces N×M integration to N+M;
- `MCPTools(command=...)` + `connect()`/`close()`接入 stdio本地 servers; for远程 use SSE or Streamable HTTP;
- For multiple servers, use multiple独立的 `MCPTools` instances in parallel (`MultiMCPTools` is deprecated);
- MCP tools can be自由混合 with custom tools and内置 Toolkits passed to `tools=[...]`;
- Security is the第一优先级 for MCP落地: 最小授权, 可信来源, 危险操作确认.
