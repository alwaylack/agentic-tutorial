## 24.1 Metrics：

`RunOutput.metrics`  token 、、。"、"：

```python
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat

agent = Agent(
    model=OpenAIChat(
        id="deepseek-chat",
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        base_url="https://api.deepseek.com/v1",
    ),
    markdown=True,
)

response = agent.run("用三句话解释什么是向量检索")

m = response.metrics
print("输入 token:", m.input_tokens)
print("输出 token:", m.output_tokens)
print("总 token:", m.total_tokens)
print("耗时:", m.duration)
```
