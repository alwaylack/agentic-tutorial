## 12.1 Parallel: Concurrent Execution of Independent Steps

Steps within a `Parallel` block execute并发; outputs are **aggregated in配置顺序** and passed to the next step:

```python
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.workflow import Parallel, Step, StepInput, StepOutput, Workflow

model = OpenAIChat(
    id="deepseek-chat",
    api_key=os.getenv("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com/v1",
)

hackernews_researcher = Agent(name="HN Researcher", role="Find tech trends from HackerNews", model=model)
web_researcher = Agent(name="Web Researcher", role="Search web and official docs", model=model)
paper_researcher = Agent(name="Paper Researcher", role="Retrieve academic paper insights", model=model)

workflow = Workflow(
    name="parallel-research",
    steps=[
        Parallel(
            Step(name="hn", executor=hackernews_researcher),
            Step(name="web", executor=web_researcher),
            Step(name="papers", executor=paper_researcher),
            name="research",
        ),
        Step(name="synthesis", executor=writer),  # Receives the aggregated result from all three paths
    ],
)
```

The three research directions are互不依赖; executing concurrently压缩总耗时 to the水平 of the slowest path. Note: if parallel function steps need to写 session state, each branch should写不同的 key to避免竞态.

## 12.2 Condition: Conditional Branching

`Condition` uses an evaluator function to决定走哪条路; supports `else_steps` for the反向分支:

```python
from agno.workflow import Condition, Step, StepInput, StepOutput, Workflow


def is_technical_issue(step_input: StepInput) -> bool:
    text = str(step_input.input or "").lower()
    return any(kw in text for kw in ["error", "bug", "crash", "timeout"])


def diagnose(step_input: StepInput) -> StepOutput:
    return StepOutput(content=f"Technical diagnosis: {step_input.input}")


def general_support(step_input: StepInput) -> StepOutput:
    return StepOutput(content=f"General support reply: {step_input.input}")


workflow = Workflow(
    name="support-router",
    steps=[
        Condition(
            name="triage",
            evaluator=is_technical_issue,
            steps=[Step(name="diagnose", executor=diagnose)],          # True branch
            else_steps=[Step(name="general", executor=general_support)],  # False branch
        ),
        Step(name="follow_up", executor=log_and_reply),
    ],
)
```

The evaluator can be a sync/async Python function, a布尔值, or a CEL expression string. Compared to a Team\'s "模型自己决定派谁", the branching logic here is **代码 you write** — testable and复现.

## 12.3 Loop: Iterate Until达标

`Loop`重复执行内部步骤, until `end_condition` returns True or reaches `max_iterations` (default 3):

```python
from agno.workflow import Loop, Step, StepInput, StepOutput, Workflow


def draft_section(step_input: StepInput) -> StepOutput:
    prev = step_input.previous_step_content or str(step_input.input)
    return StepOutput(content=f"{prev}\n【Add a more specific argument】")


def quality_check(outputs: list[StepOutput]) -> bool:
    """Consider达标 if any iteration output exceeds 120 characters"""
    return any(len(str(o.content or "")) > 120 for o in outputs)


def final_edit(step_input: StepInput) -> StepOutput:
    return StepOutput(content=f"Final draft:\n{step_input.previous_step_content}")


workflow = Workflow(
    name="quality-loop",
    steps=[
        Loop(
            name="drafting-loop",
            steps=[Step(name="expand", executor=draft_section)],
            end_condition=quality_check,
            max_iterations=3,
            forward_iteration_output=True,  # Next round gets the previous round\'s output as previous_step_content
        ),
        Step(name="edit", executor=final_edit),
    ],
)
```

`forward_iteration_output=True` is the key to迭代累积: by default each round重新开始 from the原始输入; after enabling, the next round\'s `previous_step_content` is the previous round\'s result,实现"越写越长、逐轮打磨".

## 12.4 Router: Dynamic Path Selection

`Router`\'s selector函数返回**要走的一组步骤**, picking from `choices`:

```python
from typing import List
from agno.workflow import Router, Step
from agno.workflow.types import StepInput

tech_step = Step(name="tech_research", executor=hackernews_researcher)
general_step = Step(name="general_research", executor=web_researcher)


def research_router(step_input: StepInput) -> List[Step]:
    topic = (step_input.previous_step_content or step_input.input or "").lower()
    if any(kw in topic for kw in ["ai", "programming", "startup", "software"]):
        return [tech_step]     # Returns a list; can return multiple steps
    return [general_step]


workflow = Workflow(
    name="router-demo",
    steps=[
        Router(
            name="strategy",
            selector=research_router,
            choices=[tech_step, general_step],
        ),
        publish_step,
    ],
)
```

选型口诀: **布尔判断用 `Condition`, 多路择一用 `Router`**. Both can be嵌套组合 — e.g., a Loop nested inside a branch selected by the Router.

## 12.5 Hands-On Combo: Content Production Pipeline + Step-Level Structured IO

串联本章原语 into a real pipeline, and let each LLM step use `output_schema` to output Pydantic objects:

```python
from pydantic import BaseModel, Field


class Draft(BaseModel):
    title: str = Field(description="Article title")
    body: str = Field(description="Main text")
    word_count: int


class Review(BaseModel):
    approved: bool
    comments: list[str]


drafter = Agent(name="Drafter", model=model, output_schema=Draft,
                instructions=["Output the draft according to the schema"])
review_agent = Agent(name="Reviewer", model=model, output_schema=Review,
                     instructions=["Review the draft; approved indicates是否通过"])

content_workflow = Workflow(
    name="content-pipeline",
    steps=[
        Parallel(Step(name="collect_hn", executor=hackernews_researcher),
                 Step(name="collect_web", executor=web_researcher),
                 name="collect"),
        Step(name="draft", executor=drafter),
        Loop(
            name="revise-loop",
            steps=[Step(name="review", executor=review_agent)],
            end_condition=lambda outputs: all(
                getattr(o.content, "approved", False) for o in outputs
            ),
            max_iterations=3,
            forward_iteration_output=True,
        ),
        Step(name="publish", executor=publisher),
    ],
)
```

Each step\'s output is an object validated by Pydantic; downstream steps receive不再是"祈祷格式正确"的纯文本 — this is the分水岭 between production-grade Workflows and demos.

::: tip Class Executors
When初始化配置 or状态维护 is needed, implement a class with `__call__(self, step_input) -> StepOutput` as the executor; the instance复用于 multiple runs.
:::

## 12.6 Chapter Summary

- `Parallel` runs independent steps并发; aggregates outputs in order; parallel branches writing shared state should使用不同的 key;
- `Condition(evaluator, steps, else_steps)` implements testable确定性分支;
- `Loop` converges via `end_condition` + `max_iterations`; `forward_iteration_output=True`让迭代基于上一轮结果累积;
- `Router.selector` returns the list of Steps to execute; suited for多路择一;
- Step-level `output_schema`让结构化数据 in the entire pipeline.
