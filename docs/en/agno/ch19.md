# Chapter 19 · Reasoning and Thinking Models

> Chapter goals: understand two ways Agno lets "the model think one step further" —内置推理流程 and原生思考模型; learn to接入 DeepSeek-R1类 models via `reasoning_model`; judge what tasks are worth the推理开销.

## 19.1 Why Reasoning Is Needed

普通对话模型 is "think and output immediately": for多步数学, complex planning,逻辑陷阱类 tasks, it容易在第一步就走偏. The本质 of **reasoning** is to let the model first生成中间思考步骤 (draft,分解, self-check), then给出最终答案 —相当于把"思维过程" also变成了生成内容.

Agno provides两条路径:

1. **Built-in reasoning flow for Agents**: `reasoning=True`; let the Agent推理 step by step (Cop底层通过提示词 with多轮调用实现; `reasoning_min_steps`/`reasoning_max_steps`控制步数);
2. **Native thinking models**: directly use models like DeepSeek-R1 / deepseek-reasoner that自带思维链; or use the `reasoning_model` parameter to指定 a专用 model负责推理.

## 19.2 Direct Connection to Thinking Models

The simplest approach: just换 the model id to the thinking model; Agent code changes零改动:

```python
# reasoning_direct.py
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat

reasoning_agent = Agent(
    model=OpenAIChat(
        id="deepseek-reasoner",              # DeepSeek\'s thinking model
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        base_url="https://api.deepseek.com/v1",
    ),
    markdown=True,
)

reasoning_agent.print_response("A 3x3 magic square where each row, column, and diagonal sums to 15; give one filling method and验证.")
```

At runtime you will看到输出里先出现一段"思考过程" (思维链), then the最终答案. Note: thinking models通常不支持或不建议 simultaneously使用 `temperature` etc.采样参数干预; also not suited for低延迟场景.

## 19.3 Using reasoning_model to Combine "Dual Models"

The `reasoning_model` parameter lets you指定 an independent model专职推理; the主模型负责最终表达 —典型组合 is "cheap模型干杂活,推理模型啃硬骨头", or the reverse "推理模型出方案, cheap模型写报告":

```python
from agno.agent import Agent
from agno.models.openai import OpenAIChat

agent = Agent(
    # Main model:负责最终回复
    model=OpenAIChat(
        id="deepseek-chat",
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        base_url="https://api.deepseek.com/v1",
    ),
    # Reasoning model: first use it to逐步推演 when facing难题 (also accepts "provider:model_id" strings)
    reasoning_model=OpenAIChat(
        id="deepseek-reasoner",
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        base_url="https://api.deepseek.com/v1",
    ),
    reasoning_min_steps=1,
    reasoning_max_steps=10,   # Cap on推理步数;控制成本
    markdown=True,
)

agent.print_response("Three letters randomly put into three envelopes; what is the概率 all are misplaced? Give a完整推导.")
```

You can also开 only `reasoning=True` to let the Agent use the内置的分步推理流程 (`reasoning_agent` parameter can also传入 a自定义 Agent充当"推理器"); but note this显著增加调用轮数:

```python
stepwise_agent = Agent(
    model=OpenAIChat(
        id="deepseek-chat",
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        base_url="https://api.deepseek.com/v1",
    ),
    reasoning=True,          # Enable built-in分步推理流程
    reasoning_max_steps=6,   # Limit步数 to控制成本与耗时
    markdown=True,
)
```

## 19.4 The Cost of Reasoning and Suitable Scenarios

Reasoning is not a免费午餐; every "thinking more" means更多 token and longer延迟:

| Task type | Recommend reasoning? | Reason |
|---|---|---|
| Math/logic/constraint求解 | ✅ Strongly recommend | Thought chains显著提升正确率 |
| Multi-step planning, complex决策 | ✅ Recommend | Decomposition and self-check减少遗漏 |
| Chitchat, translation, format转换 | ❌ Not recommended | Purely增加延迟 and费用 |
| Simple RAG Q&A | ❌ Generally不 need | Retrieval质量才是瓶颈 |

::: warning Common Pitfalls
- Passing `reasoning=True` to a思考模型叠加内置推理流程 is equivalent to "推理套推理";成本翻倍且容易超时;
- Setting `reasoning_max_steps` too高可能让一次 `run()`挂起很久;生产环境务必配合超时;
- The思考模型\'s output mixes思维链内容; when doing结构化解析 only取最终答案字段.
:::

## 19.5 Collaboration with Tools and RAG

Reasoning and retrieval are互补能力: reasoning解决"怎么想"; RAG解决"知道什么". A典型组合 is letting the思考模型担任主控 in Agentic RAG — first推理出 "what information I need", then检索, then综合:

```python
agent = Agent(
    model=OpenAIChat(
        id="deepseek-reasoner",
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        base_url="https://api.deepseek.com/v1",
    ),
    knowledge=knowledge,          # Knowledge base built in Chapter 17
    search_knowledge=True,
    instructions=["First analyze what信息 the question needs; then检索 the知识基; finally answer with依据."],
    markdown=True,
)
```

## 19.6 Chapter Summary

- Reasoning = let the model生成中间思考步骤 before answering; can显著提升逻辑类任务正确率;
- Direct连接方式:换 model id to `deepseek-reasoner` etc.; zero code changes;
- `reasoning_model` can指定专职推理模型 for an Agent (supports Model objects or `provider:model_id` strings); `reasoning_min_steps`/`reasoning_max_steps`控制步数;
- Reasoning有真实成本:判断是否值得按任务类型; do not滥用 for simple tasks;
- Reasoning is正交 with RAG/tools;可组合使用.
