## 2.1 Installation Agno

Recommend always invirtual environment中开发，avoid pollutingsystem Python：

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -U agno python-dotenv
```

Verify installation：

```bash
python -c "import agno; print(agno.__version__)"
# 3.0.x（教程编写时最新大版本to 3.x）
```

::: warning Version Note
Agno since 2.x 起to 1.x has many breaking changes（如存储类from `agno.storage.sqlite.SqliteStorage` migrated to `agno.db.sqlite.SqliteDb`），3.x continues and consolidatesthis unified API——本课程覆盖all usage covered 3.x 下applies to。Many tutorials online are based on 1.x，please refer to this course and the official documentation。
:::

## 2.2 using .env 管理 API Key

**永远不要 Key 写死代码里**。项目根目录创建 `.env` 文件：

```text
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx
```

再创建 `.gitignore` 它排除出版本库。代码中using `python-dotenv` 加载：

```python
# load_env.py
import os
from dotenv import load_dotenv

load_dotenv()  # 读取当前目录 .env 并注入环境变量

key = os.getenv("DEEPSEEK_API_KEY")
print("Key 已加载：" + key[:6] + "..." if key else "未找to DEEPSEEK_API_KEY！")
```

## 2.3 First Agent：完整拆解

```python
# agent_01.py —— 你第一个 Agno Agent
import os
from dotenv import load_dotenv
from agno.agent import Agent
from agno.models.openai import OpenAIChat

load_dotenv()

agent = Agent(
    model=OpenAIChat(
        id="deepseek-chat",                              # third-party model模型 ID
        api_key=os.getenv("DEEPSEEK_API_KEY"),           # from环境变量读取密钥
        base_url="https://api.deepseek.com/v1",          # OpenAI 兼容端点
    ),
    instructions=["using简洁中文回答", "不确定时要明说"],
    markdown=True,
)

agent.print_("一句话介绍什么is AI Agent")
```

Running `python agent_01.py`，你会看to DeepSeek 回答被打印出来。逐个参数Understand：

- `id`：模型名称，由三方服务商定义（DeepSeek 还has思考模型 `deepseek-reasoner`）；
- `base_url`：兼容端点地址。换成 OpenRouter、通义、Kimi 等只需改这一行；
- `instructions`：behavior instructions列表，Agno 会它们组装进 system 消息；
- `markdown=True`：让输出按 Markdown rendering，in the terminal表格and代码块more readable。

if不想记 `base_url`，也可以使using Agno 提供generic class `OpenAILike`（位于 `agno.models.openai.like`），parameters are ly the same。

## 2.4 常见Connection Error Troubleshooting

初学者nine out of ten errors集中这三种情况：

```python
# debug_connection.py —— 三种典型错误复现andsince查
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat

def make_agent(base_url):
    return Agent(model=OpenAIChat(
        id="deepseek-chat",
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        base_url=base_url,
    ))

# 错误一：401 Unauthorized → Key not loaded或typo
# since查：os.getenv("DEEPSEEK_API_KEY") is否to None？

# 错误二：404 Not Found → base_url missing or extra path
# DeepSeek  format ends with /v1；写成 https://api.deepseek.com 会 404

# 错误三：model not found → id name does not match provider
# for example "deepseek-chat" 误写成 "deepseek_v3"

try:
    make_agent("https://api.deepseek.com/v1").run("ping")
    print("连接成功")
except Exception as e:
    print("失败原因：", e)
```

troubleshooting mantra：**先check Key（401），再check URL（404），最后check model name（400）**。

## 2.5 让First Agent more useful：加一个工具

不带工具 Agent 只能靠模型内部知识回答。加上搜索工具后，它能获取-time information——这is Agent andordinary chatbotwatershed：

```python
# agent_search.py —— 带搜索工具 Agent
import os
from dotenv import load_dotenv
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.tools.duckduckgo import DuckDuckGoTools

load_dotenv()

news_agent = Agent(
    model=OpenAIChat(
        id="deepseek-chat",
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        base_url="https://api.deepseek.com/v1",
    ),
    tools=[DuckDuckGoTools()],            # 注入 DuckDuckGo 搜索能力
    instructions=["先搜索最新信息再回答", "答案末尾列出参考链接"],
    markdown=True,
    show_tool_calls=True,                 # 输出中展示工具调using过程
)

news_agent.print_("今天has哪些about AI 新闻？", stream=True)
```

观察输出你会发现多一段tool call records：模型先请求调using搜索工具，Agno 执行后结果pass back给模型生成final ——这正isChapter 1讲Running循环。工具原理andsincedefinition methods第 7、8 章展开。

## 2.6 Chapter Summary

- virtual environment + `pip install -U agno` isstandard starting approach；本课程所hasusing法适using于 Agno 3.x，旧版 1.x API 已不兼容；
- API Key 一律走 `.env` + `python-dotenv`，严禁hard-coding；
- 接入third-party model = `OpenAIChat(id, api_key, base_url)`，switch provider只改 `base_url`；
- Connection Error Troubleshooting顺序：401 check Key → 404 check URL → 400 check model name；
- 加上 `tools=[...]` 后，Agent 就from"聊天"upgrade to"action"。
