# Chapter 2 · 环境搭建与第一个 Agent

> Chapter goals：Set up a reusable development environment，Run through the first DeepSeek-connected Agent，并Learn to troubleshootthree most common连接错误。

## 2.1 安装 Agno

Recommend always in虚拟环境中开发，avoid pollutingsystem Python：

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -U agno python-dotenv
```

Verify installation:

```bash
python -c "import agno; print(agno.__version__)"
# 3.0.x(the latest major version at time of writing is 3.x)
```

::: warning Version Note
Agno since 2.x 起to 1.x has many breaking changes（如存储类从 `agno.storage.sqlite.SqliteStorage` migrated to `agno.db.sqlite.SqliteDb`），3.x continues and consolidatesthis unified API——本课程覆盖的all usage covered 3.x 下applies to。Many online tutorials are based on 1.x，please refer to this course and the official documentation。
:::

## 2.2 Managing API Keys with .env

**Never hardcode keys in your code**。项目根目录创建 `.env` 文件：

```text
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx
```

再创建 `.gitignore` 把它排除出版本库。代码中用 `python-dotenv` 加载：

```python
# load_env.py
import os
from dotenv import load_dotenv

load_dotenv()  # Read .env from current directory and inject environment variables

key = os.getenv("DEEPSEEK_API_KEY")
print("Key loaded：" + key[:6] + "..." if key else "DEEPSEEK_API_KEY not found！")
```

## 2.3 第一个 Agent：完整拆解

```python
# agent_01.py —— your first Agno Agent
import os
from dotenv import load_dotenv
from agno.agent import Agent
from agno.models.openai import OpenAIChat

load_dotenv()

agent = Agent(
    model=OpenAIChat(
        id="deepseek-chat",                              # third-party model ID
        api_key=os.getenv("DEEPSEEK_API_KEY"),           # read key from environment variables
        base_url="https://api.deepseek.com/v1",          # OpenAI-compatible endpoint
    ),
    instructions=["answer concisely in Chinese", "be explicit when uncertain"],
    markdown=True,
)

agent.print_response("Introduce what an AI Agent is in one sentence")
```

运行 `python agent_01.py`，you will see the DeepSeek response printed。understand each parameter：

- `id`：model name defined by third-party providers（DeepSeek 还有reasoning model `deepseek-reasoner`）；
- `base_url`：compatible endpoint address。switch to OpenRouter, Tongyi, Kimi etc. by only changing this line；
- `instructions`：行为指令列表，Agno 会assemble them into system messages；
- `markdown=True`：render output as Markdown，tables and code blocks are more readable in terminal。

如果不想记 `base_url`，也可以使用 Agno provided generic class `OpenAILike`（位于 `agno.models.openai.like`），parameters are exactly the same。

## 2.4 常见连接错误排查

nine out of ten errors from beginners concentrate on these three situations：

```python
# debug_connection.py —— 三种典型错误的复现与since查
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat

def make_agent(base_url):
    return Agent(model=OpenAIChat(
        id="deepseek-chat",
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        base_url=base_url,
    ))

# 错误一：401 Unauthorized → Key not loaded or typo
# since查：os.getenv("DEEPSEEK_API_KEY") whether it is None？

# 错误二：404 Not Found → base_url missing or extra path
# DeepSeek correct format ends with /v1；写成 https://api.deepseek.com will return 404

# 错误三：model not found → id name does not match provider
# 例如把 "deepseek-chat" mistakenly written as "deepseek_v3"

try:
    make_agent("https://api.deepseek.com/v1").run("ping")
    print("连接成功")
except Exception as e:
    print("失败原因：", e)
```

排查口诀：**check Key first（401），then check URL（404），finally check model name（400）**。

## 2.5 Make the First Agent More Useful: Add a Tool

不带工具的 Agent can only rely on internal model knowledge。加上搜索工具后，它能get real-time information——这是 Agent 与watershed between ordinary chatbots：

```python
# agent_search.py —— Agent with search tool
import os
from dotenv import load_dotenv
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.tools.duckduckgo import DuckDuckGoTools

load_dotenv()

news_agent = Agent(
    model=OpenAIChat(
        id="deepseek-chat",
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        base_url="https://api.deepseek.com/v1",
    ),
    tools=[DuckDuckGoTools()],            # inject DuckDuckGo search capability
    instructions=["search for latest info first then answer", "list reference links at the end of answer"],
    markdown=True,
    show_tool_calls=True,                 # 在输出中show tool call process
)

news_agent.print_response("今天有哪些关于 AI 的新闻？", stream=True)
```

观察输出你会发现多了一段tool call records：模型先request to call search tool，after Agno executes, pass results back to model to generate final answer——这正是第 1 章讲的execution loop。工具的原理与since定义方法在第 7、8 章展开。

## 2.6 Chapter Summary

- 虚拟环境 + `pip install -U agno` 是标准起手式；all usage in this course applies to Agno 3.x，old 1.x API is incompatible；
- API Key 一律走 `.env` + `python-dotenv`，hard-coding is strictly prohibited；
- 接入三方模型 = `OpenAIChat(id, api_key, base_url)`，换服务商只改 `base_url`；
- connection error troubleshooting order: 401 check Key → 404 check URL → 400 check model name；
- 加上 `tools=[...]` 后，Agent 就从"聊天"升级为"行动"。
