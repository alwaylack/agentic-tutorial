# Chapter 2 · Environment Setup and First Agent

> Chapter goals: set up a reusable development environment, run your first Agent connected to DeepSeek, and learn to troubleshoot the three most common connection errors.

## 2.1 Installing Agno

We recommend always developing in a virtual environment to avoid polluting your system Python:

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -U agno python-dotenv
```

Verify the installation:

```bash
python -c "import agno; print(agno.__version__)"
# 3.0.x (the latest major version when this tutorial was written is 3.x)
```

::: warning Version Note
Agno has many breaking changes from 2.x to 1.x (e.g., storage classes migrated from `agno.storage.sqlite.SqliteStorage` to `agno.db.sqlite.SqliteDb`). Version 3.x continues and consolidates this unified API — all usage covered in this tutorial is applicable under 3.x. Many old tutorials online are based on 1.x; please refer to this tutorial and official documentation.
:::

## 2.2 Managing API Keys with .env

**Never hard-code keys in your code.** Create a `.env` file in your project root:

```text
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx
```

Then add it to `.gitignore` to exclude it from version control. Load it in code with `python-dotenv`:

```python
# load_env.py
import os
from dotenv import load_dotenv

load_dotenv()  # Read .env from current directory and inject environment variables

key = os.getenv("DEEPSEEK_API_KEY")
print("Key loaded: " + key[:6] + "..." if key else "DEEPSEEK_API_KEY not found!")
```

## 2.3 First Agent: Complete Breakdown

```python
# agent_01.py —— Your first Agno Agent
import os
from dotenv import load_dotenv
from agno.agent import Agent
from agno.models.openai import OpenAIChat

load_dotenv()

agent = Agent(
    model=OpenAIChat(
        id="deepseek-chat",                              # Model ID for third-party models
        api_key=os.getenv("DEEPSEEK_API_KEY"),           # Read secret from environment variable
        base_url="https://api.deepseek.com/v1",          # OpenAI-compatible endpoint
    ),
    instructions=["Answer concisely in Chinese", "Say explicitly when unsure"],
    markdown=True,
)

agent.print_response("Introduce what an AI Agent is in one sentence")
```

Run `python agent_01.py`, and you'll see DeepSeek's reply printed out. Understand each parameter:

- `id`: Model name, defined by the third-party provider (DeepSeek also has a reasoning model `deepseek-reasoner`);
- `base_url`: Compatible endpoint address. Switch to OpenRouter, Tongyi, Kimi, etc. by changing just this line;
- `instructions`: Behavior instruction list; Agno assembles them into the system message;
- `markdown=True`: Renders output as Markdown, making tables and code blocks more readable in the terminal.

If you don't want to remember `base_url`, you can also use Agno's generic class `OpenAILike` (located at `agno.models.openai.like`) with identical parameters.

## 2.4 Troubleshooting Common Connection Errors

Beginners' ninety percent of errors concentrate on these three scenarios:

```python
# debug_connection.py —— Reproduction and self-check of three typical errors
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat

def make_agent(base_url):
    return Agent(model=OpenAIChat(
        id="deepseek-chat",
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        base_url=base_url,
    ))

# Error 1: 401 Unauthorized → Key not loaded or spelling error
# Self-check: Is os.getenv("DEEPSEEK_API_KEY") None?

# Error 2: 404 Not Found → base_url missing or extra path
# DeepSeek correct写法 ends with /v1; writing https://api.deepseek.com will 404

# Error 3: model not found → id inconsistent with provider's name
# E.g., mistakenly writing "deepseek_v3" instead of "deepseek-chat"

try:
    make_agent("https://api.deepseek.com/v1").run("ping")
    print("Connection successful")
except Exception as e:
    print("Failure reason:", e)
```

Troubleshooting mantra: **Check Key first (401), then URL (404), finally model name (400)**.

## 2.5 Making the First Agent More Useful: Add a Tool

An Agent without tools can only answer based on the model's internal knowledge. With a search tool added, it can fetch real-time information — this is the watershed between Agents and ordinary chatbots:

```python
# agent_search.py —— Agent with search tool
import os
from dotenv import load_dotenv
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.tools.duckduckgo import DuckDuckGoTools

load_dotenv()

news_agent = Agent(
    model=OpenAIChat(
        id="deepseek-chat",
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        base_url="https://api.deepseek.com/v1",
    ),
    tools=[DuckDuckGoTools()],            # Inject DuckDuckGo search capability
    instructions=["Search for latest info before answering", "List reference links at the end"],
    markdown=True,
    show_tool_calls=True,                 # Show tool call process in output
)

news_agent.print_response("What AI news is there today?", stream=True)
```

Observing the output, you'll see an additional tool call record: the model first requests calling the search tool, Agno executes it and feeds results back to the model to generate the final answer — this is exactly the run loop described in Chapter 1. Tool principles and customization are covered in Chapters 7 and 8.

## 2.6 Chapter Summary

- Virtual environment + `pip install -U agno` is the standard starting move; all usage in this tutorial applies to Agno 3.x; old 1.x APIs are no longer compatible;
- API Keys always go through `.env` + `python-dotenv`; hard-coding is strictly prohibited;
- Connecting with third-party models = `OpenAIChat(id, api_key, base_url)`; switching providers only requires changing `base_url`;
- Connection error troubleshooting order: 401 check Key → 404 check URL → 400 check model name;
- Adding `tools=[...]` upgrades the Agent from "chat" to "action."
