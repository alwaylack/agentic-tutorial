# Chapter 2 · Environment Setup and Your First Agent

> Chapter goals: set up a reusable development environment, run your first Agent connected to DeepSeek, and learn to troubleshoot the three most common connection errors.

## 2.1 Installing Agno

Always develop in a virtual environment to avoid polluting your system Python:

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -U agno python-dotenv
```

Verify the installation:

```bash
python -c "import agno; print(agno.__version__)"
# 3.0.x (the latest major version when this tutorial was written is 3.x)
```

::: warning Version Note
Agno has many breaking changes from 1.x to 2.x (e.g., storage classes migrated from `agno.storage.sqlite.SqliteStorage` to `agno.db.sqlite.SqliteDb`). Version 3.x continues and consolidates this unified API — all usage covered in this course applies to 3.x. There is a lot of old tutorial content online based on 1.x; follow this course and the official docs as the source of truth.
:::

## 2.2 Managing API Keys with .env

**Never hardcode Keys in code.** Create a `.env` file in the project root:

```text
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx
```

Then add it to `.gitignore` to keep it out of version control. Load it in code with `python-dotenv`:

```python
# load_env.py
import os
from dotenv import load_dotenv

load_dotenv()  # Reads the local .env and injects environment variables

key = os.getenv("DEEPSEEK_API_KEY")
print("Key loaded: " + key[:6] + "..." if key else "DEEPSEEK_API_KEY not found!")
```

## 2.3 First Agent: Full Breakdown

```python
# agent_01.py —— your first Agno Agent
import os
from dotenv import load_dotenv
from agno.agent import Agent
from agno.models.openai import OpenAIChat

load_dotenv()

agent = Agent(
    model=OpenAIChat(
        id="deepseek-chat",                              # Model ID defined by the third-party provider
        api_key=os.getenv("DEEPSEEK_API_KEY"),           # Read the key from environment variables
        base_url="https://api.deepseek.com/v1",          # OpenAI-compatible endpoint
    ),
    instructions=["Answer concisely in Chinese", "Say explicitly when unsure"],
    markdown=True,
)

agent.print_response("Introduce AI Agents in one sentence")
```

Run `python agent_01.py` and you will see DeepSeek\'s response printed. Understand each parameter:

- `id`: the model name, defined by the third-party provider (DeepSeek also has a reasoning model `deepseek-reasoner`);
- `base_url`: the compatible endpoint address. To switch to OpenRouter, Tongyi, Kimi, etc., just change this one line;
- `instructions`: a list of behavior directives; Agno assembles them into the system message;
- `markdown=True`: renders output as Markdown, making tables and code blocks more readable in the terminal.

If you do not want to remember `base_url`, you can also use the通用类 `OpenAILike` provided by Agno (located at `agno.models.openai.like`), with identical parameters.

## 2.4 Troubleshooting Common Connection Errors

Nine out of ten beginner errors fall into these three categories:

```python
# debug_connection.py —— reproduce and self-check three typical errors
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat

def make_agent(base_url):
    return Agent(model=OpenAIChat(
        id="deepseek-chat",
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        base_url=base_url,
    ))

# Error 1: 401 Unauthorized → Key not loaded or typo
# Self-check: is os.getenv("DEEPSEEK_API_KEY") None?

# Error 2: 404 Not Found → base_url is missing or has extra path segments
# The correct DeepSeek写法 ends with /v1; writing https://api.deepseek.com alone returns 404

# Error 3: model not found → id does not match the provider\'s naming
# e.g., mistakenly writing "deepseek_v3" instead of "deepseek-chat"

try:
    make_agent("https://api.deepseek.com/v1").run("ping")
    print("Connection successful")
except Exception as e:
    print("Failure reason:", e)
```

Troubleshooting mantra: **check the Key first (401), then the URL (404), and finally the model name (400)**.

## 2.5 Making Your First Agent More Useful: Add a Tool

An Agent without tools can only answer from the model\'s internal knowledge. Adding a search tool gives it real-time information access — this is the分水岭 between Agents and ordinary chatbots:

```python
# agent_search.py —— an Agent with a search tool
import os
from dotenv import load_dotenv
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.tools.duckduckgo import DuckDuckGoTools

load_dotenv()

news_agent = Agent(
    model=OpenAIChat(
        id="deepseek-chat",
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        base_url="https://api.deepseek.com/v1",
    ),
    tools=[DuckDuckGoTools()],            # Inject DuckDuckGo search capability
    instructions=["Search for the latest info before answering", "List reference links at the end of the answer"],
    markdown=True,
    show_tool_calls=True,                 # Display the tool call process in the output
)

news_agent.print_response("What AI news is there today?", stream=True)
```

In the output you will notice an added tool call记录: the model first请求调用搜索工具, Agno执行后把结果回传给模型生成最终答案 — this is exactly the running loop described in Chapter 1. The原理 of tools is expanded in Chapters 7 and 8.

## 2.6 Chapter Summary

- Virtual environment + `pip install -U agno` is the standard起手式; all usage in this course applies to Agno 3.x; the old 1.x API is no longer compatible;
- API Keys一律走 `.env` + `python-dotenv`;硬编码 is strictly forbidden;
- Connecting to a third-party model = `OpenAIChat(id, api_key, base_url)`; switching providers requires only changing `base_url`;
- Connection error troubleshooting order: 401 check Key → 404 check URL → 400 check model name;
- With `tools=[...]` added, the Agent upgrades from "chatting" to "acting".
