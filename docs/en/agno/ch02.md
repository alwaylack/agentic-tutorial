## 2.1 Install Agno

Recommend always invirtual environment，avoid pollutingsystem Python：

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -U agno python-dotenv
```

Verify installation：

```bash
python -c "import agno; print(agno.__version__)"
# 3.0.x（ 3.x）
```

::: warning Version Note
Agno since 2.x to 1.x has many breaking changes（ `agno.storage.sqlite.SqliteStorage` migrated to `agno.db.sqlite.SqliteDb`），3.x continues and consolidatesthis unified API——all usage covered 3.x applies to。Many tutorials online are based on 1.x，please refer to this course and the official documentation。
:::

## 2.3  Agent：

```python
# agent_01.py ——  Agno Agent
import os
from dotenv import load_dotenv
from agno.agent import Agent
from agno.models.openai import OpenAIChat

load_dotenv()

agent = Agent(
    model=OpenAIChat(
        id="deepseek-chat",                              #  ID
        api_key=os.getenv("DEEPSEEK_API_KEY"),           # environment variable
        base_url="https://api.deepseek.com/v1",          # OpenAI 
    ),
    instructions=["", ""],
    markdown=True,
)

agent.print_response(" AI Agent")
```

Run `python agent_01.py`， DeepSeek 。Understand：

- `id`：，（DeepSeek  `deepseek-reasoner`）；
- `base_url`：。 OpenRouter、、Kimi ；
- `instructions`：，Agno  system ；
- `markdown=True`：Output Markdown ，。

 `base_url`， Agno  `OpenAILike`（ `agno.models.openai.like`），。

## 2.4 ConnectionErrorTroubleshoot

：

```python
# debug_connection.py —— Errorsince
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat

def make_agent(base_url):
    return Agent(model=OpenAIChat(
        id="deepseek-chat",
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        base_url=base_url,
    ))

# Error：401 Unauthorized → Key Error
# since：os.getenv("DEEPSEEK_API_KEY")  None？

# Error：404 Not Found → base_url 
# DeepSeek  /v1 ； https://api.deepseek.com  404

# Error：model not found → id 
#  "deepseek-chat"  "deepseek_v3"

try:
    make_agent("https://api.deepseek.com/v1").run("ping")
    print("Connection")
except Exception as e:
    print("：", e)
```

Troubleshoot：** Key（401）， URL（404），（400）**。

## 2.5  Agent ：

 Agent 。，—— Agent ：

```python
# agent_search.py ——  Agent
import os
from dotenv import load_dotenv
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.tools.duckduckgo import DuckDuckGoTools

load_dotenv()

news_agent = Agent(
    model=OpenAIChat(
        id="deepseek-chat",
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        base_url="https://api.deepseek.com/v1",
    ),
    tools=[DuckDuckGoTools()],            #  DuckDuckGo 
    instructions=["", ""],
    markdown=True,
    show_tool_calls=True,                 # Output
)

news_agent.print_response(" AI ？", stream=True)
```
