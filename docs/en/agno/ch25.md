## 25.1 Model Tiered Routing: Let the Right Model Do the Right Job

The biggest生产成本 is "using a大模型 for a小模型's work". Tier by任务难度:

```python
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat

def make_model(model_id: str) -> OpenAIChat:
    """Unified third-party model factory: all tiers走同一个 OpenAI-compatible endpoint"""
    return OpenAIChat(
        id=model_id,
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        base_url="https://api.deepseek.com/v1",
    )

# Classification/extraction/formatting: small model, fast and cheap
classifier = Agent(
    name="Classifier",
    model=make_model("deepseek-chat"),
    output_schema=Category,           # Structured output naturally适合小模型
    instructions=["Classify the user request into question/complaint/other"],
)

# Complex reasoning/creation:大模型 or thinking model
analyst = Agent(
    name="Analyst",
    model=make_model("deepseek-reasoner"),
    instructions=["Perform root-cause analysis on user complaints and给出处理建议"],
)
```

配合第 12 章的 `Router`/`Condition`,实现 "小模型先分类、大模型只接难活"的漏斗结构. In Teams, only配 the leader with a大模型; members inherit or显式 use小模型.

## 25.2 Concurrency Throughput: asyncio.gather + arun

Agent-level并发 uses `arun()` with standard asyncio:

```python
import asyncio

async def analyze(symbol: str) -> str:
    result = await analyst.arun(f"Analyze the risk trend of {symbol} over the past week")
    return f"{symbol}: {result.content}"

async def main():
    symbols = ["AAPL", "NVDA", "TSLA", "AMZN"]
    # Run 4 analyses concurrently; total duration≈the slowest one, not the sum
    results = await asyncio.gather(*[analyze(s) for s in symbols])
    print("\n".join(results))

asyncio.run(main())
```

At the Workflow层面, use `Parallel` steps for自动并发 (see Chapter 12). Note: the并发上限 should match the provider's限流 —控制同时在飞的请求数 with `asyncio.Semaphore`.

## 25.3 Four Axes of Cost Control

1. **Tiered routing** (see 25.1) —通常能砍掉 50% 以上成本;
2. **Control上下文**: when `add_history_to_context=True`, use `num_history_runs` to限制带入的历史轮数,避免会话越长越贵;
3. **Limit tool loops**: set a `max_tool_calls`类上限 on Agents; set `max_iterations` on Teams' Tasks mode,防止单次运行失控;
4. **Use metrics as a预算门禁**: after each run,检查 `metrics.total_tokens`; when过预算, degrade to a小模型 or directly熔断.

```python
result = agent.run("Long task...")
if result.metrics and result.metrics.total_tokens > 50_000:
    # Log and alert: single run tokens exceed budget
    print("WARN: token over budget", result.metrics.total_tokens)
```

## 25.4 Evaluation (Evals): Turning Quality into Regression Tests

After changing prompts, switching models, or adjusting tools, how do you know youdidn't break the产品? Agno's official Evals turn预期行为 into可重复执行的 checks, runnable in both开发 and CI:

```python
from agno.agent import Agent
from agno.eval.accuracy import AccuracyEval

evaluation = AccuracyEval(
    name="calculator-accuracy",
    model=make_model("deepseek-chat"),
    agent=calc_agent,
    input="What is 10 factorial?",
    expected_output="3628800",
)

result = evaluation.run(print_results=True)
assert result is not None and result.avg_score >= 8
```

## 25.5 Dockerizing AgentOS Deployment

AgentOS is just a FastAPI application; containerization is非常直接:

```dockerfile
FROM python:3.12-slim AS base
WORKDIR /app

# Install dependencies first, leveraging layer caching
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 7777
# Production does not use reload; worker count adjusted per CPU
CMD ["uvicorn", "agent_os:app", "--host", "0.0.0.0", "--port", "7777", "--workers", "2"]
```

```yaml
# docker-compose.yml key snippet
services:
  agentos:
    build: .
    environment:
      - DEEPSEEK_API_KEY=${DEEPSEEK_API_KEY}   # Keys走环境变量, never into the image
    volumes:
      - agent-data:/app/tmp                     # SqliteDb file persists
  db:
    image: postgres:16                          # Production建议 PostgresDb instead of SQLite
volumes:
  agent-data:
```

生产要点:

- **密钥管理**: API Keys are注入 only via environment variables or a密钥管理服务; never hardcoded in code or the image;
- **数据库升级**: SQLite single-file suits开发; production switches to `PostgresDb` (sessions, memory, tracing share or separate databases);
- **Enable authorization and tracing**: `authorization=True` + `tracing=True` (Chapters 22, 23);
- **Health checks**: configure liveness probes on the `/info` endpoint.

## 25.7 Chapter Summary

- Model tiered routing is the性价比最高的优化:小模型 for classification/extraction,大模型/思考模型 for reasoning/creation;
- Agent concurrency uses `arun()` + `asyncio.gather` (配 Semaphore for限流); Workflow uses `Parallel`;
- Cost control = tiered routing + control历史轮数 + limit iterations + metrics budget门禁;
- Evals (Accuracy/Judge/Reliability/Performance) turn质量 into CI-runnable assertions;
- Containerized deployment of AgentOS is无异 from deploying a FastAPI app: keys via environment variables, SQLite换 Postgres, enable authorization and tracing.
