## 25.2 ：asyncio.gather + arun

Agent  `arun()`  asyncio：

```python
import asyncio

async def analyze(symbol: str) -> str:
    result = await analyst.arun(f"分析 {symbol} 最近一周的走势风险")
    return f"{symbol}: {result.content}"

async def main():
    symbols = ["AAPL", "NVDA", "TSLA", "AMZN"]
    # 并发跑 4 个分析，总耗时≈最慢一个，而非四者之和
    results = await asyncio.gather(*[analyze(s) for s in symbols])
    print("\n".join(results))

asyncio.run(main())
```

Workflow  `Parallel` （ 12 ）。—— `asyncio.Semaphore` 。
