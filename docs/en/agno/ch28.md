## 28.2 Build the Product Manual Knowledge Base

生产知识库要考虑两件事: **批量初始化** and **日常增量更新**. Manage with an独立脚本:

```python
# build_kb.py —— knowledge base initialization and incremental maintenance
import os
from pathlib import Path
from agno.knowledge.knowledge import Knowledge
from agno.knowledge.embedder.openai import OpenAIEmbedder
from agno.vectordb.lancedb import LanceDb, SearchType

knowledge = Knowledge(
    vector_db=LanceDb(
        table_name="product_manual",
        uri="tmp/lancedb",
        search_type=SearchType.vector,
        embedder=OpenAIEmbedder(
            id="Qwen/Qwen3-Embedding-8B",       # Third-party compatible embedding service
            api_key=os.getenv("EMBEDDING_API_KEY"),
            base_url="https://api.siliconflow.cn/v1",
        ),
    )
)

def sync_manuals(docs_dir: str = "manuals/") -> None:
    """Scan the manuals directory; only ingest新增/变更 files (idempotent by文件名)."""
    for f in Path(docs_dir).glob("**/*"):
        if f.suffix.lower() not in {".pdf", ".md"}:
            continue
        knowledge.insert(
            path=str(f),
            skip_if_exists=True,     # Skip if已入库 → naturally supports增量
        )
        print(f"Synced: {f.name}")

if __name__ == "__main__":
    sync_manuals()
    # Verify retrieval效果: directly ask a question from the manual
    results = knowledge.search("What is the return policy?", top_k=3)
    for r in results:
        print("-", r.content[:80])
```

If you need "rebuild when the file changes",实现真正的增量同步 with hash对比:

# kb_sync.py —— hash-based content change detection (reference思路 for exercise 1)
import hashlib, json
from pathlib import Path

HASH_FILE = Path("tmp/kb_hashes.json")

def file_hash(p: Path) -> str:
    return hashlib.sha256(p.read_bytes()).hexdigest()   # Content-level fingerprint

## 28.3 Build the Customer Service Agent

```python
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.knowledge.knowledge import Knowledge
from agno.knowledge.embedder.openai import OpenAIEmbedder
from agno.vectordb.lancedb import LanceDb, SearchType

knowledge = Knowledge(
    vector_db=LanceDb(
        table_name="product_manual",
        uri="tmp/lancedb",
        search_type=SearchType.vector,
        embedder=OpenAIEmbedder(
            id="Qwen/Qwen3-Embedding-8B",
            api_key=os.getenv("EMBEDDING_API_KEY"),
            base_url="https://api.siliconflow.cn/v1",
        ),
    )
)

cs_agent = Agent(
    id="support-agent",
    name="Support Agent",
    model=OpenAIChat(
        id="deepseek-chat",
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        base_url="https://api.deepseek.com/v1",
    ),
    knowledge=knowledge,
    instructions=[
        "你是产品客服助手。根据知识库内容回答用户问题。",
        "回答必须附带来源标注：依据：[文档名]（第X页）",
        "如果知识库中找不到答案，回复：'{转人工话术}'，不要编造政策。",
    ],
    markdown=True,
)
```

## 28.4 Publish with AgentOS

```python
from agno.os import AgentOS
from agno.db.sqlite import SqliteDb

db = SqliteDb(db_file="tmp/cs.db")

agent_os = AgentOS(
    id="cs-agent-os",
    agents=[cs_agent],
    db=db,
    authorization=True,
    tracing=True,
)

app = agent_os.get_app()

if __name__ == "__main__":
    agent_os.serve(app="agent_os:app", reload=True)
```

## 28.7 Load Testing

```python
# load_test.py —— asyncio concurrent压测 + 回答质量抽检
import asyncio, os, time
import httpx

URL = "http://localhost:7777/agents/support-agent/runs"
CONCURRENCY, TOTAL = 10, 50                    # Concurrency and total requests

async def one(client: httpx.AsyncClient, sem: asyncio.Semaphore, i: int):
    async with sem:
        start = time.perf_counter()
        r = await client.post(URL, data={
            "message": f"How to redeem membership points? (test {i})",
            "user_id": "load-test",
            "session_id": f"lt-{i}",           # Each request独立会话,模拟真实分布
        })
        elapsed = time.perf_counter() - start
        ok = r.status_code == 200 and "依据：" in r.text   # Status code + citation双断言
        return elapsed, ok

async def main():
    sem = asyncio.Semaphore(CONCURRENCY)
    async with httpx.AsyncClient(timeout=60) as client:
        results = await asyncio.gather(*[one(client, sem, i) for i in range(TOTAL)])
    times = sorted(t for t, _ in results)
    passed = sum(ok for _, ok in results)
    print(f"p50={times[len(times)//2]:.1f}s  p95={times[int(len(times)*0.95):.1f}s")
    print(f"Pass rate: {passed}/{TOTAL}")

if __name__ == "__main__":
    asyncio.run(main())
```

验收基线参考: p95 < 15s (含模型推理), zero 5xx, 抽样 10条回答全部附带来源标注且无编造政策.达不到就先排查知识库命中率,而不是急着扩容.

## 28.8 Chapter Summary

- **Knowledge base工程化**: `skip_if_exists` provides幂等增量;注意"同名改内容不会重建索引"的边界;必要时删除后重灌;
- **回答可信度**: 检索增强 + 来源标注 + 明确兜底话术;三件套缺一不可 — especially "say转人工 when unknown" is the安全底线 for客服 Agent;
- **AgentOS is FastAPI**: `get_app()` returns a原生应用;探针端点随加随用; Uvicorn/Docker全套生态通用;
- **数据要挂卷**: LanceDb and session库放卷上是省钱又保数据的习惯;
- **Launch three-piece套**: probes (healthz/readyz) → smoke (来源抽检) →压测 (latency and error-rate基线).
