# Chapter 13 · Multimodal Agents

> Chapter goals: learn to pass multimodal inputs to Agents using `Image` / `Audio` / `Video` / `File` content objects, understand the implementation paths for image and audio output, and complete a hands-on case of "invoice image → structured data".

## 13.1 The Multimodal Content Object System

Agno用统一的**content objects** abstract four modalities, all imported from `agno.media`. The官方文档 structure is:

| Class | Supported sources | Common metadata |
|---|---|---|
| `Image` | `url`, `filepath`, `content` | `format`, `mime_type`, `detail` |
| `Audio` | `url`, `filepath`, `content` | `format`, `mime_type`, `sample_rate`, `channels` |
| `Video` | `url`, `filepath`, `content` | `format`, `mime_type`, `duration` |
| `File` | `url`, `filepath`, `content`, `external` | `filename`, `format`, `mime_type` |

Each class supports both URLs and local files and raw bytes, letting "online image direct连" and "local file processing"切换 seamlessly. The passing方式是 `run()` / `print_response()` keyword arguments: `images=[...]`, `audios=[...]`, `videos=[...]`, `files=[...]`.

::: warning Model Capability Determines Everything
The framework is just a搬运工; **whether the model can actually see images / hear audio is determined by the model**. When接入 visual models, confirm the provider's corresponding model supports the modality (e.g., DeepSeek's chat series currently does not接受 image input; for visual tasks choose a provider model with视觉 support). Video input is目前仅 Gemini and AWS Bedrock部分模型支持.
:::

## 13.2 Image Understanding: URLs and Local Files

```python
# vision_agent.py —— Image understanding (requires switching to a visual-model-compatible endpoint)
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat   # Or OpenAILike pointing to任意 visual model endpoint
from agno.media import Image

agent = Agent(
    model=OpenAIChat(
        id="qwen-vl-plus",                  # Example: third-party OpenAI-compatible visual model id
        api_key=os.getenv("VISION_API_KEY"),
        base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
    ),
    instructions=["Descriptions should be specific: state the subject first, then details"],
    markdown=True,
)

# Method 1: URL direct pass
agent.print_response(
    "What is in this image? Summarize in one sentence.",
    images=[Image(url="https://upload.wikimedia.org/wikipedia/commons/thumb/3/3a/Cat03.jpg/640px-Cat03.jpg")],
)

# Method 2: Local file
agent.print_response(
    "Describe this image",
    images=[Image(filepath="./photo.jpg")],
)

# Method 3: Multi-image comparison
agent.print_response(
    "Compare the style differences between these two images",
    images=[Image(filepath="./a.jpg"), Image(filepath="./b.jpg")],
)
```

Three details worth noting:

- **Multiple images = list with more items**; order is the order the model sees;
- `Image(detail=...)`可控制视觉细节级别 (affects token consumption);
- Byte-stream scenarios (e.g.,刚 downloaded from网络, not yet on disk) use `Image(content=raw_bytes)`.

## 13.3 Document Understanding and Audio Transcription

PDFs and other documents are passed via `File` objects; audio via `Audio` objects:

```python
# doc_audio.py —— PDF summary and speech transcription
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.media import Audio, File

pdf_agent = Agent(
    model=OpenAIChat(
        id="deepseek-chat",                 # Text model即可处理解析后的 PDF 文本
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        base_url="https://api.deepseek.com/v1",
    ),
)
pdf_agent.print_response(
    "Summarize the three core conclusions of this report",
    files=[File(filepath="./annual_report.pdf")],
)


audio_agent = Agent(
    # Audio input requires selecting a model endpoint supporting audio
    model=OpenAIChat(
        id="qwen-audio-asr",
        api_key=os.getenv("AUDIO_API_KEY"),
        base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
    ),
)
with open("./meeting.wav", "rb") as f:
    audio_bytes = f.read()

audio_agent.print_response(
    "Transcribe this recording to text and list action items",
    audios=[Audio(content=audio_bytes, format="wav")],
)
```

## 13.4 Image and Audio Output

Besides "reading", Agno also supports "writing". Image generation goes through the工具 path — equip the Agent with `OpenAITools` and specify the image model; audio output is returned directly by the model:

```python
# gen_image.py —— Let the Agent生成图片 and save locally
import base64
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.tools.openai import OpenAITools          # Built-in OpenAI capability toolkit
from agno.utils.media import save_base64_data      # Officially provided save utility

agent = Agent(
    model=OpenAIChat(
        id="gpt-image-hosting-model",               # Example: the conversational model hosting image generation
        api_key=os.getenv("IMAGE_API_KEY"),
        base_url="https://your-openai-compatible-endpoint/v1",
    ),
    tools=[OpenAITools(image_model="gpt-image-2")], # Specify the actual image-generation model
)

response = agent.run("Draw an illustration of a snowy mountain sunset")

if response.images and response.images[0].content:
    image_base64 = base64.b64encode(response.images[0].content).decode("utf-8")
    save_base64_data(image_base64, "sunset.png")     # Write to disk
    print("Saved sunset.png")
```

```python
# gen_audio.py —— Audio reply
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.utils.audio import write_audio_to_file

agent = Agent(
    model=OpenAIChat(
        id="gpt-audio",
        api_key=os.getenv("AUDIO_API_KEY"),
        base_url="https://your-openai-compatible-endpoint/v1",
        modalities=["text", "audio"],                # Declare output modality
        audio={"voice": "alloy", "format": "wav"},   # Voice and format
    ),
)

response = agent.run("Explain compound interest using a fable")
if response.response_audio:
    write_audio_to_file(audio=response.response_audio.content, filename="story.wav")
```

::: tip Where Do Generated Media Go?
Image generation results are in the `response.images` list (bytes in `.content`); audio results are in `response.response_audio`. By default they exist only in memory; you need toencode and write to disk yourself — the officialdocs provide `save_base64_data` and `write_audio_to_file` utilities.
:::

## 13.5 Comprehensive Case: Invoice Image Structured Extraction

Connect this chapter's content with the前一章's tools and Chapter 5's structured output — this is one of the most高频 multimodal scenarios in enterprise:

```python
# invoice_ocr.py —— Invoice image -> structured JSON
import os
from pydantic import BaseModel, Field
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.media import Image


class Invoice(BaseModel):
    vendor: str = Field(..., description="Vendor name")
    amount: float = Field(..., description="Total amount including tax")
    currency: str = Field(default="CNY", description="Currency code")
    invoice_no: str = Field(..., description="Invoice number")


agent = Agent(
    model=OpenAIChat(
        id="qwen-vl-plus",                    # Visual model负责"看"
        api_key=os.getenv("VISION_API_KEY"),
        base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
    ),
    output_schema=Invoice,                    # Pydantic负责"定形"
    instructions=[
        "Extract fields from the invoice image; retain two decimal places for amounts",
        "For unrecognized fields, leave empty and note in备注",
    ],
)

result: Invoice = agent.run(
    "Extract information from this invoice",
    images=[Image(filepath="./invoice_scan.png")],
).content

print(result.vendor, result.amount, result.invoice_no)
```

This pattern's extensibility is极强:换 `output_schema`适配 contracts, IDs, report screenshots — any "image in, structure out"需求.

## 13.6 Chapter Summary

- Four modalities对应 `agno.media`'s四个 content objects, all supporting `url` / `filepath` / `content` three sources;
- Input hangs on `run()`'s `images/audios/videos/files` parameters; **可用性取决于所选模型的能力**; video input目前仅 Gemini and Bedrock支持;
- Output direction: images generated via `OpenAITools` (results in `response.images`); audio直出 by the model (`response.response_audio`);
- Multimodal + `output_schema`组合 is the标准解法 for OCR / receipt extraction scenarios.
