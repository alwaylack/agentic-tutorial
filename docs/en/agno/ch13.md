# Chapter 13 · Multimodal Agents

> Chapter goals: learn to pass multimodal inputs to Agents using `Image` / `Audio` / `Video` / `File` content objects; understand the implementation paths for image and audio outputs; complete a hands-on case of "invoice image → structured data".

## 13.1 The Multimodal Content Object System

Agno uses a unified **content object** abstraction for four modalities, all imported from `agno.media`. The official docs structure:

| Class | Supported Sources | Common Metadata |
|---|---|---|
| `Image` | `url`, `filepath`, `content` | `format`, `mime_type`, `detail` |
| `Audio` | `url`, `filepath`, `content` | `format`, `mime_type`, `sample_rate`, `channels` |
| `Video` | `url`, `filepath`, `content` | `format`, `mime_type`, `duration` |
| `File` | `url`, `filepath`, `content`, `external` | `filename`, `format`, `mime_type` |

The same class supports URLs as well as local files and raw bytes; this lets "online image direct connect" and "local file processing"切换 seamlessly. The传入方式 is via keyword parameters in `run()` / `print_response()`: `images=[...]`, `audios=[...]`, `videos=[...]`, `files=[...]`.

::: warning Model Capabilities决定一切
The framework is only a搬运工; **what真正决定 whether the model can see images / hear audio is the model itself**. When接入视觉模型,确认三方服务商的对应模型支持该模态 (e.g., DeepSeek\'s chat series currently does not接受图像输入; for视觉任务 should choose a三模型 that supports vision). Video input目前仅 Gemini and部分 AWS Bedrock models支持.
:::

## 13.2 Image Understanding: URLs and Local Files

```python
# vision_agent.py —— image understanding (requires switching to a vision-capable third-party/compatible model)
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat   # or OpenAILike pointing to any vision model endpoint
from agno.media import Image

agent = Agent(
    model=OpenAIChat(
        id="qwen-vl-plus",                  # Example: a third-party OpenAI-compatible vision model id
        api_key=os.getenv("VISION_API_KEY"),
        base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
    ),
    instructions=["Be specific in descriptions; state the主体 first, then细节"],
    markdown=True,
)

# Method 1: pass URL directly
agent.print_response(
    "What is in this image? Summarize in one sentence.",
    images=[Image(url="https://upload.wikimedia.org/wikipedia/commons/thumb/3/3a/Cat03.jpg/640px-Cat03.jpg")],
)

# Method 2: local file
agent.print_response(
    "Describe this image",
    images=[Image(filepath="./photo.jpg")],
)

# Method 3: multi-image comparison
agent.print_response(
    "Compare the风格差异 between these two images",
    images=[Image(filepath="./a.jpg"), Image(filepath="./b.jpg")],
)
```

Three细节值得注意:

- **Multiple images are just列表多一项**; the顺序 is the order the model sees them;
- `Image(detail=...)`可控制视觉细节级别 (affects token消耗);
- For byte-stream scenarios (e.g., just downloaded from the网络, not yet落盘), use `Image(content=raw_bytes)`.

## 13.3 Document Understanding and Audio Transcription

PDFs等文档通过 `File` objects传入; audio通过 `Audio` objects传入:

```python
# doc_audio.py —— PDF summary and audio transcription
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.media import Audio, File

pdf_agent = Agent(
    model=OpenAIChat(
        id="deepseek-chat",                 # A text model suffices to process已解析的 PDF text
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        base_url="https://api.deepseek.com/v1",
    ),
)
pdf_agent.print_response(
    "Summarize the three core conclusions of this report",
    files=[File(filepath="./annual_report.pdf")],
)


audio_agent = Agent(
    # Audio input requires choosing an音频模型 endpoint
    model=OpenAIChat(
        id="qwen-audio-asr",
        api_key=os.getenv("AUDIO_API_KEY"),
        base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
    ),
)
with open("./meeting.wav", "rb") as f:
    audio_bytes = f.read()

audio_agent.print_response(
    "Transcribe this recording into text and列出待办事项",
    audios=[Audio(content=audio_bytes, format="wav")],
)
```

## 13.4 Image and Audio Outputs

Beyond "reading", Agno also supports "writing". Image generation走工具路径 —给 Agent配 `OpenAITools` and指定图像模型; audio output is returned直接 by the model:

```python
# gen_image.py —— let the Agent generate an image and save it locally
import base64
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.tools.openai import OpenAITools          # Built-in OpenAI capability toolkit
from agno.utils.media import save_base64_data      # Officially provided保存工具函数

agent = Agent(
    model=OpenAIChat(
        id="gpt-image-hosting-model",               # Example: the对话模型承载图像生成
        api_key=os.getenv("IMAGE_API_KEY"),
        base_url="https://your-openai-compatible-endpoint/v1",
    ),
    tools=[OpenAITools(image_model="gpt-image-2")], # Specify the actual生图模型
)

response = agent.run("Draw an illustration of a雪山日落")

if response.images and response.images[0].content:
    image_base64 = base64.b64encode(response.images[0].content).decode("utf-8")
    save_base64_data(image_base64, "sunset.png")     # Save to盘
    print("Saved sunset.png")
```

```python
# gen_audio.py ——语音回复
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.utils.audio import write_audio_to_file

agent = Agent(
    model=OpenAIChat(
        id="gpt-audio",
        api_key=os.getenv("AUDIO_API_KEY"),
        base_url="https://your-openai-compatible-endpoint/v1",
        modalities=["text", "audio"],                #声明输出模态
        audio={"voice": "alloy", "format": "wav"},   # Voice and format
    ),
)

response = agent.run("Explain compound interest using a fable")
if response.response_audio:
    write_audio_to_file(audio=response.response_audio.content, filename="story.wav")
```

::: tip Where Do Generated Media Go
Image generation results are saved in the `response.images` list (bytes in `.content`);语音结果 in `response.response_audio`. They默认只存在于内存中; you need to encode and落盘 yourself — the官方 provides `save_base64_data` and `write_audio_to_file` two tool functions.
:::

## 13.5 Comprehensive Case: Invoice Image Structured Extraction

串联本章内容与前一章的工具、第 5 章的结构化输出 — this is one of the最高频的多模态场景 in enterprise:

```python
# invoice_ocr.py —— invoice image → structured JSON
import os
from pydantic import BaseModel, Field
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.media import Image


class Invoice(BaseModel):
    vendor: str = Field(..., description="开票方名称")
    amount: float = Field(..., description="价税合计金额")
    currency: str = Field(default="CNY", description="币种代码")
    invoice_no: str = Field(..., description="发票号码")


agent = Agent(
    model=OpenAIChat(
        id="qwen-vl-plus",                    # Vision model负责"看"
        api_key=os.getenv("VISION_API_KEY"),
        base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
    ),
    output_schema=Invoice,                    # Pydantic负责"定形"
    instructions=[
        "Extract fields from the invoice image; keep金额保留两位小数",
        "For fields that are识别不清, set to空字符串 and explain in备注",
    ],
)

result: Invoice = agent.run(
    "Extract the information from this invoice",
    images=[Image(filepath="./invoice_scan.png")],
).content

print(result.vendor, result.amount, result.invoice_no)
```

This pattern\'s扩展性极强:换 `output_schema` to适配合同,身份证,报表截图 etc. — any "图片进,结构出" need.

## 13.6 Chapter Summary

- Four modalities对应 `agno.media`\'s four content objects; all支持 `url` / `filepath` / `content` three sources;
- Inputs挂 on `run()`\'s `images/audios/videos/files` parameters; **whether they can be used depends on the selected model\'s capabilities**; video input目前仅 Gemini and Bedrock支持;
- Output direction: images are generated via the `OpenAITools` tool (results in `response.images`); audio is returned directly by the model (`response.response_audio`);
- Multimodal + `output_schema`组合 is the标准解法 for OCR/invoice extraction scenarios.
