# Chapter 20 · Skills: Pluggable Domain Capabilities

> Chapter goals: understand Agno\'s Skills skill package system (based on the Anthropic Agent Skills spec); learn to write compliant `SKILL.md`;挂载 skills to Agents and Teams via `LocalSkills`;了解 Claude云端预置技能 (pptx/xlsx/docx/pdf) 的接入方式.

## 20.1 Why Skills Are Needed: From instructions to Skill Packages

In the课程 content up to this chapter, there are only two手段 to塞领域知识 into an Agent:

| Approach | Suitable场景 | Shortcoming |
|---|---|---|
| `instructions` / system prompt | Short behavior constraints |知识一多就撑爆上下文; full payload付费 on every request |
| `Knowledge` (RAG) | Factual Q&A for massive静态资料 | Retrieves "资料片段"; not good at传递成套的方法论与脚本 |

真实业务里还有第三种需求: **把"某类任务该怎么做"打包成一个可复用、可分享的知识单元** — e.g., "how to do a code review", "how to write an industry weekly report". This is exactly the定位 of a **Skill**:

> A Skill is a自包含的目录包;内含结构化指令、可选的可执行脚本与参考文档. The Agent uses it progressively in four steps: "发现 → 加载 → 引用 → 执行".

Skills and Tools are互补关系而非替代关系: **Tools给 Agent能力 (what actions it can perform); Skills给 Agent方法论 (how to do这类事 well)**.

::: tip Relation to the Community Ecosystem
Agno\'s Skills integration follows Anthropic\'s open-source [Agent Skills spec](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview); meaning skills directories you写 for Claude Code, third-party技能 packages shared online,只要结构合规即可直接放进 Agno项目复用.
:::

## 20.2 Progressive Loading: The Core Mechanism that Saves Tokens

The problem with writing all领域知识 directly into the system prompt is "全量付费,全程占位". Skills采用**渐进式发现 (Progressive Discovery)**策略:

1. **Browse**: after注册, only each skill\'s **name + one-sentence描述** appears in the Agent\'s system prompt (dozens of tokens);
2. **Load**: when the task匹配 a skill, the模型自行调用 `get_skill_instructions(skill_name)` to read in the完整指令;
3. **Reference**: when more细节 is needed,读入 `references/`下的文档;
4. **Execute**: when精确计算/校验 is needed, run scripts under `scripts/` with a shebang.

After挂载 Skills, the Agent自动获得这三个专用工具:

| Tool | Purpose |
|---|---|
| `get_skill_instructions(skill_name)` | Load a skill\'s完整指令 |
| `get_skill_reference(skill_name, reference_path)` | Read a reference文档 for a skill |
| `get_skill_script(skill_name, script_path, execute, args, timeout)` | Read or执行 a script in a skill |

::: warning Token Economics
Ten完整方法论 directly into the system prompt could be数万 token固定开销; the same内容做成十份技能; the system prompt only has ten摘要 — only the命中的那份 is完整载入.
:::

## 20.3 Writing a Compliant Skill: SKILL.md and Directory Structure

A skill is just a普通目录; the唯一必需 is the root `SKILL.md`:

```text
my-skills/
├── report-writer/          # Directory name = skill name (强制一致)
│   ├── SKILL.md            # Required: YAML frontmatter + Markdown instructions
│   ├── scripts/            # Optional: executable scripts (must have a shebang)
│   │   └── wc_check.py
│   └── references/         # Optional: reference docs; loaded on demand
│       └── style-guide.md
└── code-review/
    └── SKILL.md
```

`SKILL.md` consists of YAML frontmatter元数据 + body instructions. **Only six合法顶级字段**: `name`, `description`, `license`, `compatibility`, `allowed-tools`, `metadata`; any other顶级字段 will cause校验失败 (put自定义信息 into the `metadata` dict):

```markdown
---
name: report-writer
description: Write structured industry weekly reports; with word-count validation script and style guide
license: Apache-2.0
metadata:
  version: "1.0.0"
  author: gaoxueling
  tags: ["writing", "report"]
---

# Industry Weekly Report Writing Skill

Enable this skill when the user requests an industry weekly/monthly report.

## Process
1. First ask清楚 the report周期 and目标读者;
2. Organize in three sections: "This week\'s dynamics → data highlights → next period outlook";
3. Before output, run scripts/wc_check.py to验证正文字数是否在范围内.

## Details
Style requirements见 references/style-guide.md; load only when the user质疑措辞.
```

Strict校验 happens at load time; skills violating规则 will raise `SkillValidationError`:

- `name`: only lowercase letters, numbers, hyphens allowed; ≤64 characters; cannot start/end with `-`; no consecutive `--`; **must一致 with the directory name**;
- Length caps: `description` ≤1024 characters; `compatibility` ≤500 characters; `license`建议用 SPDX identifiers (e.g., `MIT`, `Apache-2.0`);
- Scripts must开头 with `#!` shebang (e.g., `#!/usr/bin/env python3`); executed with the skill目录 as the工作目录; the model can传参.

A simple配套脚本 `scripts/wc_check.py`:

```python
#!/usr/bin/env python3
"""Count Chinese characters and total lines in input text; for self-check before report delivery."""
import sys

text = sys.stdin.read() if not sys.argv[1:] else open(sys.argv[1], encoding="utf-8").read()
cjk = sum(1 for ch in text if "\u4e00" <= ch <= "\u9fff")
print(f"{cjk} CJK characters; {len(text.splitlines())} lines total")
sys.exit(0 if 800 <= cjk <= 2000 else 1)
```

## 20.4 Mounting Skills to Agents with LocalSkills

`Skills` is the技能编排器; `LocalSkills` is the built-in文件系统加载器;支持加载整个技能库 or单个技能:

```python
import os
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.skills import Skills, LocalSkills

agent = Agent(
    name="Weekly Report Assistant",
    model=OpenAIChat(
        id="deepseek-chat",
        api_key=os.getenv("DEEPSEEK_API_KEY"),
        base_url="https://api.deepseek.com/v1",
    ),
    skills=Skills(
        loaders=[LocalSkills("/path/to/my-skills")]
    ),
)
```

## 20.5 Skills in Teams

When传入 skills to a Team, theleader directly gets the skill tools and prompt snippets — acting as a "懂行的协调者":

```python
from agno.team import Team

review_team = Team(
    name="Code Review Team",
    model=model,
    members=[frontend_dev, backend_dev],
    skills=Skills(loaders=[LocalSkills("/path/to/review-skills")]),
    mode="coordinate",
)
review_team.print_response("Review and improve this code: def calc(x,y): return x+y", stream=True)
```

How to choose among three配置层级:

| Config approach | Suitable场景 |
|---|---|
| `Team(skills=...)` | The队长需要领域标准来协调调度 (评审规范,路由规则) |
| Member `Agent(skills=...)` | Expert members need专业知识 to完成本职工作 |
| Both layers配置 | The队长 needs context for分派; members also need知识 for执行 |

其内部机制与前几章的 knowledge/memory/tools完全同构: `skills.get_tools()` adds skill tools to the leader\'s工具列表; `get_system_prompt_snippet()` injects skill元数据 into the leader\'s system prompt.

## 20.6 Advanced: Claude Cloud Agent Skills (Optional Reading)

If you use the Anthropic官方 API, you can also let skills "跑在云端" — Claude provides four开箱即用的容器化 skills that can直接产出 Office files in an isolated沙箱:

| Skill ID | Capability |
|---|---|
| `pptx` | Create/edit presentations and analyze their content |
| `xlsx` | Create spreadsheets; generate reports with charts |
| `docx` | Create/edit Word documents |
| `pdf` | Generate排版精美的 PDF reports |

The用法 is to pass the skill config to the `Claude` model object (at most 8 skills per request; `type="custom"`配合 `skill_*` IDs can使用上传到工作区的自定义技能):

```python
from agno.agent import Agent
from agno.models.anthropic import Claude

agent = Agent(
    model=Claude(
        id="claude-sonnet-4-6",
        skills=[{"type": "anthropic", "skill_id": "pptx", "version": "latest"}],
    ),
    instructions="制作简洁、结构清晰的演示文稿.",
)

run = agent.run("Generate a three-page presentation on 'Renewable Energy'")
# The产物不在本地: extract file_ids from run.model_provider_data;
# then download via Anthropic Files API (client.beta.files.download) to落盘.
```

::: warning Production Note
Cloud skills run in隔离容器中 with **no网络**; the产物 must be downloaded via the Files API which is still beta; for `pause_turn` long-task中断场景建议改用 Anthropic原生 SDK续传. Skills/Files APIs are不可用 on Amazon Bedrock and Google Vertex AI channels. This section is选读扩展; the rest of the course examples do not依赖 Anthropic直连.
:::

## 20.7 Engineering Practice Checklist

- **What值得做成 Skill**:流程稳定, cross-Agent复用的方法论 (评审规范,写作模板,运维手册); "每次都要取最新值"的内容请继续交给 Tools/RAG;
- **Deterministic计算交给脚本**: word count, format转换, lint checks written as scripts the model calls; far more可靠 than letting it"口算";
- **Skills也要写测试**: SKILL.md is part of prompt engineering;务必回归验证 after switching models;
- **版本治理**: record iterations with `metadata.version`; important changes走 Git PR评审.

## 20.8 Chapter Summary

- Skill = `SKILL.md` + optional `scripts/` + optional `references/`; six合法 frontmatter fields; `name` must一致 with the directory name;
- Progressive loading:摘要常驻 → 指令按需 → 参考按需 → 脚本执行;显著节省 token;
- `Skills(loaders=[LocalSkills(...)])`挂载 to an Agent; pass to `Team.skills` and the队长直接持有;
- Anthropic users可叠加云端预置技能 (pptx/xlsx/docx/pdf) to生成 Office files.
