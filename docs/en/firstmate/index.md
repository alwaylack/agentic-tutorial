# FirstMate · Course Guide

This course spans **18 chapters**, based on the **FirstMate official documentation and repository**, mastering the agent distro paradigm for orchestrating a fleet of coding agents.

## What You Will Learn

| Stage | Chapters | Content |
|---|---|---|
| Getting Started | 01–05 | Overview, environment setup, AGENTS.md anatomy, hard rules & safety boundaries, runtime layout |
| Intermediate | 06–11 | Session backends (tmux/herdr/zellij/Orca/cmux), crewmate delegation, worktree isolation, project modes, zero-token event-driven supervision |
| Advanced | 12–15 | Built-in skills, two-layer skill system, secondmate, remote fleet & Relay |
| Production Practice | 16–18 | Three capstones: personal dev fleet, multi-project parallel delivery pipeline, secondmate remote fleet scaling |
