## 20.1 Project Planning and CLAUDE.md

First initialize the project and write `CLAUDE.md` — this is the foundation of the entire workflow:

```bash
mkdir todo-app && cd todo-app
git init
npm create vite@latest . -- --template react-ts
```

```markdown
# CLAUDE.md

## Project Overview
Full-stack Todo app: React + TypeScript frontend, Express + SQLite backend.

## Tech Stack
- Frontend: React 18, TypeScript, Tailwind CSS
- Backend: Express, better-sqlite3
- Tests: Vitest (frontend), Jest (backend)
- Package manager: pnpm

## Hard Constraints
- All API routes use the /api/v1/ prefix
- DB operations must go through the repository layer
- Every feature must have corresponding tests

## Verification Commands
- Frontend tests: pnpm test:front
- Backend tests: pnpm test:back
- Type check: pnpm typecheck
- Full verify: pnpm check
```

## 20.2 Requirements → Design → Coding

## 20.3 Integrating MCP Tools

Configure filesystem and database tools for Claude:

```json
// .claude/mcp.json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "."]
    },
    "sqlite": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-sqlite", "--db-path", "./data/todo.db"]
    }
  }
}
```

After配置, Claude can directly query the database status todebug issues.

## 20.4 Skills and Hooks Automation

Encapsulate重复 operations as Skills; use Hooks for automated quality checks:

```markdown
<!-- .claude/skills/deploy/SKILL.md -->
---
name: deploy-check
description: Pre-deploy checks: run all tests, type checks, and builds; only allow deployment after all pass.
---

## Steps
1. Run pnpm check (includes lint + typecheck + all tests)
2. Run pnpm build to confirm成功构建
3. If any step fails, report errors and stop
4. After all pass, output "✅ Deploy check passed"
```

```json
// .claude/settings.json — Hooks
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "command": "pnpm lint --fix --quiet"
      }
    ]
  }
}
```

Auto-run lint fix after every file edit by Claude.

## 20.5 Verification and Deployment

After completing development, have Claude执行 the full deployment flow:

```text
> Use the deploy-check skill for pre-deployment verification.
  After all pass, help me generate a Dockerfile and docker-compose.yml.
```

Claude will:
1. Load the `deploy-check` Skill;
2. Execute检查 commands item by item;
3. Generate Docker config based on the project structure;
4. Commit code and tag.
