# Chapter 1 · Introduction to Claude Code

> Chapter goals: Understand Claude Code's positioning and core value, complete installation and authentication setup, and verify the environment is working.

## 1.1 What Is Claude Code

Claude Code is Anthropic's **terminal AI coding assistant** (agentic coding tool). It runs in your terminal and can directly read/write project files, execute shell commands, run tests, and commit git — not just generate code snippets for you to paste manually.

Key differences from traditional IDE plugins:

| Feature | IDE Autocomplete Plugin | Claude Code |
|---|---|---|
| Where it runs | Inside the editor | Independent terminal process |
| Can execute commands | ❌ | ✅ Bash / tests / Git |
| Context source | Current file only | Entire project directory |
| Multi-file editing | Single file | Cross-file atomic operations |
| Autonomy | Passive autocomplete | Active planning and execution |

::: tip Core Philosophy
Claude Code follows an **"agentic"** design philosophy: you describe the goal, it autonomously plans steps, calls tools, verifies results, and iterates — you review and decide.
:::

## 1.2 Installation

### Prerequisites

- Node.js **18+**
- macOS / Linux / Windows (WSL)

### Global npm Install

```bash
npm install -g @anthropic-ai/claude-code
```

### Verify Installation

```bash
claude --version
# Prints version number, e.g. 2.1.241

claude --help
# Shows all available subcommands and options
```

## 1.3 Authentication Setup

Claude Code supports two authentication methods:

### Method 1: Anthropic API Key (pay-as-you-go)

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
```

It's recommended to add this line to `~/.zshrc` or `~/.bashrc` for persistence.

### Method 2: Claude Pro/Max Subscription (included in your subscription)

The first time you run `claude`, select "Log in with Claude account" — a browser will open an OAuth authentication page.

## 1.4 First Launch

Enter any project directory and start Claude Code:

```bash
cd my-project/
claude
```

You'll see an interactive REPL prompt. Type a test message:

```text
> Tell me about this project's structure and tech stack
```

Claude Code will automatically read files in the directory, analyze the code, and provide a summary.

## 1.5 Version Management

```bash
# Check current version
claude --version

# Update to the latest
npm update -g @anthropic-ai/claude-code

# Pin a specific version (recommended for team collaboration)
npm install -g @anthropic-ai/claude-code@2.1.241
```

::: warning Version Consistency
When working in a team, it's recommended that all members use the same version of Claude Code to avoid inconsistent behavior from CLAUDE.md instructions.
:::
