# Chapter 4 · File Operations and Code Editing

> Chapter goals: Master Claude Code's file read/write toolchain, understand the diff preview confirmation flow, and learn to efficiently search the codebase.

## 4.1 File Tool Overview

Claude Code has the following built-in file operation tools:

| Tool | Function | Requires Confirmation |
|---|---|---|
| **Read** | Read file contents | ❌ |
| **Write** | Create new files or overwrite | ✅ |
| **Edit** | Precise text replacement in existing files | ✅ |
| **Grep** | Regex search file contents (similar to ripgrep) | ❌ |
| **Glob** | Match file paths by pattern | ❌ |

## 4.2 Read: Reading Files

When you ask "what does this function do," Claude Code automatically calls Read to fetch file contents:

```text
> What does the parse_config function in src/utils/parser.py do?
```

It will:
1. Read `src/utils/parser.py` with Read
2. Analyze the function logic
3. Return an explanation

You can also specify a line range:

```text
> Read lines 50-100 of app/models/user.py
```

## 4.3 Write and Edit: Creating and Modifying

### Creating a New File

```text
> Create a date_utils.py under src/utils/ with functions to format dates and parse date strings
```

Claude Code will use Write to create the file and display a diff preview in the terminal for your confirmation:

```diff
+ src/utils/date_utils.py (new file)
+
+ from datetime import datetime, timezone
+
+
+ def format_iso(dt: datetime) -> str:
+     """Format datetime to ISO 8601 string in UTC."""
+     ...
```

Press `y` to confirm, `n` to reject, `e` to edit before saving.

### Modifying an Existing File

```text
> Change ValueError to a custom ConfigParseError in parser.py
```

Claude Code uses the Edit tool for precise text replacement, also showing a diff.

## 4.4 Grep and Glob: Searching

```text
> Find all places in the project using the deprecated requests.get
```

Internally executes equivalent to `grep -rn "requests.get" --include="*.py"`.

```text
> Which Python files have "test" in their filename?
```

Uses Glob to match `**/test*.py`.

## 4.5 Multi-File Atomic Operations

Claude Code can coordinate modifications across multiple files in a single task:

```text
> Replace all print() calls in the project with logger.info()
```

It will:
1. Use Grep to find all `print(` occurrences
2. Use Edit to replace one by one in each file
3. Show the diff for each file
4. Ask for your confirmation per file

## Chapter Summary

- Five file tools: Read / Write / Edit / Grep / Glob;
- Write operations require your confirmation via diff before taking effect;
- Multi-file modifications are auto-coordinated with per-file confirmation;
- Grep/Glob are free searches that don't consume additional permissions.
