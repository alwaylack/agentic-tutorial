## 21.2 `/claude-api upgrade`: SDK Migration Assistant

v2.1.239新增 the `/claude-api upgrade` slash command, which自动 migrates Python projects from Anthropic SDK 0.x to 1.x:

```
> /claude-api upgrade
Analyzing your project...
Found 12 files using anthropic 0.x API patterns.
Key changes:
- anthropic.Anthropic() → anthropic.Client()
- httpx.Timeout → anthropic.Timeout
- completion.model → response.model

Apply changes? [y/N]
```

Migration注意事项:
- Timeout classes change from `httpx.Timeout` to `anthropic.Timeout`
- Streaming callback signatures have changes
-建议 running the test suite before committing

## 21.3 keybindingFlavor: Keybinding Styles

v2.1.238 introduced the `keybindingFlavor` setting, supporting Bash readline-style keybindings:

```jsonc
// ~/.claude/settings.json
{
  "keybindingFlavor": "readline"
}
```

After setting, `Ctrl+W` in the prompt deletes to the previous whitespace (consistent with Bash behavior). Default `"classic"` remains unchanged.

## 21.4 Plugin Marketplace headersHelper

v2.1.238 added the `headersHelper` mechanism to the plugin marketplace — when the marketplace URL需要 dynamic auth headers, specify a command to generate temporary tokens:

```jsonc
// marketplace.json
{
  "url": "https://internal.company.com/plugins/catalog.json",
  "headersHelper": "/usr/local/bin/get-plugin-token"
}
```

This command executes only during plugin install or update; suitable for short-lived token scenarios, avoiding hardcoding long-term keys.

## 21.5 Concise Output Style

v2.1.237内置了 **Concise** output style. When enabled, Claude skips intros and narratives, outputting results directly:

```
/config → Output style → Concise
```

Suitable for experienced developers — reduces reading time without sacrificing code quality.

## 21.6 Bedrock/Vertex Support

Same version adds full-screen renderer support for Bedrock, Vertex AI, and Foundry users; newly installed on these platforms now defaults to full-screen TUI.

## 21.7 LLM Gateway Prompt Caching Fix

v2.1.237 fixed a issue where prompt caching failed when using自定义 base_url or an LLM gateway. If your organization routes API requests through a proxy, upgrading自动享受s cache discounts.
