# Chapter 10 · MCP Integration and External Tools

> Chapter goals: Master Claude Code's MCP (Model Context Protocol) integration, learn to configure MCP servers with stdio/SSE transport, and使用 common tool extensions to expand Claude's capability boundaries.

## 10.1 The Role of MCP in Claude Code

MCP lets Claude Code突破 built-in tools (file read/write, Bash) and connect to any external service:

```text
┌─────────────────┐     MCP Protocol      ┌──────────────────┐
│   Claude Code    │ ◄──────────────► │   MCP Server      │
│                  │                   │                  │
│ Built-in tools:   │    stdio/SSE     │  filesystem      │
│   Read/Write     │    JSON-RPC      │  github          │
│   Bash/Grep      │ ◄──────────────► │  postgres        │
│                  │                   │  slack           │
│ MCP tools:       │                   │  puppeteer       │
│   mcp__fs__read  │                   │  ...custom        │
└─────────────────┘                   └──────────────────┘
```

Each MCP server exposes a组 of **tools** (tools), and Claude automatically selects which to call based on the task. Tool names follow the format `mcp__<server>__<tool>`.

## 10.2 Configuring MCP Servers

### Command-line Addition

```bash
# Basic syntax
claude mcp add <name> <command> [args...]

# Add a filesystem server — let Claude safely access specified directories
claude mcp add filesystem -- npx -y @modelcontextprotocol/server-filesystem /path/to/dir

# Add a GitHub server
claude mcp add github -- npx -y @modelcontextprotocol/server-github

# Add an SSE remote server
claude mcp add my-api --transport sse https://my-server.com/mcp

# List configured servers
claude mcp list

# Remove
claude mcp remove filesystem
```

### Config File Method

```json
// .claude/settings.json or ~/.claude/settings.json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/home/user/projects"]
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_TOKEN": "ghp_xxx"
      }
    }
  }
}
```

### Scope

| Scope | Flag | Effective Range |
|---|---|---|
| Project | default | Current directory only |
| User | `--scope user` | All projects |
| Global | `--scope global` | Cross-project sharing |

## 10.3 Transport Protocol Deep Dive

### stdio (Standard Input/Output)

The most commonly used local transport:

```text
Claude Code ──stdin──►  MCP Server process
            ◄─stdout──
```

- Server spawns as a subprocess;
- Exchanges JSON-RPC messages via stdin/stdout;
- Suitable for本地 scripts and npm-package-style servers.

### SSE (Server-Sent Events)

For remote HTTP services:

```bash
claude mcp add remote-tools --transport sse https://mcp.example.com/sse \
  --header "Authorization: Bearer token123"
```

- Claude Code acts as an SSE client connecting to a remote endpoint;
- Suitable for team-shared centralized MCP services.

## 10.4 Common MCP Server Walkthrough

### filesystem — Filesystem Access

```bash
claude mcp add fs -- npx -y @modelcontextprotocol/server-filesystem ~/docs ~/notes
```

After adding, Claude can:
- `mcp__fs__read_file` — read files in the specified directory
- `mcp__fs__write_file` — create or modify files
- `mcp__fs__list_directory` — list directory contents
- `mcp__fs__search_files` — search files

### github — GitHub API Operations

```bash
export GITHUB_TOKEN="ghp_your_token"
claude mcp add gh -- npx -y @modelcontextprotocol/server-github
```

```text
> Help me create an issue in the anthropics/claude-code repo,
  titled "MCP integration guide", description: "need to supplement MCP config docs"

Claude will调用 the mcp__gh__create_issue tool to complete the operation.
```

### postgres — Database Queries

```bash
claude mcp add db -- npx -y @modelcontextprotocol/server-postgres \
  "postgresql://user:pass@localhost:5432/mydb"
```

```text
> Query the number of users registered in the last 7 days grouped by day

Claude executes SQL via mcp__db__query and returns results.
```

## 10.5 Tool Discovery and Permission Control

### Viewing Available Tools

```bash
# List all currently available MCP tools
> /mcp

# Output:
# ┌────────────────────────────────────────────┐
# │ MCP Servers                                │
# ├────────────────────────────────────────────┤
# │ ✅ filesystem (4 tools)                    │
# │ ✅ github (12 tools)                       │
# │ ❌ postgres — connection refused           │
# └────────────────────────────────────────────┘
```

### Permission Control

MCP tools require user confirmation by default; pre-approve in settings.json:

```json
{
  "permissions": {
    "allow": [
      "mcp__filesystem__read_file",
      "mcp__filesystem__list_directory",
      "mcp__github__get_issue"
    ],
    "deny": [
      "mcp__github__delete_repository"
    ]
  }
}
```

::: warning Least Privilege Principle
Only allow tools you trust. Especially `delete_*`, `write_*`类 tools — a malicious MCP server could cause data loss.
:::

## Chapter Summary

- MCP configured via `claude mcp add`; supports stdio (local) and SSE (remote) transport;
- Common servers: filesystem (files), github (code hosting), postgres (database);
- Tool naming format `mcp__<server>__<tool>`; view status with `/mcp`;
- Fine-grained MCP tool permissions via allow/deny in settings.json;
- Follow least privilege — only open必要 tools.
