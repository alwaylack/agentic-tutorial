# Claude Code · Course Guide

This course consists of **21 chapters**, based on **Claude Code 2.x** official docs and npm package notes — from zero to team-level engineering applications.

## What You Will Learn

| Phase | Chapters | Content |
|---|---|---|
| Getting Started | 01–05 | Installation & config, basic conversations, CLAUDE.md, file editing, Bash execution |
| Advanced | 06–10 | Permission security, multi-turn sessions, Git integration, MCP tools, Skills |
| Expert | 11–15 | Sub-agents, Hooks, IDE integration, SDK programmatic invocation, enterprise config |
| Production | 16–21 | Enterprise config, cost management, best practices & team norms, capstone project, recent new features |
