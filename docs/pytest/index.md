# pytest 教程 · 课程导学

本课程基于 **pytest 9.x 官方文档**编写，共 **20 章**，从零基础一路讲到生产实践。

## 你将学到什么

| 阶段 | 章节 | 内容 |
|---|---|---|
| 入门 | 01–05 | 测试基础、断言、组织与标记、参数化 |
| 进阶 | 06–11 | fixture 全家桶、内置 fixture、mock、配置文件 |
| 高级 | 12–18 | 插件开发、覆盖率、并行执行、异步测试、Hypothesis |
| 生产实践 | 19–20 | Web 服务集成测试、CI 与测试治理 |

## 学习前提

- 会 Python 基础语法（函数、类、模块导入）；
- 本机装有 Python 3.10+。

## 如何学习

1. 每章先读讲解、亲手敲示例代码；
2. 完成「随堂测验」（答错会给出正确答案和原因）；
3. 完成「动手实践」3 道小题后再进入下一章。

👉 从 [第 1 章](./ch01) 开始。
